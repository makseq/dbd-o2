# UI_SPEC — веб-интерфейс 1D fluid-симуляции ДБР в O₂

Версия 1.0 · тёмная научная тема · аудитория: физик/инженер плазмы.
Документ — спецификация, не код. Всё, что здесь задано числами и HEX'ами, обязательно к исполнению;
всё остальное — рекомендация.

## 0. Принципы, из которых выведено всё остальное

1. **Модель одномерна — интерфейс не должен врать про 2D.** Разрядный промежуток рисуется полосой (slab),
   но это визуальный приём: поперёк промежутка поле однородно по построению. Полоса обязана нести подпись
   `1D model · uniform in transverse direction`. «Филамент» в 1D — это не пятно в плоскости электрода,
   а **временной импульс** и волна ионизации по x. Честная «двумерная» картинка здесь ровно одна —
   диаграмма **x–t** (streak). Она равноправна snapshot-режиму, а не «nice-to-have».
2. **Три временных масштаба на одном экране физически несовместимы**, поэтому их разводят явно:
   период (10⁻⁴ с) → полупериод → филамент (10⁻⁸…10⁻⁷ с) → наработка O₃ (10⁻¹…10¹ с).
   Решение — двухуровневая шкала времени (§4.3) + отдельный «медленный» трек химии.
3. **Цвет — последнее решение, а не первое.** Палитра проверена скриптом (§3.5), не на глаз.
4. **Идентичность частиц никогда не кодируется только цветом** (§3.2, §5.3).
5. **Никаких двойных осей Y.** Ток и напряжение — два стека одной временной оси, не два масштаба в одних осях.

## 2. Панели: содержание и поведение

### 2.1 B. Discharge gap (главная панель)

**Геометрия.** Горизонтальная ось = координата x поперёк ячейки, слева направо:
`metal (12 px, фикс.) | dielectric₁ | gas gap | dielectric₂ | metal (12 px)`.
Ширина диэлектриков и зазора **пропорциональна реальным d** (при d_d=0.5, d_gap=1.0 → 25 % / 50 % / 25 %).
Металл рисуется фиксированной шириной вне пропорции (он не часть расчётной области) и визуально отделён.

**Заливка.** Диэлектрики — `#1c2430` с диагональной штриховкой 45°, шаг 6 px, `#2a3644` (текстура нужна,
чтобы диэлектрик читался в forced-colors и ч/б печати). Металл — `#3a4250` со сплошной заливкой и
вертикальной штриховкой 90°. Газовый зазор — колормапа выбранного поля.

**Режим `snapshot`** (по умолчанию): текущее поле f(x, t) в виде вертикально-однородной полосы
высотой 140 px. Поверх полосы — тонкая (1.5 px) линия того же поля в линейных/лог-координатах,
цвет `#e8eaed` при 60 % opacity: колормапа даёт быстрое узнавание, линия — количественное чтение.

**Режим `x–t streak`**: накопительная растровая диаграмма, ось X = координата, ось Y = время
(вниз — прошлое), окно = текущий полупериод либо длина «лупы» микрошкалы. Это главный инструмент,
чтобы **увидеть волну ионизации**: катодонаправленный стример виден как наклонная яркая полоса,
таунсендовский режим — как равномерное горизонтальное свечение. Скорость волны считается по наклону
и выводится в подписи: `v_front ≈ 2.4·10⁵ m/s`.

**Переключаемые поля** (сегментный контрол сверху):

| Поле | Тип шкалы | Колормапа | Примечание |
|---|---|---|---|
| `n_e` | log₁₀, 7 декад | sequential Inferno | дефолт |
| `ρ = e(n₊ − n₋ − n_e)` | **diverging**, симметрично | Blue↔Red, серый ноль | знак обязателен |
| `S_ion` / glow | log₁₀ | sequential Inferno | «свечение», бумит при пробое |
| `|E|` | lin | sequential Inferno | |
| `E/N`, Td | lin | sequential Inferno + изолиния 100 Td | порог ионизации |
| `E_x` (знаковое) | diverging | Blue↔Red | опция, «nice-to-have» |

Скейлинг: `auto` (по текущему кадру, с экспоненциальным сглаживанием τ=300 ms, чтобы не мерцало) или
`fix` (пользователь задаёт min/max, чтобы сравнивать режимы). Colorbar с числовыми тиками — **всегда**,
без него колормапа не количественна.

**Поверхностный заряд σ.** На каждой границе газ/диэлектрик — вертикальная «шина» шириной 6 px:
- знак: `+` → `#e66767`, `−` → `#3987e5`, |σ| → непрозрачность 0.15…1.0 и высота заполнения шины;
- поверх — ряд глифов `+`/`−` (плотность глифов ∝ |σ|) — это secondary encoding, не только цвет;
- числовое значение `σ, nC/cm²` подписью под шиной, tabular-nums;
- слева/справа маленький спарклайн σ(t) за последние 2 периода (24×32 px).

**Подсветка филамента.** Когда `S_ion` превышает 5 % от исторического максимума:
- зона x, где превышение, обводится 1 px рамкой `#ffd166` с наружным glow `0 0 12px rgba(255,209,102,.45)`;
- под полосой появляется маркер-«игла» с подписью длительности текущего импульса.

### 2.2 D. Waveforms (осциллограмма)

Три трека, **общая ось времени**, раздельные оси Y (стек, не dual-axis):
1. `U_app` (приложенное), `U_gap` (на промежутке), опц. `U_diel` — кВ, линейная.
2. `I_disch` (ток разряда = полный минус ёмкостной), `I_total` — переключатель `lin | log`.
   Дефолт **log** (диапазон 10⁻⁶…10⁻¹ A): импульсы в десятки нс на линейной шкале превращаются в
   вертикальные палки без структуры.
3. Опц. трек: `σ_left`, `σ_right`.

Ось X подчинена микрошкале (§4.3): при lens = 4 µs видны отдельные импульсы; при полном периоде —
огибающая (min/max decimation, не подвыборка — иначе импульсы теряются; см. §4.4).

Курсор времени: вертикальная линия `#8b93a1`, 1 px, с меткой `t = 12.8043 ms`. Курсор синхронен во
всех панелях (crosshair-brushing): наведение на Q–V подсвечивает соответствующую точку осциллограммы,
и наоборот. Клик по осциллограмме = перемотка симуляции к этому t (только в режиме воспроизведения буфера).

### 2.3 E. Q–V Лиссажу

Квадратная область (aspect 1:1, иначе наклоны читаются неверно). Q по вертикали (nC), U_app по горизонтали (кВ).

- Текущий период — сплошная линия `#e8eaed` 2 px; 7 предыдущих — те же координаты, opacity 0.10…0.35, без цвета.
- Автодетект четырёх вершин A, B, C, D по изломам (кривизна ∂²Q/∂U²). Вершины — точки 8 px, подписи A…D.
- Аппроксимация двух пар сторон МНК:
  `C_diel` = наклон разрядных сторон (A→B, C→D), `C_cell` = наклон нейтральных (B→C, D→A).
  Аппроксимирующие прямые — пунктир 4 4, `#8b93a1`, с подписью наклона.
- Производные величины в подписи панели: `U_min` (напряжение горения), `ΔQ` (перенесённый заряд),
  `E_per_period = ∮U dQ`, `P = f·E`. Всё с единицами и tabular-nums.
- **Индикатор качества**: если фигура не параллелограмм (R² сторон < 0.98 или не найдено 4 вершины) —
  бейдж `⚠ non-ideal Lissajous — Manley slopes unreliable`, статусный цвет `#fab219`. Молча выдавать
  C_diel по кривому эллипсу — хуже, чем не выдавать вовсе.
- Переключатель `[1 period] / [last 8] / [accumulate]`.

### 2.4 F. Density profiles

Мультилиния n_s(x) в log₁₀, ось Y от 10¹² до 10²² м⁻³ (авто-расширение, но не сужение уже, чем 6 декад).
Шесть кривых, идентичность = **цвет + штрих + прямая подпись у правого конца кривой** (§3.2).
- Наведение → вертикальный crosshair + тултип со **всеми** шестью значениями в точке x, отсортированными
  по убыванию, плюс проверка квазинейтральности `Σq/e = …`.
- Клик по легенде = solo (остальные к 12 % opacity), alt+клик = скрыть.
- Опция: показывать не профиль по x, а временной ряд n̄_s(t) (усреднённое по зазору) — на нём видна
  медленная наработка O и O₃; переключатель `x-profile | time-series`.

### 2.5 C. Metrics

Плитки 3×3, каждая: подпись (11 px, `#8b93a1`, uppercase, letter-spacing .06em), значение (20 px,
mono, tabular-nums, `#e8eaed`), единицы (12 px, `#8b93a1`), микро-спарклайн 60×16 px за последние 8 периодов.

Обязательные плитки: `Power, W` · `Specific energy, J/L` · `Ozone, ppm` · `max E/N, Td` ·
`peak current, mA` · `breakdowns per period` · `C_diel, pF` · `C_cell, pF` · `energy per period, mJ`.

Строка ниже — статус солвера: `dt` · `steps/frame` · `wall→sim` · `CFL` · `Poisson iters` · `residual`.
Если `CFL > 0.9` или `residual > 1e-8` — строка окрашивается в `#fab219` / `#d03b3b` с иконкой,
а не только цветом.

**Ограничение, о котором надо знать честно.** На полном списке пар (all-pairs) шесть насыщенных
хуёв на тёмном фоне не проходят порог CVD ни в одном порядке — это математика, а не вкус.
Поэтому secondary encoding **обязателен, а не опционален**:
1) разные dash-массивы из таблицы; 2) прямая подпись у конца каждой кривой (≤ 4 видимых кривых —
подписываются все; больше — подписываются 4 верхние по значению в точке курсора);
3) solo-по-клику; 4) режим `CVD-safe` в настройках, который оставляет 4 кривые (`e⁻, O₂⁺, O⁻, O₃`)
и прячет остальные за «Other».

Вспомогательные (не частицы): `U_app` `#e8eaed` 2 px сплошная · `U_gap` `#a9b0bb` 2 px `6 3` ·
`I_disch` `#ffd166` 2 px · `I_total` `#ffd166` 1 px `3 3` · `σ_left` `#3987e5` · `σ_right` `#e66767`.

### 3.3 Колормапа полей (sequential)

**Выбор: Inferno. Обоснование, а не вкус:**
- **turbo/jet — исключены.** Немонотонная светлота создаёт ложные «полосы» и градиенты там, где данные
  гладкие; при CVD распадается. Для количественного поля это дефект, а не стиль.
- **viridis** — перцептивно равномерна и CVD-безопасна, но её тёмный конец сине-фиолетовый и на
  тёмно-синем UI-фоне «нулевая плазма» сливается с рамками панели; плюс метафора неверная —
  зелёный не читается как свечение.
- **Inferno** — тоже перцептивно равномерна и монотонна по светлоте (это главное), но её тёмный конец
  почти чёрный (`#000004`) и на фоне `#10141a` даёт естественный «выключенный газ», а яркий конец
  (`#fcffa4`) прямо читается как эмиссия. Для `n_e`, `S_ion`, `|E|`, `E/N` — один и тот же Inferno,
  чтобы «ярче = больше» было единым правилом во всех режимах.

Стопы (позиция 0→1): `#000004 · #1b0c41 · #4a0c6b · #781c6d · #a52c60 · #cf4446 · #ed6925 · #fb9b06 · #f7d13d · #fcffa4`
(равномерно по 1/9). Для печати/ч-б доступен режим `grayscale` — те же данные, ramp `#0a0a0a → #f2f2f2`.

Для сравнительных задач доступна альтернатива **viridis**:
`#440154 · #414487 · #2a788e · #22a884 · #7ad151 · #fde725` — переключатель в настройках, не в основном UI.

### 3.4 Колормапа знаковых полей (diverging)

Для `ρ` и `E_x`. Правило: два полюса + **нейтральный серый ноль**, никакого хуё-радужного центра.
На тёмном фоне ноль — тёмно-серый, полюса — яркие (обратно light-mode логике).

| позиция | значение | HEX |
|---|---|---|
| −1.0 | max отриц. | `#9ec5f4` |
| −0.6 | | `#3987e5` |
| −0.25 | | `#256abf` |
| 0 | ноль | `#383f48` |
| +0.25 | | `#a72f2f` |
| +0.6 | | `#e66767` |
| +1.0 | max полож. | `#f5a8a8` |

Шкала всегда **симметрична** (`±max|ρ|`), иначе ноль уезжает с серого. Одновременно на экране
допускается только одно знаковое поле — поэтому пара blue↔red переиспользуется для обоих.
Дополнительно: изолиния `ρ = 0` — белая 1 px пунктиром `2 2` (не только цвет).

### 3.5 Статусные цвета (зарезервированы, не используются для серий)

`good #0ca30c` · `warning #fab219` · `serious #ec835a` · `critical #d03b3b`.
Всегда с иконкой и текстом. Применение: CFL/сходимость, «Лиссажу не параллелограмм»,
«численная неустойчивость», «сеть не разрешает дебаевский радиус» (`λ_D < 2Δx` → `critical`).

### 3.6 Проверка

```
node scripts/validate_palette.js "#e66767,#3987e5,#d55181,#c98500,#9085e9,#199e70" \
     --mode dark --surface "#10141a"
```
Ожидается PASS по всем пяти пунктам. Любое изменение палитры — только с повторным прогоном.

## 4. Анимация

### 4.1 Что именно движется

| Объект | Частота | Как обновляется |
|---|---|---|
| Колормапа зазора | 60 fps | полная перерисовка из текущего состояния солвера |
| Профили n_s(x) | 30 fps | достаточно; на 60 глаз всё равно не различает |
| Осциллограмма | 60 fps | инкрементально, append + сдвиг окна |
| Q–V фигура | 60 fps | append; C_diel/C_cell пересчитываются 1 раз в период |
| Метрики (числа) | 4 Гц | быстрее — числа мельтешат и нечитаемы; исключение — peak current, обновляется по событию |
| σ-шины | 60 fps | opacity/высота |
| Спарклайны | 1 раз в период | |
| x–t streak | 60 fps | одна новая строка растра за кадр (или N строк при высокой скорости) |

**Развязка солвера и рендера обязательна.** Солвер крутится в Web Worker с адаптивным dt
(0.1…50 нс), рендер берёт последний доступный снимок. Никакого `requestAnimationFrame` внутри
интегратора. Между кадрами Worker делает столько шагов, сколько влезает в бюджет 12 мс,
но не больше, чем требует заданная скорость.

### 4.2 Событие пробоя

Триггер: `dI/dt` пересекает порог вверх **и** `I_disch > 0.05·I_peak_hist`. По событию:

1. **Вспышка (flash).** Оверлей поверх газового зазора: белый `#ffffff` с α = 0.35, спад
   экспоненциально, τ = 120 ms wall-time. Ограничен по x зоной, где `S_ion > 0.5·max`.
2. **Послесвечение (afterglow).** Буфер свечения: `G ← max(S_ion_norm, G·exp(−Δt_wall/τ_g))`, τ_g = 250 ms.
   Рисуется именно G, а не мгновенный `S_ion` — иначе 30-наносекундный филамент при скорости 40×
   попадёт в межкадровый интервал и его никто не увидит. **Это ключевое решение всей анимации.**
   Индикатор `afterglow ON` виден в углу панели, чтобы никто не принял G за мгновенное поле.
3. **Трейл на осциллограмме.** Импульс тока получает вертикальный маркер `#ffd166` и остаётся
   в «истории событий» микрошкалы.
4. **Метка на макрошкале** — «искра» ▲ в позиции t события; цвет по полярности полупериода.
5. **Кольцо на Q–V** — точка события выделяется кружком 6 px на текущей траектории.
6. **Звук — нет.** Даже опционально: физику не слушают, а короткий клик 100 раз в секунду — пытка.

При `prefers-reduced-motion: reduce`: flash и bloom отключаются, остаётся afterglow (он несёт данные)
и статичный маркер события.

### 4.3 Двухмасштабная временная шкала (панель H)

```
MACRO  |0 ─────────────────────────────●───────────────────────| 20.0 ms  (200 периодов)
       |  ▲   ▲    ▲   ▲    ▲   ▲    ▲   ▲   ← события пробоя  |
       |                            [▓▓]  ← окно лупы (не в масштабе, min 4 px)
MICRO  |t−2 µs ══════════════▉▉▉══════════════ t+2 µs |  lens: 4 µs  ⤢ ├──●──┤
```

- **MACRO**: вся история симуляции, ось в мс и в номерах периодов. Треугольники — события пробоя
  (вверх — положительный полупериод `#e66767`, вниз — отрицательный `#3987e5`). Драг = перемотка.
- **MICRO** («лупа»): окно вокруг курсора, ширина настраивается 20 ns … 100 µs логарифмическим
  слайдером. Осциллограмма и x–t streak подчинены именно микрошкале.
- **Связь**: положение лупы на MACRO рисуется как выделенный прямоугольник (минимум 4 px, иначе
  при lens=100 нс из 20 мс он невидим — типичная ошибка brush-навигации).
- **Snap to event**: кнопки `⏮ event` / `event ⏭` перемещают курсор точно на предыдущий/следующий
  пробой. Без этого найти 30-наносекундный импульс мышкой невозможно.
- **Медленный трек (химия).** Третья, опциональная строка `SLOW`: ось в секундах, показывает
  `[O₃](t)`, `[O](t)`, средняя мощность. Обновляется 1 раз в период. Именно на ней видно, что
  озон копится сотнями периодов, пока филаменты мигают на MICRO.

### 4.4 Децимация данных (иначе импульсы исчезают)

Кольцевые буферы: сырые данные солвера (dt ~ ns) → 3 уровня пирамиды (×64, ×4096, ×262144).
Агрегация — **min/max/last в бине**, не среднее и не подвыборка: усреднение убивает наносекундный
пик тока полностью. На графике при децимации рисуется вертикальный «конверт» min–max тем же цветом
при 45 % opacity плюс линия по last. Индикатор `decimated ×4096` в углу панели — пользователь
обязан знать, что смотрит на огибающую.

## 5. Типографика, размеры, отзывчивость, a11y

### 5.1 Типографика

- UI-шрифт: `Inter`, фолбэк `system-ui, -apple-system, Segoe UI, Roboto, sans-serif`.
- Числа и всё, что в моноширинном контексте: `JetBrains Mono`, фолбэк `ui-monospace, SFMono-Regular, Menlo, monospace`.
- **Все числовые значения**: `font-variant-numeric: tabular-nums` — иначе метрики дёргаются при обновлении.
- Шкала: 11 px (тики, единицы) / 12 px (подписи, легенды) / 13 px (тело, значения контролов) /
  16 px (заголовки панелей) / 20 px (значения метрик) / 28 px (hero-число, если появится).
- Заголовки панелей: 12 px, uppercase, letter-spacing 0.08em, `--text-muted`.
- Индексы в формулах (`n_e`, `O₂⁺`, `E/N`) — настоящие Unicode-подстрочные/надстрочные или `<sub>/<sup>`,
  не «O2+».
- Единицы **всегда** отделены от числа тонким пробелом (U+2009) и набраны `--text-muted`.
- Числа: значащих цифр 3, экспонента в виде `4.7·10⁻³`, не `4.7e-3`, кроме полей ввода.

### 5.2 Отзывчивость

| Ширина | Раскладка |
|---|---|
| ≥ 1440 px | как в мокапе (2 колонки, 12-грид) |
| 1100–1440 | правая колонка сужается; метрики 3×3 → 2×4; контролы получают внутренний скролл |
| 760–1100 | одна колонка: Gap → Waveforms → Q–V → Profiles → Metrics; контролы уезжают в правый drawer (кнопка ☰) |
| < 760 (мобильный) | Gap-панель фиксирована сверху (высота 180 px), под ней **табы** `Waveforms / Q–V / Profiles / Metrics`; контролы — bottom sheet; transport-бар остаётся sticky; микрошкала есть, макро сворачивается в компактный слайдер |

Правила: каждая панель с широким содержимым (Q–V, streak) скроллится **внутри себя**
(`overflow-x: auto`), body никогда не скроллится горизонтально. Минимальная полезная ширина
Gap-панели — 320 px; ниже колормапа остаётся, а линия-профиль поверх неё скрывается.

### 5.3 Доступность

- **Текст** ≥ 4.5:1, **графические метки и линии** ≥ 3:1 к своей поверхности — все цвета §3.2 проверены.
- **Никогда только цветом**: dash-паттерны + прямые подписи для кривых; глифы `+`/`−` для σ;
  штриховка для диэлектрика/металла; иконка+текст для статусов; пунктирная изолиния `ρ=0`.
- **Колормапа не количественна без colorbar** — colorbar обязателен всегда, плюс hover-readout
  `n_e(x=0.62 mm) = 3.1·10¹⁹ m⁻³`. Опция «contour overlay» — изолинии по декадам с подписями,
  чтобы поле читалось вообще без цвета.
- **Табличный вид**: у каждой панели кнопка `⊞ table` — те же данные числами (профили в узлах сетки,
  ряды осциллограммы, вершины Лиссажу). Это и a11y, и способ скопировать число.
- **Клавиатура**: `Space` play/pause · `←/→` шаг кадра · `Shift+←/→` шаг события ·
  `+/−` скорость · `1…5` переключение поля колормапы · `L` lin/log · `T` table ·
  `E` экспорт · `?` шпаргалка. Все контролы фокусируемы, focus-ring 2 px `--accent` с offset 2 px.
- **Screen reader**: у каждой панели `role="img"` + `aria-label` с текстовым резюме, обновляемым
  раз в период («период 128: два пробоя, пиковый ток 38 мА, мощность 4.7 Вт»). Живой регион
  `aria-live="polite"` только для событий пробоя и предупреждений, не для чисел.
- **prefers-reduced-motion**: §4.2.
- **forced-colors**: заливки → штриховки, полагаемся на текстуры и подписи.

## 6. Контролы

### 6.1 Параметры (панель G)

Все слайдеры — с **числовым полем ввода рядом**, шагом по стрелкам, и подписью текущего значения
с единицами. Логарифмические там, где отмечено. Изменение применяется по `input` (live), кроме
геометрии — там по `change` (перестройка сетки).

| Контрол | Диапазон | Шаг | Шкала | Дефолт | Реакция |
|---|---|---|---|---|---|
| `U₀` амплитуда | 1 … 20 kV | 0.1 | lin | 10.0 | live, без сброса |
| `f` частота | 0.5 … 100 kHz | 0.1 | **log** | 10.0 | live |
| `d_gap` | 0.2 … 5 mm | 0.05 | log | 1.00 | пересборка сетки → soft reset |
| `d_diel` | 0.1 … 2 mm | 0.05 | lin | 0.50 (×2) | soft reset |
| `ε_r` | 1 … 30 | 0.5 | lin | 9.0 | live (меняет C_diel) |
| `γ` (вторичная эмиссия) | 0 … 0.3 | 0.005 | lin | 0.05 | live |
| `n₀` затравка | 1e10 … 1e16 m⁻³ | — | log | 1e13 | live |
| `p` давление | 0.1 … 2 atm | 0.05 | lin | 1.00 | live (меняет N) |
| `T` газа | 250 … 600 K | 10 | lin | 300 | live |
| `R_series` | 0 … 10 MΩ + toggle | — | log | 0, off | live |
| `S` площадь электрода | 0.1 … 100 cm² | — | log | 1.0 | live (масштаб токов) |
| `N_x` узлов сетки | 200 … 4000 | — | log | 800 | hard reset |
| `форма U(t)` | sine / square / pulsed | — | — | sine | live |

Раздельные «расширенные» контролы (свёрнутая секция `▸ Numerics`): CFL-таргет, макс. dt,
допуск Пуассона, схема потоков (Scharfetter–Gummel / upwind), вкл/выкл трёхтельного прилипания,
вкл/выкл фотоионизации.

Индикатор рядом с геометрией: `Δx = 1.25 µm · λ_D = 2.3 µm · N_x/λ_D = 1.8` со статусным цветом.
Физик должен видеть, что сетка разрешает дебаевскую длину, без залезания в консоль.

### 6.2 Пресеты

Кнопка-дропдаун вверху; каждый пресет — полный набор параметров + рекомендованное поле колормапы
+ настройка лупы. Смена пресета = hard reset с подтверждением, если есть несохранённый прогон.

| Пресет | Параметры | Что показывает |
|---|---|---|
| **Filamentary** (дефолт) | U₀ 10 kV, f 10 kHz, gap 1.0 mm, ε_r 9, γ 0.05, n₀ 1e13, p 1 atm | острые импульсы тока 20–80 нс, катодонаправленная волна на x–t, классический параллелограмм |
| **Townsend / homogeneous** | U₀ 5 kV, f 5 kHz, gap 2.0 mm, γ 0.2, n₀ 1e15 (повышенная предыонизация), p 0.5 atm | один широкий импульс на полупериод, однородное свечение, «эллипсоподобный» Лиссажу |
| **Ozonizer** | U₀ 12 kV, f 25 kHz, gap 0.6 mm, ε_r 9, S 10 cm², прогон 500 периодов | выход O₃ в ppm, удельная энергия J/L, медленный трек химии; UI сразу открывает `time-series` в профилях |
| **Barrier sweep** *(nice-to-have)* | параметрический прогон ε_r 4→20 | как C_diel двигает наклон Лиссажу |

Пресет, помимо цифр, задаёт **начальный вид**: активное поле колормапы, lin/log тока, ширину лупы,
режим профилей. Иначе пользователь получает правильную физику в неправильном ракурсе.

### 6.3 Transport (панель H)

- `⏵/⏸` play/pause · `⏮` reset to t=0 · `⏩` fast-forward.
- `speed` — логарифмический слайдер `wall-time → sim-time`, 1e-9 … 1e-3 s/s, подпись в кратности
  и в абсолюте: `42× (1 s → 24 µs)`. Ограничение сверху — по бюджету Worker'а, при упоре
  в бюджет показывается `throttled`.
- `[1 period]` — прогнать ровно один период и встать на паузу.
- `[run to steady]` — гнать, пока критерий стационарности не выполнен: относительное изменение
  `E_per_period` и `ΔQ` < 0.5 % за 5 подряд периодов, максимум 5000 периодов. Прогресс-бар с
  текущим критерием, кнопка «стоп». По завершении — тост `steady state at period 341 (Δ 0.3 %)`.
- `[step dt]` — один шаг солвера (для отладки численности).
- `[step event]` — до следующего пробоя.
- `reset ⟲` — сброс состояния при сохранении параметров; `⟲⟲` — сброс к пресету.

### 6.4 Экспорт

| Кнопка | Содержимое |
|---|---|
| `⤓ CSV` | меню: **time-series** (t, U_app, U_gap, I_disch, I_total, Q, σ_L, σ_R, P) с выбором децимации; **profile @cursor** (x, n_e, n_O2+, n_O−, n_O2−, n_O, n_O3, E, ρ, S_ion); **per-period summary** (period, E, P, ΔQ, C_diel, C_cell, U_min, N_breakdowns, [O₃]) |
| `⤓ PNG` | текущая панель или весь дашборд; 2× DPI; с вшитой подписью параметров и timestamp в углу — иначе картинка в статье не воспроизводима |
| `⤓ JSON` | полный набор параметров + версия солвера + сид — для точного воспроизведения прогона |
| `Manley report` | markdown-блок: наклоны, C_diel, C_cell, U_min, энергия, мощность, R² аппроксимации |

Все экспорты содержат заголовок с единицами и строку метаданных `# dbd-o2 v… , params hash …`.

## 7. Приоритезация

### MVP (без этого интерфейс не выполняет задачу)

1. Gap-панель, режим `snapshot`, поля `n_e` и `S_ion`, log-шкала, colorbar.
2. σ-шины с числовым значением и знаком (глифы `+/−`).
3. Осциллограмма: U_app, U_gap, I_disch (log), общий курсор времени.

## 8. Открытые вопросы к физической части

1. Нужен ли отдельный вид для возбуждённых состояний (O₂(a¹Δ), O(¹D))? Если да — палитра §3.2
   расширяется до 8 слотов, и режим `CVD-safe` становится обязательным по умолчанию.
2. Как определять «число пробоев за период» формально — по числу локальных максимумов `I_disch`
   выше порога, или по пересечениям `dI/dt`? От этого зависит стабильность метрики; предлагается
   порог `0.1·I_peak` + минимальный интервал 5 нс, и порог должен быть настраиваемым.
3. Ток отображения (displacement) вычитается из полного для получения `I_disch` — нужно решить,
   показывать ли оба по умолчанию (сейчас: `I_disch` жирный, `I_total` тонкий пунктир).

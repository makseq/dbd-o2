# NUMERICS_2D.md — численная схема 2D осесимметричной (r,z) fluid-модели ДБР в чистом O₂

Документ фиксирует численную постановку 2D-части проекта `/p/dbd-o2` (код: `sim2d/`, плеер: `player/`).
Химия, транспортные коэффициенты, γ, затравка — **целиком из `docs/PHYSICS.md`**, здесь они не
переопределяются. 1D-схема (`docs/NUMERICS.md`) используется как источник уже принятых решений
(Шарфеттер–Гуммель, полунеявный Пуассон, экспоненциальный интегратор источников, Сато–Морроу);
всё, что ниже, — это её честное обобщение на цилиндр плюс то, что в 1D не встречалось.

Целевая платформа: **node.js, офлайн-расчёт**, один поток (опционально `worker_threads` для GEMM),
`Float64Array` для состояния, результат — кадры на диске.

> **Важно (повтор из ТЗ, чтобы не потерялось в коде):** в чистом O₂ фотоионизация не работает
> (нет N₂-излучателя, ионизующего O₂). Модель распространения фронта здесь держится на трёх ногах:
> фоновая затравка + отлипание от O⁻/O₂⁻/O₃⁻ (объёмная память) + γ-эмиссия с диэлектрика.
> Модель Железняка **не включена и включаться не должна**.

## 1. Сетка и метрики

### 1.1 Область и что в неё входит

В отличие от 1D-схемы (где барьеры исключались аналитически в условие Робина), **в 2D барьеры
включаются в сетку явными ячейками**. Причина конкретная: в 2D потенциал внутри барьера
**не линеен** — он несёт радиальную структуру от пятна поверхностного заряда, и её нужно
разрешать. Аналитическое исключение всё же возможно (точное DtN-отображение слоя, диагональное
в радиальном модальном базисе, §2.7), но оно ломается, как только полунеявная поправка делает
базис зависящим от σ_cond. Поэтому: **явные ячейки барьера, у них `eps_r = 9`, нулевая
подвижность всех сортов, нулевые источники, плотности не эволюционируют.** Один код сборки
на всю область, нулевой риск рассогласования.

```
z = 0 ........ 0.5 мм : барьер 1 (Al2O3, eps_r=9),  металл при z=0, phi = U(t)
z = 0.5 ...... 1.5 мм : ГАЗ (O2, 1 атм, 300 K)
z = 1.5 ...... 2.0 мм : барьер 2, металл при z=Lz=2.0 мм, phi = 0
r = 0 ........ R = 0.5 мм ; r=0 ось, r=R зеркальная (Neumann) стенка
```

Сетка **cell-centered конечно-объёмная**, тензорная: `nr` колонок × `nz` строк, узлы граней
`rf[0..nr]`, `zf[0..nz]`. Граница газ/диэлектрик **обязана совпадать с гранью сетки** — это
не удобство, а условие точности: скачок ε тогда попадает точно на грань, где гармоническое
среднее даёт **точный** поток, а не аппроксимацию.

### 1.2 Раскладка памяти

**Решение: `field[i*nz + j]`, то есть `z` — быстрый (contiguous) индекс, `r` — медленный.**

Обоснование не косметическое: самая дорогая операция всего кода — плотное радиальное
преобразование `û[k][:] = Σ_i Q[k][i] · u[i][:]` (§2.5). При такой раскладке оно распадается
на `nr²` вызовов `axpy` по непрерывным векторам длины `nz` — идеальный последовательный доступ,
~0.6–1 нс/MAC в V8. При обратной раскладке это был бы strided-доступ с промахами кэша и
потерей в 3–5 раз. Транспорт по z тоже становится непрерывным; транспорт по r идёт со шагом
`nz` — приемлемо, потому что это простое чтение соседней «строки» (префетчер справляется).

### 1.3 Профили сетки

| Профиль | nr | nz (d1/газ/d2) | dr_min / dr_max | dz_min / dz_max (газ) | ячеек |
|---|---|---|---|---|---|
| `demo` | 80 | 176 (14/148/14) | 2.6 / 12 мкм | 2.6 / 10 мкм | 14 080 |
| **`default`** | **96** | **224 (16/192/16)** | **2.13 / 10.4 мкм** | **2.01 / 7.91 мкм** | **21 504** |
| `accurate` | 160 | 320 (24/272/24) | 1.2 / 6.4 мкм | 1.4 / 5.5 мкм | 51 200 |

Что надо разрешить (из PHYSICS.md §6 и общей физики атмосферного ДБР):
- катодный слой у поверхности диэлектрика: **10–30 мкм** → нужно ≥ 8–15 ячеек → `dz_min ≈ 2 мкм`;
- головка стримера / фронт лавины по z: 20–80 мкм;
- радиус филамента: 50–150 мкм → при `dr` у оси 2.1 мкм внутри 50 мкм лежит **20 ячеек**,
  внутри 150 мкм — **47 ячеек**. Достаточно для формы головки и радиального растекания σ.

#### Генератор сетки по r (сгущение к оси, экспоненциальное растяжение)

```js
// rf[0]=0 ... rf[nr]=R ; сгущение у r=0
function makeRGrid(nr, R, betaR = 1.6) {
  const rf = new Float64Array(nr + 1);
  const den = Math.exp(betaR) - 1;
  for (let k = 0; k <= nr; k++) rf[k] = R * (Math.expm1(betaR * k / nr)) / den;
  return rf;
}
```
Свойства при `nr=96, R=0.5 мм, betaR=1.6`: `dr[0]=2.126 мкм`, `dr[nr-1]=10.35 мкм`,
**отношение соседних ячеек ровно `exp(betaR/nr) = 1.0168`** (1.7 % — гладко, второй порядок
конечно-объёмной аппроксимации сохраняется; порог из 1D-документа `<8 %` выполнен с запасом).

Почему не tanh, как в 1D: tanh симметричен, а тут нужна **односторонняя** густота у оси
(на оси нет пограничного слоя, но есть филамент; у `r=R` вообще ничего не происходит,
это зеркальная стенка). Экспонента даёт постоянный коэффициент растяжения — лучшее, что
можно сделать при фиксированном `nr` и заданном `dr_min`.

#### Генератор сетки по z (три блока)

```js
function makeZGrid(nz1, ngap, nz2, d1, Lg, d2, betaG = 2.63, qB = 1.3147) {
  // блок 1: барьер, геометрическое сгущение К ГРАНИЦЕ z=d1
  // блок 2: газ, симметричный tanh (густо у обеих поверхностей)
  // блок 3: барьер, зеркало блока 1
  const zf = [0];
  // --- барьер 1: ячейки от металла к поверхности, dz убывает как qB^-1
  const dz0 = d1 * (qB - 1) / (Math.pow(qB, nz1) - 1);   // ширина у поверхности
  for (let k = nz1 - 1; k >= 0; k--) zf.push(zf[zf.length-1] + dz0 * Math.pow(qB, k));
  // --- газ: симметричный tanh
  const th = Math.tanh(betaG / 2), z0 = zf[zf.length-1];
  for (let k = 1; k <= ngap; k++) {
    const s = 2 * k / ngap - 1;
    zf.push(z0 + 0.5 * Lg * (1 + Math.tanh(betaG * s / 2) / th));
  }
  // --- барьер 2: зеркало
  const z1 = zf[zf.length-1];
  for (let k = 0; k < nz2; k++) zf.push(zf[zf.length-1] + dz0 * Math.pow(qB, k));
  return Float64Array.from(zf);
}
```
При `nz1=nz2=16, ngap=192, betaG=2.63, qB=1.3147`:
`dz_gap ∈ [2.01, 7.91] мкм` (max отношение соседних 1.024), в барьере `dz ∈ [2.0, 121] мкм`
(отношение 1.31).

> **Почему в барьере можно нарушать правило гладкости 8 %.** Внутри барьера нет ни зарядов,
> ни источников, ни транспорта; решается только уравнение Лапласа с постоянной ε. Конечно-объёмная
> схема с гармоническим средним на грани **точна** для любого профиля, линейного по z, при
> **любом** распределении узлов. Радиальная структура там гладкая (масштаб ≥ размера пятна
> заряда, ≥ 50 мкм) и по r сетка гладкая. Значит грубая градуировка по z в барьере не стоит
> ничего по точности, а экономит 2×(16..24) строк вместо 2×60.

### 1.4 Метрики (выписать один раз, положить в предвычисленные массивы)

```
rf[i]      , i = 0..nr        грани по r,  rf[0]=0, rf[nr]=R
rc[i] = 0.5*(rf[i] + rf[i+1])            центр ячейки (арифметический!)
dr[i] = rf[i+1] - rf[i]
hr[i] = rc[i] - rc[i-1]                  расстояние между центрами, i = 1..nr-1

zf[j]      , j = 0..nz
zc[j] = 0.5*(zf[j] + zf[j+1])
dz[j] = zf[j+1] - zf[j]
hz[j] = zc[j] - zc[j-1]                  j = 1..nz-1

Acell[i] = pi*(rf[i+1]^2 - rf[i]^2)      площадь КОЛЬЦА (площадь z-грани ячейки), м²
V[i][j]  = Acell[i] * dz[j]              объём ячейки, м³
Az[i][j] = Acell[i]                      площадь верхней/нижней грани
Ar[i][j] = 2*pi*rf[i] * dz[j]            площадь боковой грани при r = rf[i]
                                          -> Ar[0][j] = 0 ТОЖДЕСТВЕННО (ось)
```

Полезные предвычисления для дивергенции (§4.3):
```
cr_out[i] = 2*rf[i+1] / (rf[i+1]^2 - rf[i]^2)      // = Ar(i+1)/V * dz
cr_in [i] = 2*rf[i]   / (rf[i+1]^2 - rf[i]^2)      // cr_in[0] = 0
```

**Про выбор центра ячейки.** Строгий центроид кольца — `r_c = (2/3)(rf₊²+rf₊rf₋+rf₋²)/(rf₊+rf₋)`,
он отличается от арифметической середины на `O(dr²/r)`. Мы **берём арифметическую середину**,
и вот почему это правильно, а не лениво:
- дискретный оператор с арифметическими центрами и точными площадями граней — это в точности
  классический трёхточечный цилиндрический лапласиан, он второго порядка на гладких сетках;
- он **симметризуем** диагональной матрицей `Acell` (§2.3) — а именно на этом стоит весь
  прямой решатель. С центроидами симметрия сохраняется тоже, но ценой того, что расстояния
  между центрами перестают согласовываться с площадями, и константное решение
  перестаёт быть точным ядром оператора (появляется невязка `O(dr²/r)` у оси).
- Тест `L_r · 1 = 0` **до машинного нуля** — обязательное требование (§8), и оно выполняется
  тождественно при любом выборе `rc`, потому что оператор построен на разностях. Но точность
  восстановления гладких радиальных профилей у оси лучше с арифметическим центром при наших
  гладких сетках.

Ячейка `i=0` — это **цилиндрик** радиуса `rf[1]`, а не тонкое кольцо. Диагностику «на оси»
берём как значение в `i=0` (это среднее по объёму цилиндрика радиуса 2.1 мкм — физически
это и есть «на оси»).

### 1.5 Материальные массивы

```
epsr[j]  = 9  для j в барьерах, 1 в газе          (функция ТОЛЬКО от j — ключ ко всему §2)
eps[j]   = eps0 * epsr[j]
isGas[j] = (j >= JG0 && j <= JG1)                  JG0 = nz1, JG1 = nz1+ngap-1
```
Индексы поверхностей:
```
JS_LO = nz1 - 1        последняя ячейка барьера 1 (диэлектрик)
JG0   = nz1            первая ячейка газа        — грань между ними несёт sigma_lo(r)
JG1   = nz1+ngap-1     последняя ячейка газа
JS_HI = nz1+ngap       первая ячейка барьера 2   — грань между JG1 и JS_HI несёт sigma_hi(r)
```
Поверхностный заряд: два массива длины `nr` — `sigLo[i]`, `sigHi[i]` [Кл/м²].

## 2. Пуассон: разделимый прямой решатель

### 2.1 Постановка и конечно-объёмная дискретизация

```
div( eps(z) * grad phi ) = -rho(r,z)
rho = e*( n_O2+ + n_O4+ - n_e - n_O- - n_O2- - n_O3- )   в газе, 0 в барьерах
```
плюс сингулярные слои `sigma_lo(r)`, `sigma_hi(r)` на двух гранях газ/диэлектрик.
Граничные условия: `phi = U(t)` при `z=0`, `phi = 0` при `z=Lz`, `dphi/dr = 0` при `r=0` и `r=R`.

Интегрируем по ячейке `(i,j)` и применяем теорему Гаусса. Обозначим **проводимости граней**
(в электростатическом смысле, [Ф/м] × м = Ф... фактически `eps*A/h`, размерность Ф):

```
Tz[i][j+1/2] = epsF[j+1/2] * Acell[i] / hz[j+1]          // j+1/2 между j и j+1
Tr[i+1/2][j] = eps[j]      * Ar[i+1][j] / hr[i+1]        // = eps[j]*2*pi*rf[i+1]*dz[j]/hr[i+1]

epsF[j+1/2] = hz[j+1] / ( 0.5*dz[j]/eps[j] + 0.5*dz[j+1]/eps[j+1] )    // ГАРМОНИЧЕСКОЕ среднее
```
Гармоническое среднее обязательно: оно даёт точный поток через границу двух сред с разными ε
при кусочно-линейном потенциале. Арифметическое даёт ошибку 30–50 % на границе газ/Al₂O₃.

Уравнение строки `(i,j)`:
```
  Tz[i][j+1/2]*(phi[i][j+1] - phi[i][j])  -  Tz[i][j-1/2]*(phi[i][j] - phi[i][j-1])
+ Tr[i+1/2][j]*(phi[i+1][j] - phi[i][j])  -  Tr[i-1/2][j]*(phi[i][j] - phi[i-1][j])
= -rho[i][j] * V[i][j]  -  (вклады sigma, §2.6)
```
Матрица `A` (в этой, **не** поделённой на объём форме) **симметрична и отрицательно определена**:
коэффициент `T_f` принадлежит грани, а не ячейке. Это существенно для §3 (там нужен CG).

На оси `Tr[-1/2][j] ∝ Ar[0][j] = 0` — граничное условие Неймана выполняется **тождественно**,
никакого специального кода. При `r=R` слагаемого `Tr[nr-1/2]` просто нет.

### 2.2 Разделимость: проверка идеи из ТЗ

Поделим строку на `V[i][j] = Acell[i]*dz[j]`:

**z-часть:**
```
(1/dz[j]) * [ epsF[j+1/2]*(phi[i][j+1]-phi[i][j])/hz[j+1]
            - epsF[j-1/2]*(phi[i][j]-phi[i][j-1])/hz[j] ]
```
`Acell[i]` сократилось нацело → **коэффициенты зависят только от `j`**. ✔

**r-часть:**
```
eps[j] * (2*pi/Acell[i]) * [ rf[i+1]*(phi[i+1][j]-phi[i][j])/hr[i+1]
                           - rf[i]  *(phi[i][j]-phi[i-1][j])/hr[i]  ]
```
`dz[j]` сократилось нацело; остался общий множитель `eps[j]` (потому что боковая грань лежит
**целиком внутри одного материала** — скачок ε происходит на z-грани, не на r-грани), а
скобка зависит только от `i`. ✔

Итого, с обозначением
```
(L_r u)_i = (2*pi/Acell[i]) * [ rf[i+1]*(u[i+1]-u[i])/hr[i+1] - rf[i]*(u[i]-u[i-1])/hr[i] ]
(A_z u)_j = (1/dz[j]) * [ epsF[j+1/2]*(u[j+1]-u[j])/hz[j+1] - epsF[j-1/2]*(u[j]-u[j-1])/hz[j] ]
```
получаем
```
(A_z phi)[i][j]  +  eps[j] * (L_r phi)[i][j]  =  -rho_eff[i][j]                       (★)
```
**Оператор разделяется. Идея из ТЗ верна.** Ключевые условия её корректности, каждое из которых
надо явно проверить в коде:

1. **`eps = eps(z)` и только `z`.** Скачок ε на границе газ/диэлектрик разделимости не мешает,
   потому что он идёт по `z` и попадает целиком в `A_z` (через `epsF`) и в скалярный множитель
   `eps[j]` при `L_r`. Если когда-нибудь захочется радиально неоднородного диэлектрика
   (например, покрытие только на оси) — метод рушится сразу и полностью; это надо записать
   как явное ограничение архитектуры.
2. **Тензорная сетка.** `rf` не зависит от `j`, `zf` не зависит от `i`. AMR/локальное измельчение
   несовместимы с методом. Это осознанная плата.
3. **Граничные условия по r — однородные Неймана на обоих концах** (ось и зеркальная стенка).
   Это делает `L_r` симметризуемым и даёт полный ортогональный базис. Если бы на `r=R` стоял
   Дирихле, всё тоже работало бы (просто другой базис).
4. **Граничные условия по z — Дирихле на обоих концах.** Это то, что спасает нулевую моду
   (см. §2.4).

### 2.3 Симметризация L_r и построение базиса

`L_r` в записи выше **не симметрична** (строка поделена на `Acell[i]`). Но:
```
M_r = diag(Acell) * L_r ,       M_r[i][i+1] = M_r[i+1][i] = 2*pi*rf[i+1]/hr[i+1]
```
— **симметричная** трёхдиагональная матрица (внедиагональный элемент зависит только от грани).
Диагональ `M_r[i][i] = -(M_r[i][i-1] + M_r[i][i+1])` (сумма строки нуль → `M_r·1 = 0`).

Пусть `D = diag(Acell[i])` (SPD, диагональная). Тогда
```
S = D^{-1/2} * M_r * D^{-1/2}          симметрична, трёхдиагональна, отрицательно полуопределена
S = Q * diag(lambda) * Q^T ,           Q ортогональна (Q^T Q = I)
L_r = D^{-1} M_r = D^{-1/2} S D^{1/2}
```
Элементы `S`:
```
S[i][i+1] = S[i+1][i] = ( 2*pi*rf[i+1]/hr[i+1] ) / sqrt(Acell[i]*Acell[i+1])
S[i][i]   = -( 2*pi*rf[i]/hr[i] + 2*pi*rf[i+1]/hr[i+1] ) / Acell[i]      (крайние члены опущены)
```

**Ответ на вопрос ТЗ «нужна ли взвешенная симметризация D^{1/2} L D^{-1/2}»: да, нужна, и
метрика — именно площади колец `Acell[i]` (не `rc[i]`, не объёмы `V[i][j]`).** Объёмы содержат
`dz[j]`, который в r-операторе сокращается, поэтому брать их было бы ошибкой (получилась бы
`j`-зависимая матрица — конец разделимости).

Замена переменных:
```
u = D^{1/2} phi        (u[i][j] = sqrt(Acell[i]) * phi[i][j])
g = D^{1/2} rho_eff
```
`A_z` действует только по `j` и коммутирует с `D^{1/2}`, поэтому (★) превращается в
```
A_z u  +  eps[j] * S u  =  -g
```
Применяем `Q^T` по индексу `i`:  `û[k][j] = Σ_i Q[i][k] u[i][j]`. Тогда для каждой моды `k`
**независимо**:
```
(A_z û_k)[j]  +  eps[j] * lambda[k] * û_k[j]  =  -ĝ_k[j]                              (★★)
```
— трёхдиагональная система по `j` размера `nz`. Прогонка Томаса, `O(nz)`.

### 2.4 Нулевая мода и обусловленность

`M_r · 1 = 0` ⟹ `S · (D^{1/2} 1) = 0` ⟹ **`lambda[0] = 0`** с собственным вектором
`q_0 ∝ sqrt(Acell[i])` (нормированный: `q_0[i] = sqrt(Acell[i]/Σ Acell)= sqrt(Acell[i]/(pi R²))`).

Это **не** сингулярность: при `k=0` система (★★) вырождается в
`(A_z û_0)[j] = -ĝ_0[j]` с **Дирихле по z на обоих концах** — невырожденная трёхдиагональная
задача. Проверка ТЗ подтверждается. (Сингулярность была бы только при Неймана по z с обеих
сторон — чистая задача Неймана, которой у нас нет и не будет: один электрод всегда заземлён.)

Диапазон собственных значений при `nr=96, betaR=1.6`:
```
lambda[0] = 0 ,  |lambda[max]| ~ 4/dr_min^2 = 4/(2.13e-6)^2 = 8.8e11 [1/м²]
eps0 * |lambda_max| = 8.85e-12 * 8.8e11 = 7.8   [Ф/м³ ... в единицах строки (★★)]
диагональ A_z ~ eps0/dz_min^2 = 8.85e-12/(2e-6)^2 = 2.2
```
Величины одного порядка — **катастрофического масштабирования нет**. Для больших `k` система
(★★) сильно диагонально доминирует (`eps*lambda_k` >> внедиагональ), значит прогонка Томаса
без выбора главного элемента устойчива: это M-матрица. Для `k` малых доминирует `A_z`, тоже
M-матрица (все внедиагональные положительны, диагональ = −сумма, плюс Дирихле). Прогонка
устойчива на всём диапазоне мод — **пивотинг не нужен**, это надо проверить один раз ассертом
`|c'[j]| < 1` в прогонке.

### 2.5 Алгоритм и стоимость

**Однократно (или при смене сетки/dt-уровня):**
```
build S (nr x nr, трёхдиагональная симметричная)
tqli(S) -> lambda[0..nr-1], Q[nr][nr]              // implicit QL с Wilkinson-сдвигом, O(nr^3)
assert ||Q^T Q - I||_inf < 1e-12
assert |lambda[0]| < 1e-9 * max|lambda|            // нулевая мода на месте
для каждой моды k: LU-факторизация трёхдиагональной (★★) -> a'[k][j], c'[k][j]   (3*nr*nz чисел)
```
`tqli` для `nr=96` — около `4*nr^3 = 3.5 Мфлоп`, ~5–10 мс. Делается **лениво**, не каждый шаг.

**На каждый вызов решателя:**
```
1. g[i][j]   = sqrt(Acell[i]) * rho_eff[i][j]                     nr*nz  умножений
2. ĝ[k][j]   = Σ_i Q[i][k] * g[i][j]                              nr^2*nz MAC   <-- ГОРЯЧЕЕ МЕСТО
3. для k=0..nr-1: прогонка по j (LU уже готова)                   ~5*nr*nz
4. u[i][j]   = Σ_k Q[i][k] * û[k][j]                              nr^2*nz MAC   <-- ГОРЯЧЕЕ МЕСТО
5. phi[i][j] = u[i][j] / sqrt(Acell[i])                           nr*nz
```
Шаги 2 и 4 — это GEMM `(nr×nr)·(nr×nz)`. В раскладке `[i*nz+j]` они пишутся как `axpy`:

```js
// forward: ghat[k][:] = sum_i Q[i][k] * g[i][:]
ghat.fill(0);
for (let i = 0; i < nr; i++) {
  const gi = i * nz;
  for (let k = 0; k < nr; k++) {
    const q = Q[i * nr + k];
    if (q === 0) continue;
    const ko = k * nz;
    for (let j = 0; j < nz; j++) ghat[ko + j] += q * g[gi + j];   // чистый axpy
  }
}
```
Стоимость при `nr=96, nz=224`: `96²·224 = 2.06 МMAC` на преобразование, `4.13 МMAC` на вызов.
При ~0.7 нс/MAC (измеренная планка V8 на непрерывных `Float64Array`) → **~3 мс на вызов**.
Прогонки: `5·96·224 = 108 кфлоп` — 0.15 мс, шум.

| nr × nz | МMAC / вызов | оценка мс/вызов |
|---|---|---|
| 80 × 176 | 2.25 | 1.6 |
| **96 × 224** | **4.13** | **~3** |
| 128 × 256 | 8.39 | ~6 |
| 160 × 320 | 16.4 | ~11.5 |

**Это точный прямой решатель** (до ошибок округления `~1e-14` относительных) — итераций нет,
критериев сходимости нет, при `sigma_cond = 0` он даёт машинно-точное решение. В тёмной фазе
(97 % периода) он используется как **окончательный** решатель, без всякого CG.

Мелкая, но важная оптимизация: `Q` плотная, но **соседние моды у оси малы вдали от оси и
наоборот** — обнуление элементов `|Q| < 1e-16` (проверка `if (q===0) continue`) ничего не даёт;
не тратьте на это время. Настоящая оптимизация — **параллелизм**: цикл по `i` (forward) и по `k`
(backward) режется на `worker_threads` по блокам `j` (каждый поток берёт свой диапазон `j`,
SharedArrayBuffer, нулевая синхронизация внутри). Масштабируется практически линейно до
числа физических ядер, см. §5.5.

### 2.6 Поверхностный заряд σ(r) как дельта-источник

σ живёт на z-грани между ячейками `j` (диэлектрик) и `j+1` (газ). Выведем вклад **точно**,
а не «размажем по ячейке».

Полупроводимости половинок ячеек к поверхности:
```
g_d = eps[j]   / (0.5*dz[j])        со стороны диэлектрика
g_g = eps[j+1] / (0.5*dz[j+1])      со стороны газа
```
Пусть `phi_s` — потенциал поверхности. Индукции (`D_z = -eps dphi/dz`):
```
D_gas  = -g_g * (phi[j+1] - phi_s)
D_diel = -g_d * (phi_s - phi[j])
```
Условие Гаусса с нормалью из диэлектрика в газ: `D_gas - D_diel = sigma`. Отсюда
```
phi_s = ( sigma + g_g*phi[j+1] + g_d*phi[j] ) / (g_g + g_d)
```
Подставляя обратно и обозначая
```
T = g_g*g_d/(g_g+g_d)  = epsF[j+1/2]/hz[j+1]        (то же гармоническое среднее!)
w_g = g_g/(g_g+g_d) ,   w_d = g_d/(g_g+g_d) ,       w_g + w_d = 1
```
получаем
```
D_gas  = -T*(phi[j+1]-phi[j]) + w_g*sigma
D_diel = -T*(phi[j+1]-phi[j]) - w_d*sigma
```
(проверка: `D_gas - D_diel = (w_g+w_d)*sigma = sigma` — условие Гаусса выполняется
**тождественно**, а не приближённо. Это гарантирует машинно-точное сохранение поверхностного
заряда в связке «поток на стенку → σ → поле».)

Подставляя в баланс ячеек, получаем **окончательную формулу для правой части** — ровно то,
что просило ТЗ, «дельта-источник, делённый на dz ячейки»:

```
rho_eff[i][j]   += w_d * sigma[i] / dz[j]        // ячейка ДИЭЛЕКТРИКА
rho_eff[i][j+1] += w_g * sigma[i] / dz[j+1]      // ячейка ГАЗА
```
(в «неподелённой» форме матрицы: `rhs[i][j] -= w_d*sigma[i]*Acell[i]`,
`rhs[i][j+1] -= w_g*sigma[i]*Acell[i]`.)

> **Ловушка, которая испортит физику, если её не заметить.** Соблазнительно положить весь σ
> в газовую ячейку (`w_g = 1`). Это **грубо неверно**: при `dz[j] ≈ dz[j+1] ≈ 2 мкм` и
> `eps_r = 9` имеем `g_d/g_g = 9`, то есть `w_d = 0.9`, `w_g = 0.1`. **90 % источника уходит
> в ячейку диэлектрика.** Ошибка в 10 раз в локальном поле у поверхности — это ошибка в
> ширине катодного слоя, в напряжении зажигания и, следовательно, в фигуре Лиссажу.

Для верхней поверхности (`j = JG1` газ, `j+1 = JS_HI` диэлектрик) знак нормали
противоположен, формулы зеркальны: `w` считается так же, а `sigma_hi` входит с
противоположным знаком относительно ориентации `+z`. Практично: определять σ **всегда** как
«физический заряд на поверхности» и в сборке использовать локальную нормаль, направленную
из диэлектрика в газ:
```
lower surface: normal = +z  -> rho_eff[JS_LO] += w_d*sigLo/dz[JS_LO];  rho_eff[JG0] += w_g*sigLo/dz[JG0]
upper surface: normal = -z  -> rho_eff[JS_HI] += w_d*sigHi/dz[JS_HI];  rho_eff[JG1] += w_g*sigHi/dz[JG1]
```
(веса `w` вычисляются по своим `dz` и `eps` в каждом случае; знак σ один и тот же, потому
что «дельта-заряд» — скаляр, а не поток. Симметрия правильная: положительный σ на любой
поверхности одинаково притягивает электроны.)

Никаких изменений в структуре матрицы это не вносит — только правая часть. **Разделимый
решатель работает с σ без модификаций.** ✔

### 2.7 (Справочно) точное исключение барьеров через DtN

Если когда-нибудь понадобится урезать `nz` на 32 строки: слой толщины `d`, ε_d, с Неймана
по бокам и Дирихле `U_el` на металле имеет **точное** отображение Дирихле→Нейман, диагональное
в базисе `Q`:
```
kappa_k = sqrt(-lambda[k])            (lambda[k] <= 0)
D_z(surface, mode k) = eps_d * kappa_k * [ phi_s,k * coth(kappa_k*d) - U_el,k / sinh(kappa_k*d) ]
для k=0 (kappa=0): D_z = eps_d * (phi_s,0 - U_el,0) / d      (обычный конденсатор)
```
Это красиво и точно, но **несовместимо с §3**: как только базис `Q` начинает зависеть от
`sigma_cond`, DtN перестаёт быть диагональной. Поэтому в основной схеме барьеры остаются
явными. Формула оставлена здесь как готовый инструмент для отдельного «быстрого
электростатического» режима и как независимый эталон для теста §8.4.

## 3. Полунеявность и нарушение разделимости

### 3.1 Диагноз: почему без полунеявности задача нерешаема

Максвелловское время релаксации `tau_M = eps0/(e*n_e*mu_e)`:

| n_e [м⁻³] | tau_M [с] |
|---|---|
| 1e16 | 1.2e-7 |
| 1e18 | 1.2e-9 |
| 1e20 (пик филамента) | **1.2e-11** ... при mu_e=0.03: **1.8e-14** |

Явная связка «плотности → Пуассон → поле» устойчива только при `dt < 2*tau_M`. В филаменте это
`~1e-14 с`, а импульс тока длится 20–200 нс → **10⁷ шагов на импульс**. Неприемлемо.
Полунеявная схема Вентцека/Хагелаара обязательна.

### 3.2 Схема и её 2D-форма

```
div( eps * grad phi^{n+1} ) = -rho^{n+1},   rho^{n+1} = rho^n - dt*div(J^{n+1})
J^{n+1} ≈ J^* + sigma_cond * (E^{n+1} - E^n)                (линеаризация по полю)
```
⟹
```
div[ (eps + dt*sigma_cond) * grad phi^{n+1} ] = -rho^n + dt*div( J^* + sigma_cond*grad phi^n )
```
Всё как в 1D, но `sigma_cond = sigma_cond(r,z)` — и вот тут **разделимость ломается**:
коэффициент `a(r,z) = eps(z) + dt*sigma_cond(r,z)` больше не функция одного `z`.

Проводимость на грани берётся **согласованно с SG-потоком**, апвиндом по каждому сорту
(как в 1D §4.2):
```
sigmaZ[i][j+1/2] = Σ_s e * mu_s(|E|_face) * n_s[upwind по знаку z_s*Ez_face]
sigmaR[i+1/2][j] = Σ_s e * mu_s(|E|_face) * n_s[upwind по знаку z_s*Er_face]
```
Полная матрица (симметричная, неподелённая):
```
Tz[i][j+1/2] = (epsF[j+1/2] + dt*sigmaZ[i][j+1/2]) * Acell[i] / hz[j+1]
Tr[i+1/2][j] = (eps[j]      + dt*sigmaR[i+1/2][j]) * Ar[i+1][j] / hr[i+1]
rhs[i][j]    = -rho^n*V + (дивергенция известного вектора F) + вклады sigma_surf
F_z[i][j+1/2] = dt*( Jz^*[i][j+1/2] - sigmaZ[i][j+1/2]*Ez^n[i][j+1/2] ) * Acell[i]
F_r[i+1/2][j] = dt*( Jr^*[i+1/2][j] - sigmaR[i+1/2][j]*Er^n[i+1/2][j] ) * Ar[i+1][j]
rhs[i][j] += (F_z[j+1/2] - F_z[j-1/2]) + (F_r[i+1/2] - F_r[i-1/2])
```
Матрица `A` остаётся **симметричной отрицательно определённой** (коэффициенты принадлежат
граням) ⟹ применим **CG**. Это принципиально: несимметричный вариант (GMRES/BiCGStab) стоил
бы вдвое дороже по памяти и был бы хуже предсказуем.

Масштаб проблемы: в филаменте `dt*sigma_cond/eps0 = dt/tau_M` доходит до **100–500**, при этом
за пределами филамента (`r > 150 мкм`) он `~1e-4`. **Радиальный контраст коэффициента — до 10³.**
Это не малая поправка, и делать вид, что она малая, нельзя.

### 3.3 Вариант (б): простая итерация с фиксированной точкой — ПОЧЕМУ НЕТ

```
M * phi^(m+1) = rhs - (A - M) * phi^(m) ,   M — разделимый оператор
```
Матрица итерации `I - M^{-1}A`. Для диффузионного оператора с коэффициентом `a` и
предобуславливателем с коэффициентом `ā` её спектр лежит примерно в
`[1 - max(a/ā), 1 - min(a/ā)]`. Пусть `ā(z)` — радиальное среднее (§3.4, вариант P1).
При филаменте радиусом 50 мкм в ячейке радиуса 500 мкм доля площади 1 %, поэтому
`ā ≈ eps0*(1 + 0.01*300) = 4*eps0`, а на оси `a = 300*eps0` ⟹ `a/ā = 75` ⟹
собственное значение `1 - 75 = -74`. **Спектральный радиус 74 — итерация расходится
взрывообразно.** Демпфирование (`phi ← phi + omega*(...)`, `omega < 2/75`) сходимость
восстанавливает, но со скоростью `1 - 2*min/(max+min) ≈ 1 - 0.005` — тысячи итераций.

**Вывод: вариант (б) непригоден при филаментарном режиме.** Он работал бы в чисто таунсендовском
(радиально однородном) режиме, где контраста нет, — но именно ради филамента и делается 2D.
Оставить его как fallback тоже нельзя: он не «медленнее», он **расходится**.
Единственное осмысленное применение фиксированной точки — 1–2 итерации на **нелинейности**
(пересчёт `sigma_cond` по новому полю), это другая, безобидная петля, см. §3.7.

### 3.4 Вариант (а): PCG с разделимым предобуславливателем — РЕКОМЕНДУЕТСЯ

CG применяется к `(-A) x = b` (SPD). Предобуславливатель `M` **обязан быть SPD**.

#### Выбор разделимого коэффициента для M

Обозначим `a(r,z) = eps(z) + dt*sigma_cond(r,z)`. Нужно `a_sep(r,z) = ar(r)*az(z)`.

**Ключевое наблюдение, которое определяет весь выбор:** в барьерах `sigma_cond ≡ 0`, то есть
`a = eps_d` **точно и радиально однородно**. Любой предобуславливатель с нетривиальным `ar(r)`
внесёт в барьер фиктивную радиальную неоднородность ε — а барьер это последовательная ёмкость,
которая напрямую задаёт напряжение на зазоре. Контраст ×20 в барьере — это ×20 в эффективной
`C_d(r)`, то есть предобуславливатель, качественно врущий про главную физику ячейки.

**Поэтому: `ar(r) ≡ 1`, вся структура уходит в `az(z)`.**
```
az(z) = eps(z) + dt * <sigma_cond>_A (z) ,
<sigma_cond>_A (z) = ( Σ_i sigmaZ[i][j+1/2] * Acell[i] ) / (pi*R^2)     — взвешенное по площади
```
Свойства:
- в барьере `<sigma_cond> = 0` ⟹ `az = eps_d` **точно**. Предобуславливатель в барьере
  **точен**, ошибки нет вообще. ✔
- в газе `az(z)` воспроизводит **осевую** структуру проводимости (катодный слой, канал,
  анодная область) точно — а это как раз то, что определяет форму решения по z.
- остаётся радиальный контраст — его и должен убрать CG.

Обозначим этот разделимый решатель `S1`. При `dt*sigma = 0` он совпадает с чистым
электростатическим `S0` из §2.5.

Многослойный (rank-1 в логарифме) вариант `ar(r)·az(z)` с подгонкой по SVD `log a` **был
рассмотрен и отвергнут** ровно по причине выше — он ломает барьер. Записано, чтобы не
переизобретали.

#### Двухуровневый предобуславливатель: S1 + z-линейный блок-Якоби

Одного `S1` мало (см. оценку итераций ниже). Добавляем **второй уровень**, который стоит
почти ничего и бьёт именно в то место, где `S1` ошибается.

Заметим: проводимость в ДБР **преимущественно осевая** (E почти вдоль z, дрейф вдоль z).
Значит ошибка `S1` — это ошибка в осевом переносе тока в тех радиусах, где `sigma` отличается
от среднего. Такую ошибку идеально гасит **z-линейная блок-Якоби релаксация с ИСТИННЫМИ
коэффициентами**: для каждого `i` решается трёхдиагональная система по `j`, где диагональные
блоки `A_ii` берутся из настоящей матрицы `A` (включая вклады r-граней в диагональ).

- `B = blockdiag(A_ii)^{-1}` — **SPD** (диагональные блоки симметричной SPD-матрицы, к тому же
  диагонально доминирующие M-матрицы) ⟹ годится для CG. ✔
- Стоимость: `nr` прогонок длины `nz` = `8*nr*nz = 172 кфлоп` ≈ **0.1 мс**, то есть **3 %**
  от стоимости `S1`. Факторизации кэшируются между итерациями CG (внутри шага `A` не меняется).

Симметричная мультипликативная комбинация (обязательно симметричная, иначе CG невалиден):
```
function applyM(b):            // возвращает x ≈ A^{-1} b, M SPD
  x = B(b)                     // z-линейная релаксация (дёшево)
  r = b - A*x                  // 1 matvec, ~10 флоп/ячейка = 0.2 Мфлоп
  x = x + S1(r)                // разделимый прямой решатель (дорого, ~3 мс)
  r = b - A*x                  // 1 matvec
  x = x + B(r)                 // z-линейная релаксация
  return x
```
Это классический симметричный двухуровневый (multiplicative) предобуславливатель: `B` играет
роль сглаживателя, `S1` — роль «грубой сетки»/глобального решателя. `M` симметрична по
построению (композиция вида `B + S1 - S1 A B - B A S1 + B A S1 A B` — симметричная). Стоимость
одного применения ≈ `S1` + 5 %.

#### Тёплый старт — второй по важности приём после самого предобуславливателя

Между шагами `dt ~ 3 пс` поле меняется на доли процента. Стартуем CG не с нуля, а с
**экстраполяции**:
```
phi_guess = 2*phi^n - phi^{n-1}        (линейная экстраполяция по времени)
```
Начальная невязка при этом уже на 2–4 порядка меньше `||b||`. Критерий остановки —
**абсолютный**, привязанный к физике, а не к `||b||`:
```
stop when  ||r||_2 <= tol_abs,   tol_abs выбирается так, чтобы ошибка поля
                                 была < 1e-4 * max|E| (в 10^3 раз ниже других ошибок схемы)
практично:  tol_abs = 1e-4 * eps0 * maxE_prev * (pi*R^2) / sqrt(nr*nz) — пересчитывается раз в 100 шагов
```

#### Ожидаемое число итераций и что делать, если их много

| Режим | контраст `a/ā` по r | ожидаемое число применений `M` |
|---|---|---|
| Тёмная фаза (`sigma≈0`) | 1 | **0** (S1 = точный решатель, CG не запускается вовсе) |
| Таунсендовский / предпробой | 1–3 | 1 |
| Растущий филамент | 10–100 | 2–4 |
| Пик тока | 100–1000 | 3–8 |

**Управление**: считаем `nCG` (число применений `M`) каждый шаг, ведём скользящее среднее.
Правило `dt`-контроллера (см. §5.4) — минимизировать **стоимость единицы физического времени**
`(nCG + c0)/dt`, где `c0 ≈ 1.5` — стоимость всего остального в единицах `S1`. Это самобалансирующий
регулятор: контраст пропорционален `dt`, значит уменьшение `dt` уменьшает `nCG`; контроллер сам
находит оптимум. Жёсткие предохранители:
```
if (nCG > 20) { откатить шаг; dt *= 0.5; повторить; }
if (nCG == 0 && sigma_max*dt/eps0 > 1) — ошибка в сборке sigma_cond, ассерт
hard cap:  dt <= 1000 * tau_M_min      // не для устойчивости, а как детектор аномалий
```

### 3.5 Почему это не сделает решатель бесполезно медленным — числа

Средняя стоимость Пуассона за период (профиль `default`, `nr=96,nz=224`, `S1 = 3 мс`):

| Фаза | доля шагов | ⟨применений M⟩ | мс/шаг на Пуассон |
|---|---|---|---|
| Тёмная | 3 % (по шагам) | 1.0 (просто `S1`) | 3 |
| Предпробой | 6 % | 1.3 | 4 |
| Филамент | 80 % | 2.5 | 7.5 |
| Спад | 11 % | 1.5 | 4.5 |
| **Средневзвешенно** | | **2.3** | **6.8** |

### 3.6 Полунеявность на границе газ/диэлектрик

Как и в 1D: линеаризация пристеночного потока по полю добавляет проводимость к грани,
примыкающей к поверхности. Практически — в §2.6 подставляем
```
g_g -> g_g + dt * sigma_wall[i] * 2/dz[JG0]     ... эквивалентно:
epsF[surface] -> epsF[surface] + dt*sigmaZ[i][surface]
```
где `sigmaZ[i][surface] = Σ_s e*mu_s*n_s,wall` считается по тому же апвинду. Веса `w_g, w_d`
**пересчитываются с этими же изменёнными `g`** — иначе нарушится тождество `w_g+w_d=1` в
дискретном смысле и σ перестанет сохраняться. Без этого схема снова становится жёсткой
именно в момент зарядки поверхности, то есть в самый интересный момент.

### 3.7 Внешняя нелинейная петля (опционально)

`sigma_cond` и `J^*` посчитаны по старому полю. Строго говоря, надо бы пересчитать их по
новому. Практика 1D и литературы: **одна итерация достаточна**, потому что ошибка входит как
`O(dt²·d sigma/dt)`. Если очень хочется — 1 дополнительная итерация Пикара **по нелинейности**
(не по разделимости!) со сходимостью, потому что здесь оператор фиксирован, а меняется только
`sigma`. Рекомендация: **не делать**, вместо этого держать `dt_field` (§5.1). Проверить один
раз на `accurate`-прогоне, что разница < 1 %.

<a name="4"></a>
## 4. Потоки: 2D Шарфеттер–Гуммель в цилиндре

### 4.1 Поля на гранях

```
Ez[i][j+1/2] = -(phi[i][j+1] - phi[i][j]) / hz[j+1]         (i=0..nr-1, j=0..nz-2)
Er[i+1/2][j] = -(phi[i+1][j] - phi[i][j]) / hr[i+1]         (i=0..nr-2)
Er[-1/2][j]  = 0   (ось, тождественно)
Er[nr-1/2][j]= 0   (зеркальная стенка)
```
На металлических гранях `Ez` считается через `phi_metal` (`U(t)` или 0) и полурасстояние
`0.5*dz[0]`.

**Модуль поля на грани — с поперечной компонентой.** Это не педантизм: в головке филамента
`|Er|` сравним с `|Ez|`, и LFA-коэффициенты (α, μ_e, D_e) зависят от `|E|`, а не от компоненты.

```
на z-грани (i, j+1/2):
   Er_at = 0.25*( Er[i-1/2][j] + Er[i+1/2][j] + Er[i-1/2][j+1] + Er[i+1/2][j+1] )
   Emag  = Math.hypot(Ez[i][j+1/2], Er_at)

на r-грани (i+1/2, j):
   Ez_at = 0.25*( Ez[i][j-1/2] + Ez[i][j+1/2] + Ez[i+1][j-1/2] + Ez[i+1][j+1/2] )
   Emag  = Math.hypot(Er[i+1/2][j], Ez_at)
```
Таблицы LFA (`muN, DN, alphaN, etaN2, etaN3`, PHYSICS.md §3) читаются **по `Emag/N` на грани**,
а не по среднему из ячеек. Причина стандартная: SG выведен для постоянных `v` и `D` на отрезке
между центрами; «постоянное» значение обязано быть значением **на грани**, иначе схема теряет
точность там, где поле меняется быстрее всего — в катодном слое и в головке.

Дрейфовая скорость в SG использует **нормальную к грани компоненту** (со знаком), а не модуль:
```
vz = z_s * mu_s(Emag) * Ez[i][j+1/2]
vr = z_s * mu_s(Emag) * Er[i+1/2][j]
```
Это правильная факторизация: подвижность — скаляр, зависящий от `|E|` (LFA), поток по грани —
проекция дрейфа на нормаль.

Для источников в ячейке:
```
Ez_c[i][j] = 0.5*(Ez[i][j-1/2] + Ez[i][j+1/2]);  Er_c[i][j] = 0.5*(Er[i-1/2][j] + Er[i+1/2][j])
Emag_c     = Math.hypot(Ez_c, Er_c)
```

### 4.2 Функция Бернулли

`B(x) = x/(exp(x)-1)`, `B(0)=1`. Требования ТЗ: ряд Тейлора при малом аргументе, ограничение
аргумента `exp` сверху/снизу.

```js
// B(x) = x / (exp(x) - 1) — устойчиво на всей вещественной оси
function bern(x) {
  if (x >  40) return x * Math.exp(-x);           // exp(-40)=4e-18: гарантированно без overflow
  if (x < -40) return -x;                         // exp(x)->0  =>  x/(0-1) = -x
  if (Math.abs(x) < 1e-4) {                       // ряд Тейлора, как просит ТЗ
    // B(x) = 1 - x/2 + x^2/12 - x^4/720 + ...
    return 1 - 0.5*x + x*x/12;                    // отн. ошибка < 1e-17 при |x|<1e-4
  }
  return x / Math.expm1(x);                       // expm1 — точен при малом x, нет катастроф. сокращения
}
```
Разбор порогов:
- `±40`: `exp(40) = 2.4e17` — до `Number.MAX_VALUE` (1.8e308) далеко, но при `x>709`
  был бы `Infinity`, а при `x>40` результат уже неотличим от асимптотики в двойной точности.
  То есть порог 40 — не «страховка от overflow», а **точная асимптотика**; заодно он и
  устраняет overflow полностью.
- `1e-4`: наивное `x/(exp(x)-1)` при `x~1e-8` теряет ~8 значащих цифр (вычитание близких чисел).
  С `Math.expm1` этой потери нет, поэтому строго формально ветка Тейлора не обязательна —
  но она **быстрее** (`expm1` ~15–25 нс против 3 умножений) и убирает зависимость от качества
  реализации `expm1` в конкретной версии V8. Оставляем.

Тождество `B(-x) = B(x) + x` — один `expm1` на грань на сорт вместо двух:
```js
const bp = bern(X), bm = bp + X;
```

### 4.3 Потоки и консервативное обновление

**z-грань `(i, j+1/2)`** (поток на единицу площади, [м⁻²с⁻¹]):
```
h  = hz[j+1]
X  = vz * h / D                      (сеточное число Пекле)
Gz[i][j+1/2] = (D/h) * ( n[i][j]*B(-X) - n[i][j+1]*B(X) )
```
**r-грань `(i+1/2, j)`**:
```
h  = hr[i+1]
X  = vr * h / D
Gr[i+1/2][j] = (D/h) * ( n[i][j]*B(-X) - n[i+1][j]*B(X) )
```
**Цилиндрическая метрика не входит в саму формулу потока** — и это правильно: SG выводится
для 1D задачи вдоль нормали к грани, а кривизна учитывается в **площади грани** при сборке
дивергенции. Попытка «встроить 1/r в SG» — распространённая ошибка; она нарушает
консервативность.

**Консервативное обновление** (`Gr[0][j] ≡ 0` на оси автоматически, потому что `cr_in[0]=0`):
```
n[i][j]^{n+1} = n[i][j]^n
   - dt * ( Gz[i][j+1/2] - Gz[i][j-1/2] ) / dz[j]
   - dt * ( cr_out[i]*Gr[i+1/2][j] - cr_in[i]*Gr[i-1/2][j] )
   + dt * S[i][j]

cr_out[i] = 2*rf[i+1]/(rf[i+1]^2 - rf[i]^2)
cr_in [i] = 2*rf[i]  /(rf[i+1]^2 - rf[i]^2),   cr_in[0] = 0
```
Проверка на константном потоке `Gr ≡ G`: `cr_out - cr_in = 2(rf[i+1]-rf[i])/(rf[i+1]²-rf[i]²)
= 2/(rf[i+1]+rf[i])` → `-G*2/(2*rc) = -G/rc` = дискретный аналог `-(1/r)d(rG)/dr` при `G=const`
даёт `-G/r`. ✔ Метрика правильная.

**Предел `D → 0` (все ионы в сильном поле, нейтралы)** — как в 1D:
```js
if (D < 1e-30 || Math.abs(X) > 40) {
  G = (v > 0) ? v * n_here : v * n_there;      // чистый апвинд = точный предел SG
} else {
  const bp = bern(X), bm = bp + X;
  G = (D/h) * (n_here*bm - n_there*bp);
}
```
Для электронов в активной фазе `|X| ~ 10..100` — ветка апвинда срабатывает часто, что экономит
`expm1`. Для ионов `X ~ 50..500` — почти всегда апвинд.

### 4.4 Коррекция потоков по новому полю (сохранение заряда)

После решения полунеявного Пуассона **обязательно** (иначе `div(eps E) ≠ rho` дрейфует):
```
Gz[i][j+1/2] += z_s * mu_s * n_s[upwind] * ( Ez^{n+1}[i][j+1/2] - Ez^n[i][j+1/2] )
Gr[i+1/2][j] += z_s * mu_s * n_s[upwind] * ( Er^{n+1}[i+1/2][j] - Er^n[i+1/2][j] )
```
Это ровно та линеаризация, которая заложена в `sigma_cond`, поэтому схема **машинно
согласована**: `Σ_s q_s div(Gamma_s)` в точности равно изменению `rho`, «зашитому» в
уравнение Пуассона. Невязка Пуассона держится на уровне `1e-12` относительных за 10⁵ шагов.
В 2D это критичнее, чем в 1D: рассогласование сначала проявляется как **паразитный радиальный
дрейф заряда** и портит форму филамента раньше, чем интегральные величины.

### 4.5 Диффузия электронов по z — неявно

`D_e ≈ 0.15 м²/с`, `dz_min = 2 мкм` ⟹ `dt_diff,z = 0.4*dz²/(2D) = 5.3e-12 с` — сопоставимо
или жёстче дрейфового CFL. По r при `dr_min = 2.13 мкм` — `dt_diff,r = 6.0e-12`.

**Решение: опция полностью неявного z-транспорта электронов** (`I + dt*A_SG,z`, трёхдиагональная
по `j` для каждого `i`, M-матрица ⟹ положительность гарантирована). Это та же машинерия, что
z-линейный блок-Якоби из §3.4 — код переиспользуется. Включать по условию
`dt_diff,z < 0.5*dt_drift`. Радиальную диффузию оставляем явной (она мягче и её неявность
разрушила бы трёхдиагональность в удобном направлении).

В профиле `default` рекомендуется **включать** (снимает и z-CFL, и z-диффузионный лимит →
`dt` определяется радиальным CFL, шагов в 3–5 раз меньше). Обязательна валидация против
явного варианта на коротком прогоне (§8.6): расхождение по пиковому току < 3 %.

## 5. Шаг по времени и бюджет производительности

### 5.1 Ограничители

```
// дрейфовый CFL — ПРАВИЛЬНАЯ 2D-форма (сумма, а не минимум!)
dt_drift = CFL / max_{i,j,s} ( |vz_{s}|/dz[j] + |vr_{s}|/dr[i] )        CFL = 0.4

// диффузионный (только если соответствующее направление явное)
dt_diff  = 0.4 / max_{i,j,s} ( 2*D_s/dz[j]^2 + 2*D_s/dr[i]^2 )

// реакционный (точность лавины, ТЗ: dt < 0.2/(alpha*|v_e|))
dt_reac  = 0.2 / max_{i,j} |nu_net| ,   nu_net = (alpha - eta2 - eta3*N)*|v_e|

// точность поля
dt_field = dE_tol * max|E| / max|dE/dt| ,      dE_tol = 0.02 (default), 0.05 (demo), 0.01 (accurate)

// поверхностный заряд
dt_surf  = 0.05 * (max|sigma| + sigma_ref) / max|dsigma/dt| ,   sigma_ref = 1e-6 Кл/м²

// релаксационный — НЕ ограничитель, а детектор аномалий
dt_relax = 1000 * min tau_M

dt = min(всё выше);  dt = min(dt, 1.25*dt_prev);  dt = clamp(dt, 1e-14, 2e-8)
```

**Про 2D CFL.** Использовать `min(dz/|vz|, dr/|vr|)` — ошибка: при диагональном движении
(головка филамента идёт по z и расширяется по r) устойчивая граница определяется **суммой**
`|vz|/dz + |vr|/dr`, а не минимумом. Разница до √2 в 2D и до 2 в углах — достаточно, чтобы
получить неустойчивость ровно в интересной точке.

### 5.2 До какой степени полунеявность снимает релаксационное ограничение — честно

В чисто релаксационном пределе (однородная плазма, нет источников, нет градиентов) схема §3.2
сводится к
```
E^{n+1} = E^n * eps/(eps + dt*sigma) = E^n / (1 + dt/tau_M)
```
Это **L-устойчивая** аппроксимация точного `exp(-dt/tau_M)`: при `dt >> tau_M` поле корректно
уходит в ноль (а не осциллирует и не взрывается, как явное `E^n(1-dt/tau_M)`).
**Ограничение по устойчивости снято полностью и безусловно.**

Что при этом **не** снято, и это надо назвать прямо:
1. **Точность релаксационного переходника — первый порядок.** `1/(1+x)` vs `exp(-x)`: при
   `x=1` ошибка 36 %, при `x=10` — форма спада неверна, но асимптотика верна. Мы **не
   разрешаем** релаксацию как процесс, мы её проглатываем. Это допустимо, потому что
   релаксация — не наблюдаемая величина: наблюдаемые (ток, заряд, свечение) живут на
   масштабе 1–100 нс, а `tau_M ~ 1e-14..1e-11`.
2. **Линеаризация `J ≈ J* + sigma(E^{n+1}-E^n)` предполагает `mu = const` за шаг.** В головке
   филамента `mu_e(E)` меняется на десятки процентов за наносекунду. Ограничитель — `dt_field`
   с `dE_tol = 0.02`. Это и есть настоящее (точностное) ограничение, пришедшее на смену
   устойчивостному.
3. **Связка лавина ↔ поле.** Экспоненциальный интегратор снимает жёсткость источников,
   но `dt_reac = 0.2/nu_net` остаётся как **точностное** ограничение: за шаг лавина не должна
   вырасти больше, чем на 22 %, иначе обратное влияние на поле считается по устаревшему полю.
4. **Обусловленность CG растёт как `dt`.** Формально устойчивость есть при любом `dt`, но
   стоимость шага растёт. Это и берёт на себя контроллер §5.4.

Итог: `dt_relax` держим с коэффициентом 1000 — **не для устойчивости, а как ассерт**.
Его срабатывание означает баг в `sigma_cond` (обычно — забытый апвинд или потерянный сорт).

### 5.3 Стратегия «тёмная фаза / филамент»

Тёмная фаза (`max n_e < 1e14 м⁻³`) занимает ~97 % **времени** периода, но должна занимать
считанные проценты **шагов**.
```
if (max n_e < N_DARK) {
   sigma_cond ≈ 0  ->  Пуассон = ОДИН вызов S1 (точный прямой решатель, без CG)
   активны только dt_field и dt_drift по ионам  ->  dt растёт до DT_MAX = 2e-8
   транспорт электронов подшагивается раз в K=10 шагов (их всё равно почти нет)
}
```
**Детектор выхода из тёмной фазы — до взрыва, а не после:**
```
if ( max_{i,j}( nu_net[i][j] ) * dt > 0.05  ||  max n_e > N_DARK ) {
    dt = 1e-12; включить полный солвер; сбросить историю экстраполяции phi
}
```
Запас по фазе — около 1 мкс физического времени до пробоя, с избытком.

Дополнительно в 2D: **радиальная локализация не даёт экономии** (сетка тензорная, шаг общий),
поэтому не пытайтесь «считать только филамент» — это разрушит и разделимость, и консервативность.

### 5.4 Контроллер dt, оптимизирующий стоимость

```js
// стоимость шага в единицах S1-вызова:  cost = nCG + c0 ,  c0 ≈ 1.5 (транспорт+химия+сборка)
// цель — минимум cost/dt
let dtNew = Math.min(dtDrift, dtDiff, dtReac, dtField, dtSurf);
// адаптация по цене: если предыдущий шаг стоил дорого, попробовать дешевле
if (nCGavg > 6) dtNew = Math.min(dtNew, 0.7 * dt);
else if (nCGavg < 2 && dtLimiter === 'none') dtNew = Math.min(dtNew, 1.25 * dt);
dtNew = Math.min(dtNew, 1.25 * dt);
dt = clamp(dtNew, 1e-14, 2e-8);
// квантование к лестнице 2^{-m/4}: позволяет переиспользовать LU-факторизации (★★) между шагами
dt = DT_REF * Math.pow(2, Math.round(Math.log2(dt/DT_REF) * 4) / 4);
```
Квантование `dt` к лестнице `2^{1/4}` — приём, который стоит одну строчку и позволяет держать
кэш LU-факторизаций всех `nr` мод (`3*nr*nz` чисел, 0.5 МБ) валидным на десятки шагов подряд.
Выигрыш скромный (прогонки — 5 % стоимости `S1`), но бесплатный.

**Отбраковка шага** (теневые копии массивов; в 2D это 9 сортов × 21504 ячеек × 8 Б = 1.5 МБ,
копирование ~0.3 мс — приемлемо, делать через двойной буфер, не через `slice()`):
```
- min n_s < -1e-6 * max n_s
- max|E^{n+1}-E^n| / max|E| > 3*dE_tol
- относительная невязка Пуассона > 1e-8
- nCG > 20
=> откат, dt *= 0.4, повтор. Норма — <0.5 % шагов.
```

<a name="6"></a>
## 6. Границы газ/диэлектрик, γ-эмиссия, σ(r)

Всё, что ниже, применяется **на каждом радиусе `i` независимо** — это и есть главное
2D-отличие: σ, γ-эмиссия и катодный слой становятся функциями `r`.

### 6.1 Потоки на стенку

Для нижней поверхности (грань между `JS_LO` и `JG0`, нормаль наружу из газа = `-z`);
`E_w = Ez` на этой грани, взятое **из решения Пуассона**, то есть уже содержащее вклад σ.

```js
// для каждого i = 0..nr-1
const vth_e = Math.sqrt(8*QE*(2/3)*epsMean_i/(Math.PI*ME));      // ~1.1e6 м/с при 3 эВ
const vth_s = Math.sqrt(8*KB*T/(Math.PI*m_s));                   // ~4.4e2 м/с для O2+

// положительные ионы (дрейф к стенке, если z_s*E_w направлен в стенку)
Gamma_pos_s = a_s * Math.abs(mu_s*E_w) * n_s_wall + 0.25*vth_s*n_s_wall;   a_s ∈ {0,1}
Gamma_pos   = Σ_{s ∈ {O2+, O4+}} Gamma_pos_s

// электроны: дрейф + тепловой сток МИНУС вторичная эмиссия
Gamma_e     = a_e * Math.abs(mu_e*E_w) * n_e_wall + 0.25*vth_e*n_e_wall - gamma*Gamma_pos

// отрицательные ионы: аналогично положительным, но со своим знаком дрейфа
Gamma_neg   = Σ_{s ∈ {O-, O2-, O3-}} ( a_s*Math.abs(mu_s*E_w)*n_s_wall + 0.25*vth_s*n_s_wall )
```
`a_s = 1`, если дрейфовая скорость `z_s*mu_s*E_w` направлена **в стенку**, иначе `a_s = 0`
(тогда наружу уходит только тепловая половина). `gamma = 0.02` по умолчанию (PHYSICS.md §4.1),
она уже включает фотоэмиссию и метастабиль-индуцированную эмиссию — **отдельного члена
фотоэмиссии не добавлять**.

Реализация в FV: на пристеночной z-грани **поток задаётся напрямую**, SG там не применяется
(его вывод предполагает две ячейки, а тут ячейка и стенка). Эмитированные электроны входят
как отрицательный (внутрь газа) поток в ту же грань — не как объёмный источник в первой ячейке.
Разница физически заметна: объёмный источник размазал бы эмиссию по 2 мкм и слегка сместил
начало катодного слоя.

`n_s_wall` — значение в примыкающей газовой ячейке (`j = JG0` или `JG1`). Экстраполяция
первого порядка; при `dz_min = 2 мкм` и толщине слоя 10–30 мкм ошибка < 10 % и не влияет
на интегральные величины. Для `accurate` можно взять SG-экстраполяцию к грани.

### 6.2 Накопление σ(r)

```
dSigLo[i]/dt = e * ( Gamma_pos[i] - Gamma_e[i] - Gamma_neg[i] )      [Кл/м²/с]
dSigHi[i]/dt = то же на верхней поверхности
```
Интегрируем тем же шагом `dt`, что и плотности; `Gamma_e` уже содержит вычтенную γ-эмиссию,
поэтому эмитированный заряд правильно увеличивает σ (уход электрона из диэлектрика = +заряд).

**Знак и ориентация.** Определяем σ как физическую плотность заряда, осевшего на поверхности,
без привязки к нормали. В §2.6 она входит в `rho_eff` с плюсом на обеих поверхностях.
Проверка: положительный σ на нижней поверхности ⟹ поле в зазоре направлено от неё вверх ⟹
тормозит следующий поток положительных ионов туда же. ✔

### 6.3 Поверхностной проводимостью пренебрегаем — обоснование числами

**Растекание вдоль поверхности.** Поверхностный заряд с плотностью σ на диэлектрике толщиной
`d1` над металлом растекается диффузионно с коэффициентом
```
D_s = G_s / C_s' ,     C_s' = eps0*eps_r/d1 = 8.854e-12*9/5e-4 = 1.594e-7 Ф/м²
```
`G_s` — поверхностная проводимость [См/□]. Для сухого Al₂O₃ в чистом O₂ `G_s ~ 1e-16..1e-14 См/□`
(на воздухе с влажностью бывает до 1e-12, но у нас чистый O₂ и нет адсорбированной воды).
При `G_s = 1e-14`:
```
D_s = 1e-14/1.594e-7 = 6.3e-8 м²/с
время растекания на масштаб филамента L = 100 мкм:  L²/D_s = 1e-8/6.3e-8 = 0.16 с
```
против полупериода `50 мкс` — **разница в 3200 раз** (при `G_s = 1e-16` — в 3.2e5 раз).

**Утечка сквозь барьер.** Объёмное сопротивление Al₂O₃ `rho_v ~ 1e14 Ом·м`:
```
tau_leak = rho_v * eps0 * eps_r = 1e14 * 8.854e-12 * 9 = 8.0e3 с
```
— восемь часов против 50 мкс.

**Вывод: и поверхностная, и объёмная проводимость диэлектрика пренебрежимы на масштабе
периода.** Радиальное «растекание поверхностного заряда», которое мы увидим в 2D, — это
**не** проводимость поверхности, а **растекание самого разряда**: катодное пятно расширяется,
потому что там, где σ уже накопился, локальное поле подавлено, и разряд смещается наружу.
Это — реальный физический механизм и главный 2D-эффект, ради которого делается модель.
Смешивать его с проводимостью нельзя.

**Опция**: `sigma_leak_tau` (по умолчанию `Infinity`, диапазон 1 мс … 1 с) — экспоненциальный
сток `dσ/dt -= σ/tau_leak`, применяемый локально по `r`. Полезен, чтобы фигура Лиссажу
замыкалась при очень длинных прогонах. По умолчанию **выключен**, чтобы не подмешивать
нефизичный механизм в валидацию V4/V5.

### 6.4 Нейтралы на стенке

`Gamma = 0.25 * gamma_stick * v_th * n` с `gamma_O = 2e-3`, `gamma_O3 = 1e-5`, `gamma_O2a = 3e-4`
(PHYSICS.md §4.3) — на обеих поверхностях, при `r=R` и на оси потока нет (Neumann/симметрия).
Как показано в PHYSICS.md, стеночная гибель O на 3 порядка слабее объёмного образования озона;
она включена ради полноты и не влияет на V10.

## 7. Диагностика: Сато–Морроу в цилиндре, Лиссажу, V1..V12

### 7.1 Весовое (лапласовское) поле в нашей геометрии — оно ТОЧНО одномерно

`E_L` определяется как поле при `phi_L = 1 В` на питаемом электроде, `0` на земле, при
`rho = 0` и `sigma = 0`. Решаем `div(eps grad phi_L) = 0` с Неймана по `r`.

Поскольку `eps = eps(z)` и граничные условия по `r` однородны Неймана, решение **строго
не зависит от `r`**: единственная возбуждённая радиальная мода — `k=0`. Следовательно
```
d_eff = d_gap + (d1 + d2)/eps_r = 1e-3 + 1e-3/9 = 1.11111e-3 м
E_L,z = 1/d_eff        = 900.0 1/м    в газе
E_L,z = 1/(eps_r*d_eff)= 100.0 1/м    в барьерах
E_L,r = 0              ТОЧНО, везде
```
Это не приближение — это точное решение, и его надо **захардкодить** (а не решать численно):
численное решение даст то же самое, но с ошибкой округления, и им же можно проверить код (§8.4).

### 7.2 Формула Сато–Морроу

```
I_cond(t) = (1/U_a) * ∫_V  J_cond(r,z) · E_L(r,z)  dV ,        U_a = 1 В (нормировка E_L)
J_cond = e*( Γ_O2+ + Γ_O4+ - Γ_e - Γ_O- - Γ_O2- - Γ_O3- )      [векторное, А/м²]
dV = 2*pi*r dr dz
```
**Поскольку `E_L,r ≡ 0`, радиальные потоки в ток НЕ ВНОСЯТ ВКЛАДА ВООБЩЕ, а барьеры не вносят
вклада, потому что там `J = 0`.** Формула схлопывается до:

```
I_cond(t) = (1/d_eff) * ∫_{газ} Jz_cond(r,z) * 2*pi*r dr dz
```

Дискретно, по z-граням газа (естественное место, где живут `Gz`):
```
I_cond = (1/d_eff) * Σ_{i=0..nr-1} Σ_{j=JG0-1..JG1}  Jz[i][j+1/2] * Acell[i] * hz[j+1]

Jz[i][j+1/2] = QE * ( Gz_O2p + Gz_O4p - Gz_e - Gz_Om - Gz_O2m - Gz_O3m )[i][j+1/2]
```
`Acell[i]*hz[j+1]` — объём «двойственной» ячейки, привязанной к грани; сумма `hz` по всем
z-граням газа даёт `d_gap` ⟹ квадратура согласована.

**Полный ток и составляющие:**
```
C_cell   = eps0 * (pi*R^2) / d_eff = 8.854e-12 * 7.854e-7 / 1.1111e-3 = 6.259e-15 Ф = 6.26 фФ
I_disp   = C_cell * dU/dt                          (U(t) = U0*sin(2*pi*f*t))
I_total  = I_cond + I_disp
Q(t)     = ∫ I_total dt                            (для фигуры Лиссажу Q–U)
```

### 7.3 Почему Сато–Морроу правильнее, чем dQ/dt

1. **Нет дифференцирования численного решения.** `dQ/dt` требует численного
   дифференцирования заряда на электроде — усиление шума в `1/dt` раз. При `dt ~ 1e-11`
   и относительной точности Пуассона `1e-10` производная получает шум порядка `1e-10/1e-11 = 10`
   относительных единиц. Сато–Морроу даёт ток **алгебраически, из уже посчитанных потоков**,
   без единого деления на `dt`.
2. **Это теорема, а не приближение.** Формула — прямое следствие теоремы взаимности
   (Рамо–Шокли для многоэлектродных систем с диэлектриками). Она даёт **мгновенный
   наведённый ток от каждого движущегося заряда**, включая заряды, которые ещё не долетели
   до электрода. `dQ/dt` по определению видит только то, что уже пришло.
3. **Чистое разделение кондукционного и смещенческого тока.** У `dQ/dt` они смешаны, и
   выделить `I_cond` для сравнения с V7 (пиковая плотность тока) можно только вычитанием
   двух больших близких чисел.
4. **В 2D — особенно.** Заряд на металле в 2D пришлось бы получать как
   `∫ D_z(r, z=0) 2πr dr` — интеграл от градиента решения по границе, где сетка самая грубая
   (`dz[0] = 121 мкм` в нашей градуировке барьера!). Точность там на порядок хуже, чем в газе.
   Сато–Морроу интегрирует по объёму газа, где сетка густая.
5. **Валидация одного через другое.** Тем не менее `dQ/dt` считаем **тоже**, как независимую
   проверку: `|I_SM - dQ/dt| / max|I| < 2e-3` во всех фазах. Расхождение = баг в сохранении заряда.

`docs/PHYSICS.md §6` даёт 11 пунктов; ниже они пронумерованы V1..V11, V12 добавлен как
2D-специфичный (§8).

**Общая поправка на площадь.** PHYSICS.md считает на `A = 1 см² = 1e-4 м²`. Наша ячейка —
`A_cell = πR² = 7.854e-7 м²`, то есть в **127.3 раза меньше**. Все «электрические» величины
(Q, I, P, C) пересчитываются множителем `127.3`; «плотностные» (σ, j, n, E) — не пересчитываются.

Ёмкости ячейки:
```
C_d    = eps0*eps_r*A_cell/(d1+d2) = 6.259e-14 Ф = 62.6 фФ     (1D: 7.97 пФ / 127.3 ✔)
C_g    = eps0*A_cell/d_gap         = 6.954e-15 Ф = 6.95 фФ
C_cell = C_d*C_g/(C_d+C_g)         = 6.259e-15 Ф = 6.26 фФ
```

| V | Критерий (PHYSICS.md §6) | Как измеряется в 2D |
|---|---|---|
| V1 | α=η при `E/N = 101.3 Тд` | Не из симуляции — юнит-тест на таблицы коэффициентов (общий с 1D). |

## 8. Валидация 2D→1D и программа тестов

Порядок важен: тесты 8.1–8.4 чисто алгебраические, они ловят 90 % ошибок за секунды.
Не переходить к физике, пока они не зелёные.

### 8.1 Метрики и операторы (мгновенно, без физики)

```
T1  Σ_i Acell[i]                       == pi*R^2                    отн. 1e-15
T2  Σ_j dz[j]                          == Lz                        отн. 1e-15
T3  Σ_ij V[i][j]                       == pi*R^2*Lz                 отн. 1e-14
T4  M_r * ones                         == 0                         абс. < 1e-9 * ||M_r||
T5  M_r симметрична                    max|M_r - M_r^T| == 0        точно (по построению)
T6  S = D^{-1/2} M_r D^{-1/2} симметр.                              точно
T7  дивергенция константного потока: подставить Gz≡G, Gr≡0 -> dn/dt == 0  (1e-15)
T8  дивергенция чисто радиального const-потока Gr≡G:  dn/dt == -G/rc[i]   (отн. 1e-12)
```

### 8.2 Собственное разложение

```
T9   ||Q^T Q - I||_inf                 < 1e-12
T10  |lambda[0]| / max|lambda|         < 1e-12                      (нулевая мода на месте)
T11  q_0[i] ∝ sqrt(Acell[i]),  отн. отклонение < 1e-12
T12  все lambda[k] <= 1e-12 * max|lambda|                           (отрицательная полуопредел.)
T13  ||S*Q - Q*diag(lambda)||_inf / ||S||  < 1e-12
T14  lambda монотонно убывают (после сортировки) и lambda[nr-1] ≈ -4/dr_min^2 (±20 %)
```

### 8.3 Пуассон — метод изготовленного решения (MMS)

Взять аналитическую функцию, удовлетворяющую граничным условиям:
```
phi_ex(r,z) = (1 - z/Lz) * U0 * cos(pi*r/R) ... — НЕ подходит: dphi/dr != 0 при r=0? cos'(0)=0 ✔,
                                                  cos'(pi)=0 ✔ -> подходит.
```
Точнее, для проверки скачка ε берём кусочно-заданное `phi_ex` с точным условием сшивки:
```
phi_ex(r,z) = f(z) * g(r),   g(r) = cos(pi*r/R)   (dg/dr = 0 при r=0 и r=R ✔)
f(z) — кусочно-линейная с изломом на границах так, что eps*f' непрерывна (нет sigma)
rho_ex = -[ (eps f')' g + eps f * (1/r)(r g')' ] ,   (1/r)(r g')' = -(pi/R)^2 * (cos + sin/(x)) ...
```
Практичнее — **дискретный MMS**: взять произвольный гладкий `phi_test`, применить к нему
**собранную матрицу** `A`, получить `b = A*phi_test`, решить `S0(b)` и сравнить.
```
T15  ||S0(A*phi_test) - phi_test||_inf / ||phi_test||_inf  < 1e-11
```
Это проверяет решатель точно и без аналитики. Для проверки **аппроксимации** (2-го порядка)
нужен аналитический MMS с измельчением `nr, nz ×2` — ожидаем падение ошибки в 4 раза.
```
T16  порядок сходимости по r и по z: 1.9 .. 2.1
```

### 8.4 Плоские / известные решения

```
T17  rho=0, sigma=0, U=1 В: решение должно совпасть с аналитическим слоистым конденсатором
     phi(z) линейна в каждом слое, E_gas = 900 В/м, E_diel = 100 В/м -> отн. ошибка < 1e-13
     (и E_r == 0 машинно точно -> проверка, что Q не «подмешивает» моды)
T18  sigma = const по r на нижней поверхности, U=0: решение одномерно, сравнить с
     аналитикой слоистого конденсатора с заряженной прослойкой.  Ошибка < 1e-13.
T19  sigma = гауссово пятно по r, U=0: сравнить с независимым решением через DtN (§2.7)
     на той же сетке. Расхождение < 1e-10 -> подтверждает и sigma-веса w_g/w_d, и барьеры.
T20  ЗАКОН ГАУССА: ∮ D·dS по границе всей области == полный заряд (объёмный + поверхностный)
     отн. 1e-13, каждый шаг в рантайме (дёшево: nr+nz операций).
```

### 8.5 ГЛАВНЫЙ ТЕСТ: 2D → 1D (V12)

**Постановка.** Убрать всё, что нарушает радиальную однородность:
```
- затравка: РАВНОМЕРНАЯ по r (гауссово пятно выключено, n_e = n_O2+ = 1e13 м⁻³ везде в газе)
- фоновый источник S_bg — равномерный
- граничные условия по r: Neumann на обоих концах (как всегда)
- всё остальное — штатное (полунеявность, SG, химия, gamma, sigma(r))
```
**Утверждение.** Задача становится строго одномерной. Радиальные потоки должны быть
**тождественно нулевыми** (не «малыми»), радиальные моды `k≥1` — не возбуждаться,
решение обязано совпасть с 1D-кодом.

**Что именно проверяется и почему это ловит всё:**

| Проверка | Порог | Что ломается, если провалено |
|---|---|---|
| `max_ij |f[i][j] - f[0][j]| / max|f|` для `f ∈ {n_e, n_O2+, rho, phi, |E|}` на каждом кадре | **< 1e-12** | Ошибка в `cr_out/cr_in` (метрика), в `Ar[0]=0` (ось), в усреднении `Er` при вычислении `Emag` на z-гранях |
| `max_ij |Er[i][j]|` | **< 1e-12 · max|Ez|** | Матрица Пуассона несимметрична / `Tr` собрана неверно |
| `max_k≥1 |û_k|` (амплитуды ненулевых мод) | **< 1e-12 · |û_0|** | `Q` не ортогональна, или `D^{1/2}`-взвешивание пропущено/лишнее |
| `max_i |sigLo[i] - sigLo[0]|` | **< 1e-12 · |sigLo[0]|** | Ошибка в пристеночных потоках по `r`, или веса `w_g/w_d` зависят от `i` |
| `Σ_i Gr[i+1/2][j]·Ar[i+1][j]` | **== 0** машинно | Ошибка знака в r-потоке |
| Сравнение с 1D-кодом на **той же z-сетке и той же последовательности dt**: `n_e(z,t)`, `phi(z,t)`, `I(t)` | **отн. L2 < 1e-10** | Любое расхождение в SG, источниках, sigma_cond, sigma-весах между двумя реализациями |
| Сравнение интегральных величин (`I`, `Q`, `U_gap`, `P`) с 1D | **отн. < 1e-9** | То же на уровне диагностики; ловит ошибки в Сато–Морроу-квадратуре |

**Почему допуск 1e-12, а не 1e-6.** Радиальная однородность здесь — не приближённое свойство,
а **алгебраическое тождество**: если состояние не зависит от `i`, то `phi[i+1]-phi[i] = 0`,
значит `Er = 0` **точно**, значит `Gr = 0` **точно**, значит источники одинаковы. Любое
отклонение выше уровня округления (`~1e-14`, накопление за 1e5 шагов до `~1e-12`) означает
**баг**, а не «численную погрешность». Это делает тест исключительно чувствительным.

**Практика запуска:** прогонять 1 полный период в профиле `demo` (7 минут) при каждом
изменении кода транспорта/Пуассона; в CI — 200 шагов (10 секунд) с тем же порогом.

**Второй уровень теста — таунсендовский режим.** При равномерной затравке разряд в O₂ при
1 мм / 10 кВ должен пойти в **таунсендовском (диффузном)** режиме, и все критерии V2–V8
должны выполниться с теми же числами, что в 1D. Это уже физическая, а не алгебраическая
проверка, и она подтверждает, что 2D-код воспроизводит уже провалидированную физику.

**Третий уровень — «слабо-2D».** Включить затравочное пятно с очень большой `sigma_r = 400 мкм`
(≫ R = 500 мкм, т.е. почти однородное). Решение должно быть *почти* одномерным:
радиальная неоднородность решения `< 3 %`, интегральные величины отличаются от 1D `< 1 %`.
Это ловит ошибки, которые тождественно зануляются при строгой однородности (например,
неверный, но симметричный вес в усреднении `Er` на z-гранях).

### 8.6 Прочие тесты

```
T21  Сохранение заряда: d/dt(∫rho dV + ∮sigma dS) + (потоки через металлы) == 0,  отн. 1e-12
T22  Положительность: min n_s >= 0 на всех шагах (после клипа — счётчик срабатываний клипа
     должен быть 0 в норме; ненулевой счётчик = сигнал, а не «нормально»)
T23  I_SM  vs  dQ/dt:  |разница| < 2e-3 * max|I|
T24  Неявный z-транспорт vs явный: пиковый I_cond отличается < 3 %, FWHM < 5 %
T25  Сеточная сходимость: default vs accurate — пиковый ток < 10 %, ΔQ < 5 %, r_fil < 15 %
T26  Независимость от затравки: n_e0 ∈ {1e12, 1e13, 1e14} — установившийся цикл (период 3)
     отличается < 2 % по ΔQ и P  (это V-критерий из PHYSICS.md §5)
T27  Симметрия по полупериодам: при симметричной геометрии |ΔQ⁺| == |ΔQ⁻| в пределах 5 %
     в установившемся режиме
```

## 9. Формат вывода кадров

### 9.1 Что пишем

**Поля (2D, квантованные)** — только по газовой части сетки (`nr × ngap = 96 × 192 = 18 432`):

| Поле | Смысл | Квантование | Диапазон |
|---|---|---|---|
| `ne` | плотность электронов, м⁻³ | uint8, **лог** | 6 декад от кадрового max |
| `sion` | скорость ионизации `α·|v_e|·n_e`, м⁻³с⁻¹ — это «свечение» | uint8, **лог** | 5 декад от кадрового max |
| `rho` | объёмный заряд, Кл/м³ (знакопеременный!) | uint8, **asinh** | симметрично |
| `Emag` | \|E\|, В/м | uint8, **линейно** | 0 … кадровый max |

Опционально (флаг `--extra-fields`): `nneg` (сумма отрицательных ионов), `no3`, `phi`.

**Поверхностные ряды (1D по r, каждый кадр)**: `sigLo[nr]`, `sigHi[nr]` — Float32, 384 Б/кадр.
Их квантовать не надо, они крошечные и нужны точными для графиков.

**Скалярные ряды** — §7.4, **каждый шаг, без прореживания**.

### 9.2 Квантование

```js
// ЛОГАРИФМИЧЕСКОЕ (ne, sion) — знакоположительные, огромный динамический диапазон
// на кадр храним vmax и число декад DEC (константа поля)
const vmax = max(field);                       // Float32 в манифесте
const lmax = Math.log10(vmax), lmin = lmax - DEC;
const s = 255 / DEC;
q[k] = v <= 0 ? 0 : Math.max(0, Math.min(255, Math.round((Math.log10(v) - lmin) * s)));
// восстановление: v = (q === 0) ? 0 : 10 ** (lmin + q/s)

// ASINH (rho) — знакопеременное, нужен «линейный около нуля, лог на хвостах»
const vmax = max(|field|), v0 = vmax * 1e-4;   // порог перехода лог->лин
const A = 127 / Math.asinh(vmax / v0);
q[k] = 128 + Math.round(A * Math.asinh(v / v0));            // 1..255, 128 == 0
// восстановление: v = v0 * Math.sinh((q - 128) / A)

// ЛИНЕЙНОЕ (Emag)
q[k] = Math.round(255 * v / vmax);
```
Разрешение при `DEC = 6` и uint8: `6/255 = 0.0235` декады на уровень = **5.6 % на уровень**.
Визуально это гладко (глаз различает ~1 % только на резких границах). Для `accurate`-прогона
и для полей, по которым будут считать числа из кадров, доступен `uint16` (`DEC/65535` =
0.02 % на уровень) — флаг `--q16`, размер ×2.

**Почему покадровая нормировка, а не глобальная.** `n_e` меняется на 8 порядков между тёмной
фазой и пиком. Глобальная нормировка отдала бы тёмной фазе 1–2 уровня из 256 — анимация была бы
чёрной 97 % времени. Покадровая нормировка + отображение `vmax(t)` отдельным графиком в плеере
= видно всё. Плеер обязан показывать кадровую шкалу (см. UI_SPEC.md).

### 9.3 Адаптивная выборка кадров

```js
// эмиттер кадров, вызывается после каждого шага
const DT_FRAME_MIN = 1e-9;      // 1 нс — во время импульса
const DT_FRAME_MAX = 1e-6;      // 1 мкс — между импульсами
function maybeEmitFrame(st) {
  const dtSince = st.t - lastFrameT;
  if (dtSince < DT_FRAME_MIN) return false;
  if (dtSince >= DT_FRAME_MAX) return true;                      // «медленный» тик
  // «интересность»: заметное изменение хоть чего-то
  const dLogNe = Math.abs(Math.log10(st.neMax) - lastLogNe);
  const dI     = Math.abs(st.Icond - lastI) / Math.max(IpeakRun, 1e-12);
  const dU     = Math.abs(st.Ugap - lastUgap) / Math.max(Math.abs(U0), 1);
  return (dLogNe > 0.04) || (dI > 0.02) || (dU > 0.005);
}
```
`IpeakRun` — бегущий максимум `|I_cond|` (обновляется по ходу, чтобы первый импульс тоже
разрешался). Такой критерий автоматически даёт ~1–2 нс шаг на фронте импульса, ~5–20 нс
на спаде, 1 мкс в темноте — ровно то, что просит ТЗ, без ручной привязки к фазам.

Ожидаемо: **~600 кадров на период** (≈ 300 на импульс × 2 + ~100 тёмных).

### 9.4 Контейнер

```
run_<id>/
  manifest.json          — всё описание, включая покадровый индекс
  grid.bin               — rf[nr+1], zf[nz+1] (Float64) — точная сетка для плеера
  fields/ne.bin          — конкатенация кадров: nFrames * (nr*ngap) байт
  fields/sion.bin
  fields/rho.bin
  fields/Emag.bin
  surf/sigLo.bin         — nFrames * nr * 4 (Float32)
  surf/sigHi.bin
  scalars/t.bin          — nSteps * 8 (Float64 — ОБЯЗАТЕЛЬНО, см. ниже)
  scalars/<name>.bin     — nSteps * 4 (Float32), по одному файлу на ряд (SoA)
```
Файл на поле, а не один общий блоб: плеер грузит только то, что показывает
(`fetch` + `Range`-запросы по offset из манифеста), и переключение поля не требует

### 9.5 Размеры — расчёт

**Полный прогон, 3 периода, профиль `default`:**

```
Кадр: 4 поля × 96×192 байт      = 4 × 18 432 = 73 728 Б
    + surf 2 × 96 × 4           =        768 Б
                                = 74 496 Б ≈ 72.8 КиБ / кадр
Кадров: 600/период × 3          = 1 800
Поля+поверхность:  1800 × 74 496 = 134.1 МБ

Скаляры: 91 000 шагов/период × 3 = 273 000 записей
   t (Float64)                    = 2.18 МБ
   18 рядов (Float32)             = 19.7 МБ
                                  = 21.9 МБ

ИТОГО: 156 МБ   <  цель 300 МБ ✔   (запас ×1.9 — хватит на 5-6 периодов или на --extra-fields)
```
С gzip (`zlib.createGzip`, уровень 6) uint8-поля с логарифмической квантизацией жмутся в
**2.2–3×** (соседние пиксели коррелируют), скаляры — в 1.4×. Полный прогон в `.gz`:
**~60 МБ**. Плеер распаковывает через `DecompressionStream('gzip')` (есть во всех
целевых браузерах). Хранить **и** сырое, и `.gz` не нужно — только `.gz`.

**Компактная версия для плеера (`--compact`):**
```
- поля даунсэмплятся 2× по обеим осям: 48 × 96 = 4 608 Б/поле
- кадры прореживаются до ~300/период (порог «интересности» ×2)
- скаляры прореживаются до 20 000/период (ТОЛЬКО в compact! в полном — все)

Кадр: 4 × 4 608 + 2×48×4 = 18 816 Б
Кадров: 300 × 3 = 900      ->  16.9 МБ
Скаляры: 60 000 × (8 + 18×4) = 4.8 МБ
ИТОГО: 21.7 МБ  <  цель 30 МБ ✔    ; в .gz — ~9 МБ
```
Даунсэмплинг делать **до** квантования, площадным усреднением с весом `Acell[i]*dz[j]`
(для `ne`, `rho`, `O3` — консервативно, сохраняя интеграл), для `Emag` и `sion` — тем же
взвешенным средним (они не консервативные величины, но визуально это правильнее максимума).

### 9.6 Запись — практика

- Писать потоком (`fs.createWriteStream`), не накапливать в памяти: полный прогон в RAM — 134 МБ,
  а с Float64-промежуточными буферами вышло бы ×8.
- `manifest.json` пишется **последним**, после `frames[]`, — он же служит маркером «прогон
  завершён». Незавершённый прогон = директория без манифеста, плеер её не покажет.
- Каждые 10 000 шагов писать `checkpoint.bin` (полное состояние, Float64, `9 сортов × 21 504 × 8 Б
  = 1.5 МБ` + σ + phi) — чтобы можно было продолжить расчёт с периода 2, а не с нуля.
  Особенно важно для `accurate`.
- Все параметры прогона + git-SHA `PHYSICS.md` и кода — в манифест. Без этого через неделю
  никто не скажет, чем прогон A отличается от прогона B.

## 10. Сводка решений и порядок реализации

### 10.1 TL;DR решений

| Вопрос | Решение | Главная причина |
|---|---|---|
| Область | газ + оба барьера явными ячейками | в 2D phi в барьере не линеен (радиальная структура σ) |
| Сетка | тензорная, `96 × 224`; r: экспон. к оси; z: 3 блока (геом./tanh/геом.) | тензорность — обязательное условие разделимости |
| Раскладка | `[i*nz + j]`, z contiguous | превращает GEMM в непрерывные axpy, ×3–5 к скорости |
| Центр ячейки | арифметический | сохраняет точную симметризуемость `L_r` |
| Пуассон | **разделимый прямой**: `Q^T` → `nr` прогонок → `Q` | точный, `O(nr²nz)`, ~3 мс при 96×224 |
| Симметризация | `S = D^{-1/2} M_r D^{-1/2}`, `D = diag(Acell)` | `Acell`, НЕ объём (иначе появится `dz[j]`) |
| Нулевая мода | `lambda_0 = 0` не сингулярна | Дирихле по z с обеих сторон |
| σ(r) | `rho_eff += w·σ/dz` в **обе** соседние ячейки, `w_g+w_d=1` | наивное `w_g=1` ошибается в 10 раз (eps_r=9) |
| Полунеявность | **PCG**, предобусл. = `S1`(разделимый, `ar≡1`) + z-линейный блок-Якоби, тёплый старт | `ar≡1` делает предобусл. **точным в барьере** |
| Фиксированная точка | **отвергнута** | расходится (спектр. радиус ~75 при контрасте 10³) |
| Потоки | SG по обоим направлениям, метрика — в площадях граней | численная диффузия апвинда > физической |
| μ на грани | по `\|E\|` **с поперечной компонентой** | в головке `\|Er\| ~ \|Ez\|` |
| dt | `CFL/(\|vz\|/dz + \|vr\|/dr)` (сумма!), + reac/field/surf | минимум вместо суммы даёт неустойчивость по диагонали |
| z-транспорт e | неявный (опция, по умолчанию вкл.) | снимает z-CFL и z-диффузию, ×3–5 по числу шагов |
| Ток | Сато–Морроу; `E_L` **точно 1D**, `E_L,r ≡ 0` | радиальные потоки в ток не вносят вклада вообще |
| Поверхн. проводимость | пренебрегаем | растекание 0.16 с против полупериода 50 мкс |
| Фотоионизация | **нет** | чистый O₂ — нет N₂-излучателя; Железняк был бы ложью |
| Главный тест | 2D→1D при однородной затравке, допуск **1e-12** | однородность здесь — тождество, а не приближение |

### 10.2 Порядок операций на шаге

```
step(dt):
   1. E на гранях из phi^n (Ez, Er); |E| на гранях с поперечным усреднением; E/N
   2. LFA-таблицы -> mu_s, D_s, alpha, eta2, eta3   (на гранях)
   3. явные SG-потоки Gz*, Gr* для всех 6 заряженных сортов
   4. sigma_cond на гранях (апвинд по каждому сорту отдельно)
   5. пристеночные потоки (§6.1) — по каждому r; sigma_cond на пристеночных гранях
   6. сборка полунеявной матрицы A(dt) и rhs (включая w_g/w_d·sigma и дивергенцию F)
   7. az(z) = eps + dt·<sigma_cond>_A ;  при смене dt-уровня или профиля — пересборка S1
   8. phi_guess = 2*phi^n - phi^{n-1};  PCG(A, rhs, M = B∘S1∘B) -> phi^{n+1}, E^{n+1}
      (в тёмной фазе: один вызов S1, CG пропускается)
   9. коррекция потоков по (E^{n+1} - E^n)                 <-- сохранение заряда
  10. консервативное обновление n_s (§4.3), включая цилиндрическую метрику
  11. sigma_lo(r), sigma_hi(r) += dt·(...)
  12. источники: экспоненциальный интегратор при E^{n+1}, порядок Гаусса–Зейделя
      e -> O2+ -> O4+ -> O- -> O2- -> O3-
  13. клип положительности (floor 1e0 м⁻³) + счётчик срабатываний
  14. накопление медленной химии; каждые dt_slow=1 нс — шаг {O, O3, O2(a)} + их диффузия
  15. диагностика: Сато–Морроу, Q, максимумы, r_fil, невязка Пуассона, закон Гаусса
  16. эмиттер кадров (§9.3); каждые 10^4 шагов — checkpoint
  17. контроллер dt (§5.4); при отбраковке — откат и повтор
```

### 10.3 Порядок реализации (что за чем писать)

1. **Сетка + метрики + тесты T1–T8.** Ничего физического. Полчаса, ловит четверть будущих багов.
2. **`L_r`, симметризация, `tqli`, тесты T9–T14.** Здесь же — бенчмарк GEMM, чтобы сразу
   знать реальную мс/вызов на целевой машине (все оценки §5 от неё зависят).
3. **Разделимый решатель `S0` + тесты T15–T20.** На этом этапе уже есть рабочий
   электростатический 2D-солвер — можно нарисовать поле от гауссова пятна σ и убедиться глазами.
4. **Транспорт SG + тест T7/T8 + тест «2D→1D для чистого транспорта»** (без Пуассона:
   заморозить поле, пустить облако, проверить радиальную однородность и сохранение массы).
5. **Химия** — переиспользовать модуль 1D целиком, он поячеечный и от размерности не зависит.
6. **Явная связка (без полунеявности), маленький `dt`** — прогнать 2D→1D (V12) полностью.
   **Не идти дальше, пока V12 не даёт 1e-12.**
7. **Полунеявность + PCG.** Повторить V12 (допуск тот же — полунеявность радиальную
   однородность не нарушает). Измерить `nCG`.
8. **Затравочное пятно, филамент, кадры, плеер.**
9. **Валидация V1..V11** в 2D, сравнение с 1D.

### 10.4 Известные ограничения архитектуры (записать, чтобы потом не удивляться)

- **Радиально неоднородный диэлектрик невозможен** без отказа от прямого решателя.
- **AMR/локальное измельчение невозможно** — сетка обязана быть тензорной.
- **Только осевая симметрия.** Ветвление филамента, несколько филаментов, азимутальная
  неустойчивость — вне модели по построению. Это надо честно писать в UI.
- **Одна ячейка микроразряда с зеркальными стенками** ⟹ моделируется бесконечный
  регулярный массив филаментов с шагом `2R = 1 мм`, а не одиночный филамент в свободном
  пространстве. Для сравнения с экспериментом на 1 см² умножать на `127.3`.
- **Полунеявность первого порядка** по релаксации: переходник `tau_M` не разрешается,
  только его асимптотика.
- **Нет фотоионизации** — по физике, а не по лени; см. преамбулу.

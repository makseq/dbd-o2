## A. БЛОКЕРЫ — без этих исправлений модель физически ложна

### A1. Знак поверхностного заряда в правой части Пуассона
`NUMERICS.md:289,315` — знак σ в исключении левой поверхности неверен.

При принятом в документе условии скачка `D_g − D_d = σ₁`:

```
phi_s = (σ₁ + g_d*U + g_g*phi_1) / (g_d + g_g)
D_g   = −G*(phi_1 − U) + w*σ₁
```

следовательно вклад в правую часть:

```
rhs_1 += G*U + w*σ₁          ← ПРАВИЛЬНО
rhs_1 += G*U − w*σ₁          ← в документе, НЕВЕРНО
```

**Почему это блокер:** накопленный поверхностный заряд должен ЭКРАНИРОВАТЬ приложенное
поле и гасить разряд (memory effect — определяющая черта ДБР). С неверным знаком он
поле УСИЛИВАЕТ: самогашение превращается в положительную обратную связь. Разряд не
погаснет, Лиссажу не замкнётся в параллелограмм, мощность уйдёт в разнос.

**Тест-ловушка (обязателен):** подать σ на обе поверхности при U=0 и проверить, что
поле в зазоре НАПРАВЛЕНО ПРОТИВ того, которое эти заряды создали при разряде, и равно
по модулю значению из A6.

### A2. `n_floor = 1e10 м⁻³` — скрытый источник ионизации
`PHYSICS.md:313` задаёт floor 1e10 м⁻³, `NUMERICS.md:522` — 1 м⁻³. Противоречие, и

### A3. Весовой потенциал Сато–Морроу
`NUMERICS.md:370,705` — `phi_B` из полунеявной матрицы использовать НЕЛЬЗЯ.

Матрица шага содержит `(ε + Δt·κ(r,z))`, то есть зависит от плазмы и от Δt. Весовой
потенциал обязан решать задачу с ФИЗИЧЕСКОЙ проницаемостью:

```
div(ε grad phi_L) = 0,   phi_L = 1 на активном электроде, 0 на заземлённом
```

**Правильно:** предвычислить `phi_L` ОДИН РАЗ при построении сетки (геометрия и ε не
меняются во времени) и хранить как константу. Ток:

```
I(t) = (e/U_a) * ∫ (Γ_i − Γ_e) · E_L dV,   E_L = −grad phi_L
```

С «весовым потенциалом» из полунеявной матрицы ток получается нефизическим и зависящим
от шага по времени.

### A4. Размерная ошибка в граничной полунеявной проводимости
`NUMERICS.md:438` складывает Ф/м² и Ф/м.

```
g_g,eff = (ε₀ + Δt*κ_wall) / (Δx/2)        ← ПРАВИЛЬНО
g_g,eff = ε₀/(Δx/2) + Δt*κ                 ← в документе, размерно неверно
```

где κ [См/м]. Проверка размерности: `Δt*κ` = с·См/м = Ф/м, складывается с ε₀ [Ф/м] —
сходится; делится на длину — Ф/м². Второй вариант складывает Ф/м² с Ф/м.

### A5. Источники реакций не сохраняют заряд
`NUMERICS.md:478` — последовательное независимое экспоненциальное обновление сортов
(проход в стиле Гаусса–Зейделя с уже обновлёнными плотностями) НЕ гарантирует, что
ионизация добавит одинаковое число `O2+` и электронов.

**Правильно:** для каждой реакции вычислять положительный **reaction extent**
`ΔR_j ≥ 0` (сколько актов реакции произошло за Δt на единицу объёма), затем применять
ОДНУ И ТУ ЖЕ величину ко всем реагентам и продуктам согласно стехиометрии:

```
для каждой реакции j:  ΔR_j = rate_j * Δt   (с ограничением по запасу реагентов)
для каждого сорта s:   n_s += Σ_j ν_{s,j} * ΔR_j
```

Ограничение по запасу применять к ΔR_j, а НЕ к n_s после факта — иначе заряд снова
теряется. Это обеспечивает сохранение заряда машинно точно.

### A6. Аналитическое исключение диэлектрика справедливо ТОЛЬКО в 1D
`NUMERICS.md:31` — сведение барьера к проводимости `g_d = ε_d/d_d` точно лишь при
`phi_s = const` по радиусу.

В 2D `phi_s = phi_s(r)`, в барьере возникает радиальное поле, и потенциал по z
перестаёт быть линейным. Для радиальной моды с волновым числом κ_k точный адмиттанс
барьера:

```
Y_k = ε_d * κ_k * coth(κ_k * d_d)
```

и `ε_d/d_d` получается только для нулевой моды (κ_k → 0).

**Правильно для 2D:** решать ПОЛНЫЙ стек `диэлектрик | газ | диэлектрик` как единую
r-z задачу (как и заложено в плане 2D). **Категорически нельзя** переносить в 2D
локальные Robin-условия из `NUMERICS.md`.

## B. ОСЕСИММЕТРИЧНАЯ ГЕОМЕТРИЯ — ловушки разделимого решателя

### B1. Симметризация радиального оператора (иначе моды неортогональны)
`[проверено вручную]` В конечных объёмах оператор имеет вид `V⁻¹K`, где K симметрична
(транcмиссивности симметричны), а V — диагональ объёмов. `V⁻¹K` **не симметрична**;
диагонализовать её как симметричную — ошибка, дающая неортогональный базис и молча
неверный потенциал.

**Правильно** — обобщённая задача с объёмными весами:

```
M_r = diag[ (r_{i+1/2}² − r_{i−1/2}²) / 2 ]
K_r v_k = λ_k M_r v_k,      нормировка  v_kᵀ M_r v_l = δ_kl
```

эквивалентно: численно диагонализовать симметричную матрицу `M_r^{-1/2} K_r M_r^{-1/2}`
(например, симметричным QL/Якоби), затем вернуть `v = M_r^{-1/2} u`.

Прямое/обратное преобразование выполнять В МЕТРИКЕ M_r:
`rho_k = v_kᵀ M_r rho`, `phi = Σ_k phi_k v_k`.

**Тест:** проверить `vᵀ M_r v = I` с невязкой < 1e-12 и совпадение решения с независимым
медленным SOR-решателем на случайном ρ с точностью < 1e-8.

### B2. Ось r = 0 — не вычислять 1/r
В cell-centered FV внутренняя грань первой ячейки имеет `r_{−1/2} = 0`, поэтому её
площадь равна нулю и поток через неё автоматически нулевой. Регулярность `∂φ/∂r = 0`
выполняется сама. Явно вычислять `1/r` на оси **нельзя** (деление на ноль).

Для равномерной сетки коэффициент связи первой ячейки со второй равен `2/Δr²`.

### B3. Знак модального уравнения
Если λ_k определены как собственные значения оператора `−L_r` (то есть λ_k ≥ 0), то

```
d/dz(ε dφ_k/dz) − ε λ_k φ_k = −ρ_k          ← МИНУС
```

Плюс перед `ε λ_k φ_k` корректен только при определении λ_k как собственных значений
самого `L_r` (тогда λ_k ≤ 0). Зафиксировать одно соглашение и проверить тестом B1.

### B4. Нулевая мода не сингулярна
Neumann-мода по r постоянна, но задача не вырождена: условия Дирихле на электродах по z
фиксируют потенциал. Сингулярность возникла бы только при Neumann по ВСЕМ внешним
границам. Специальной обработки не требуется — но убедиться тестом.

### B5. Трансмиссивность на границе газ/диэлектрик в полунеявной схеме
Не «гармоническая ε плюс Δt·κ», а последовательное сложение сопротивлений:

```
T_f = ( h_g/(ε_g + Δt*κ_g) + h_d/ε_d )⁻¹
```

(в диэлектрике κ_d = 0). Для предобуславливателя PCG при сильном локальном филаменте
разделимого оператора только с ε(z) может не хватить — включить радиально усреднённую
`κ̄(z)`, чтобы предобуславливатель оставался эффективным.

### B6. Филамент сам не появится — и это принципиально
При строго осесимметричных границах и радиально ОДНОРОДНОЙ затравке решение останется
радиально однородным навсегда. Филамент обязан инициироваться контролируемой радиальной
неоднородностью (гауссово затравочное пятно на оси — как и заложено).

**Честное ограничение для README:** осесимметричная модель описывает только ЦЕНТРАЛЬНЫЙ
канал. Внеосевой канал в этой геометрии становится кольцом, а азимутальные
филаментационные моды (реальная самоорганизация решётки микроразрядов) отсутствуют
принципиально. Не заявлять, что модель воспроизводит взаимодействие соседних филаментов.

### D6-РАЗБОР: неразрешённое противоречие двух ревью (×18–26)

**Два независимых экспертных ревью дали противоположные ответы.** Это зафиксировано
честно, а не замазано.

- Ревью №1 (сессия по физике/схеме): использовать **приведённую массу**
  `μ_r = m_i·m_g/(m_i+m_g)`, для O₂⁻–O₂ это `m_g/2`. Даёт T_eff = 815 K при v_d = 896 м/с.
- Ревью №2 (сессия по фотопроцессам): использовало **полную массу нейтрала**,
  T_eff = 948 K при 30 кВ/см, ν_D6 = 3.23e7 с⁻¹.

Пересчёт `[проверено вручную]`, μ(O₂⁻) = 2.37e-4 м²/(В·с), k = 2.7e-16·√(T_eff/300)·exp(−5590/T_eff):

| E | v_d | полная масса | приведённая масса | расхождение |
|---|---|---|---|---|
| 30.0 кВ/см | 711 м/с | T_eff = 948 K, ν = 3.24e7 с⁻¹ | T_eff = 624 K, ν = 1.23e6 с⁻¹ | **×26.3** |
| 37.8 кВ/см | 896 м/с | T_eff = 1330 K, ν = 2.08e8 с⁻¹ | T_eff = 815 K, ν = 1.14e7 с⁻¹ | **×18.2** |

Расхождение зависит от поля — это не постоянный множитель, который можно было бы
списать на калибровку.

**РЕШЕНИЕ И ЕГО ОБОСНОВАНИЕ (методологическое, не физическое):**

Выражение `k = 2.7e-16·√(T_eff/300)·exp(−5590/T_eff)` — это **эмпирический фит из
Kossyi et al. 1992**. Переменная `T_eff` в нём определена той конвенцией, которой
пользовался автор фита. Подставлять в чужой предэкспонент и чужую энергию активации
ДРУГОЕ определение `T_eff` неверно **независимо от того, какая конвенция физичнее** —
это вычисление фита вне его собственной калибровки.

Соотношение Ваннье даёт среднюю случайную энергию иона как `½·m_нейтрала·v_d²`
(именно полная масса нейтрала), и полевые константы отлипания в литературе по
плазмохимии традиционно табулируют против этой формы.

Приведённая масса корректна для энергии относительного движения в системе центра масс —
но тогда нужен и фит, выведенный в той же системе, а его у нас нет.

```
ДЕФОЛТ:  T_eff = T_g + m_g·v_d²/(3·k_B)        [полная масса нейтрала]
ПАРАМЕТР: d6MassConvention: 'neutral' | 'reduced'
```

**Обязательно:** прогнать чувствительность по обеим конвенциям и вынести результат в
`VALIDATION.md`. Это ×18–26 в частоте отлипания в тёмной фазе, то есть прямое влияние
на затравку и момент повторного зажигания. Если результаты качественно расходятся —
писать об этом в README как о признанной неопределённости модели, а не выбирать ту,
что «красивее выглядит».

## E. ЧИСЛЕННЫЕ МЕЛОЧИ, КОТОРЫЕ ЛОМАЮТ ПРОГОН

### E1. Модуль поля перед log10(E/N) — иначе NaN на отрицательном полупериоде
`NUMERICS.md:215,228` — в переменном поле ДБР половина значений E отрицательна.

```
x = |E| / (N * 1e-21)   [Td]      ← ОБЯЗАТЕЛЬНО модуль
```

Без модуля отрицательный полупериод даёт NaN либо обращение к неверному концу таблицы.
Это гарантированный сбой на первом же полупериоде.

### E2. `dt_field` обращается в ноль на старте
`NUMERICS.md:542` — `dt_field = δ·max|E|/max|dE/dt|` даёт 0 при старте синусоиды из E=0.

```
Δt_E = δ_E * max(|E|, E_scale) / max|dE/dt|
```

плюс отдельное ограничение по фазе источника (не более ~1/200 периода за шаг).

### E3. Ограничитель шага по химии неполон
`NUMERICS.md:541` — ограничение только по `|ν_i − ν_a|` пропускает жёсткость при почти
полной компенсации ионизации и прилипания, и не учитывает кластеризацию (0.7 нс),
рекомбинацию и отлипание.

```
Δt_chem ≤ 0.1 * min_s (n_s + n_ref) / |S_s|
```

по ВСЕМ сортам, где `n_ref` — малая опорная плотность, защищающая от деления на ноль.

### E4. Внешняя цепь с последовательным резистором
`NUMERICS.md:353` — сведение к мгновенному алгебраическому уравнению неверно, ток
содержит `C_cell·dU/dt`. На временном слое решать совместно:

```
I^{n+1}   = I_cond^{n+1} + C_cell*(U^{n+1} − U^n)/Δt
U^{n+1}   = U_src^{n+1} − R*I^{n+1}
```

в знаменателе скалярного уравнения обязан появиться `R*C_cell/Δt`.

### E5. Полунеявный Пуассон — полная форма
`PHYSICS.md:372` приводит сокращённую формулу. Рабочая:

```
div[ (ε + Δt*κ) grad φ^{n+1} ] = −ρⁿ + Δt * div( J* + κ grad φⁿ )
```

Отбрасывание правой поправки нарушает согласованность с диффузионным и явным током.

### E6. Проверка баланса электронов неполна
`NUMERICS.md:738` — тест C3 не учитывает электрон-ионную рекомбинацию (E6/E7),
отлипание (D1–D7), E8, фон и вторичную эмиссию. В текущем виде даже корректное решение
не сможет выполнить заявленную невязку 1e-6. Переписать тест с полным набором членов.

- **Разделение γ:** `gamma_i = gamma_eff/(1 + (F_ph/F_i))`. При номинале

### F1. Опровергнутые утверждения (ревью GPT-5.6-Sol, вторая сессия)

Три моих исходных тезиса оказались неверны. Действует версия ниже.

**Неверно:** «в чистом O₂ фотоионизация невозможна, т.к. излучатель и поглотитель совпадают».
**Верно:** собственная фотоионизация `O₂* → O₂ + hν`, `O₂ + hν → O₂⁺ + e` не запрещена.
Она мала из-за слабого возбуждения нужных состояний, предиссоциации, столкновительного
тушения при 1 атм и того, что лишь часть поглощений даёт ион, а не диссоциацию.

**Неверно:** «длина поглощения 4–40 мкм, источник локален».
**Верно:** при параметрах Железняка (χ_min = 0.035, χ_max = 2.0 см⁻¹Торр⁻¹, p = 760 Торр)
`ℓ_max = 3.76e-4 м`, `ℓ_min = 6.58e-6 м`, то есть **7 мкм … 0.38 мм**.
Эквивалентные сечения `σ_min = 1.09e-22 м²`, `σ_max = 6.20e-21 м²`.
Трёхэкспоненциальное разложение для O₂: `ℓ_j = (238, 90, 14.8) мкм` с интегральными
весами ≈ 7 % / 26 % / 67 %. **Треть источника имеет масштаб больше радиуса головки —
локальным его считать нельзя.**

**Неверно:** «фотоотлипание готовит затравку к следующему полупериоду».
**Верно:** прозрачный фотон покидает 1 мм за пикосекунды. Отлипание идёт ОДНОВРЕМЕННО
с новым светящимся импульсом. Межполупериодная затравка возможна только от
долгоживущего излучателя, а ИК от O₂(a) при `A ≈ 2e-4 с⁻¹` даёт `ν_pd ~ 2e-6 с⁻¹` —
в ~10¹² раз меньше D3, то есть незначим.

### F2. Величины (для ожиданий, не для подгонки)

| Процесс | Оценка | Значим потому что |
|---|---|---|
| Собственная фотоионизация O₂ | `S_ph/S_ion ~ 1e-5…5e-3`, `ℓ = 7…380 мкм` | влияет на морфологию фронта, не на баланс |
| Фотоэмиссия с Al₂O₃ | интегрально `1e-6…1e-2` от ионной | **в первые десятки нс `Γ_i` у поверхности ≈ 0 (ионы летят 0.5–1.4 мкс), и фотоэмиссия временно ДОМИНИРУЕТ** → задаёт момент и место зажигания |

**Порог фотоэмиссии Al₂O₃ ≠ ширина запрещённой зоны.** Нужен переход валентная зона →

поверхности **9…10.5 эВ**; дефектный/плазменно обработанный оксид даёт эмиссию из
ловушек уже при 5–8 эВ. `E_th` ОБЯЗАН быть параметром модели.

**Двойной счёт:** после введения отдельного члена фотоэмиссии `γ_i` НЕЛЬЗЯ оставлять
«эффективным» 0.02 — фотоэмиссия будет учтена дважды. Разделить явно.

### F3. Численные требования

- **Гельмгольц нельзя собирать матрицей Пуассона со сдвигом.** Пуассон собран с `ε(z)`,
  а `∇²S_j − κ_j²S_j = −q_j` имеет коэффициент 1. Переиспользуются радиальная
  диагонализация, прогонка и инфраструктура ГУ — **сборка отдельная, с ε = 1**.
- **ГУ `S_j = 0` на границе зазора физически неверно.** Использовать модальное открытое
  условие, точное для плоской границы для каждой радиальной моды:
  `∂S_hat/∂n + sqrt(k_m² + κ_j²)·S_hat = 0`.
- **Для фотоотлипания Гельмгольц с κ→0 не годится:** даёт ядро `1/(4πR)`, а прозрачный
  поток имеет `1/(4πR²)`. Правильный осесимметричный интеграл с аналитическим азимутом:
  `Ψ(r,z) = ∫ q(r',z') r' dr' dz' / (2·sqrt([(r+r')²+(z−z')²]·[(r−r')²+(z−z')²]))`.
  Самоячейку интегрировать по конечному объёму (точечное выражение сингулярно).
  Альтернатива: `1/R² = (1/R)∫₀^∞ exp(−κR)dκ` → 8–16 логарифмически разнесённых `κ_j`.
- **Коэффициенты Бурдона для воздуха** (`A_j = 1.91e-45, 4.91e-44, 4.70e-42 м⁴`;
  `λ_j = 1.72e-22, 4.53e-22, 2.76e-21 м²`) годятся как численный ТЕСТ транспорта,
  но не как физическая модель собственного излучения O₂ — веса относятся к N₂.
- **Перефит:** `σ_ion` в амплитуде, `σ_abs` в экспоненте. Подставлять одно и то же
  в оба места ошибочно при квантовом выходе < 1.

Подробности и готовые к кодированию формулы: `docs/PHOTO_PROCESSES.md`.

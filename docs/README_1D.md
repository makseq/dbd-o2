# dbd-o2 — 1D fluid simulation of a dielectric barrier discharge in pure O₂

Одномерная self-consistent fluid-модель ДБР (диэлектрического барьерного разряда)
в чистом кислороде при атмосферном давлении, с живым веб-UI.
Чистый ES2022, ноль зависимостей, ноль сборки, ноль CDN.

```
metal | dielectric (0.5 мм, ε_r=9) | gas gap O₂ (1 мм) | dielectric (0.5 мм) | metal
                                    ↑ 1 атм, 300 K, N = 2.446e25 м⁻³
U(t) = U₀ sin(2πft),  U₀ = 10 кВ,  f = 10 кГц,  S = 1 см²
```

---

## Как запустить

ES-модули не грузятся с `file://`, поэтому нужен http-сервер.

```bash
./serve.sh              # → http://127.0.0.1:8777
./serve.sh 9000         # другой порт
```

Скрипт использует `python3 -m http.server`, а если его нет — падает на встроенный
node-сервер. Больше ничего не требуется.

| URL | что запускается |
|---|---|
| `index.html` | **реальный** fluid-солвер (`src/solver.js`) |
| `index.html?mock=1` | аналитический mock (`src/mock-solver.js`) — мгновенный, без физики, для работы над UI |

### Тесты

```bash
node test/solver.test.mjs     # 55 юнит-тестов ядра (≈70 с),  exit 0 = pass
node test/run-period.mjs      # физический прогон, 17 проверок по PHYSICS.md §6
```

`run-period.mjs [периодов] [режим] [U0кВ] [fкГц]`, например
`node test/run-period.mjs 5 default 12 25`.

## Что моделируется

Плоскопараллельная ячейка ДБР: два диэлектрических барьера, между ними газовый
зазор с чистым O₂. Синусоида на металлических электродах, опционально —
последовательный балластный резистор.

Физика, которую модель воспроизводит (и которую проверяет `run-period.mjs`):

* **филаментарный/таунсендовский режим** — короткие импульсы тока (единицы–десятки нс)
  в каждом полупериоде, по 2–3 микроразряда на полупериод;
* **эффект памяти**: заряд, осевший на диэлектрике, экранирует зазор, разряд
  самогасится и зажигается со сдвигом фазы относительно нуля напряжения;
* **фигура Лиссажу Q–V** в форме параллелограмма; из наклонов её ветвей методом
  Мэнли извлекаются `C_diel` и `C_cell`;
* **электроотрицательность O₂**: диссоциативное прилипание `e + O₂ → O⁻ + O` и
  трёхтельное `e + 2O₂ → O₂⁻ + O₂`; между импульсами отрицательные ионы
  (в основном O₃⁻) превышают n_e на 4–6 порядков;
* **наработка озона** `O + O₂ + M → O₃ + M` и его разрушение `O + O₃ → 2O₂`.

### Сорта частиц

9 сортов + фон O₂ (`src/physics.js`, `SPECIES`):

| заряженные (переносятся) | нейтральные (только химия + гибель на стенке) |
|---|---|
| e⁻, O₂⁺, O₄⁺, O⁻, O₂⁻, O₃⁻ | O, O₃, O₂(a¹Δg) |

O₄⁺ и O₃⁻ обязательны: при 1 атм конверсия O₂⁺→O₄⁺ занимает 0.7 нс, а O⁻→O₃⁻ —
1.5 нс, так что именно они доминируют в послесвечении.

### Реакции

32 реакции (`src/physics.js`, `REACTIONS`), каждая с `rate(EN, N, T)`:
ионизация, диссоциативное и трёхтельное прилипание, диссоциация, возбуждение
O₂(a¹Δ), диссоциативная рекомбинация, кластеризация ионов, **отлипание**
(включая полевое `D6` по Ванье — главный канал повторного зажигания),
ион-ионная рекомбинация (двух- и трёхтельная), нейтральная химия озона.

## Физика и численная схема

### Модель

Drift-diffusion для заряженных сортов + уравнение Пуассона, локальное приближение
поля (LFA): все коэффициенты — функции приведённого поля `E/N` в таунсендах.

```
∂n_s/∂t + ∂Γ_s/∂x = S_s ,   Γ_s = z_s μ_s E n_s − D_s ∂n_s/∂x
∂/∂x (ε ∂φ/∂x) = −ρ ,        ρ = e Σ z_s n_s
dσ_L/dt = −J(x_L) ,  dσ_R/dt = +J(x_R)      (поверхностный заряд)
```

### Численная схема (детали — `docs/NUMERICS.md`)

* **Сетка** конечно-объёмная, по **всему стеку** (диэлектрик | газ | диэлектрик):
  диэлектрики — обычные ячейки с `ε_r` и нулевым транспортом. Сгущение `tanh` к
  поверхностям, гладкость `|Δx_{i+1}/Δx_i − 1| < 0.03`. Газовые ячейки помечены
  в `state.gasMask`.
* **Пуассон**: трёхдиагональная система, гармоническое среднее `ε` на грани,
  поверхностный заряд — через исключение потенциала поверхности, так что условие
  Гаусса на границе газ/диэлектрик выполняется тождественно (невязка ~3e-15).
* **Полунеявная, заряд-сохраняющая связка** поле↔плотности:
  `ε_eff = ε + Δt·σ_cond`, затем коррекция потоков
  `Γ = Γ* + z μ n_up (E^{n+1} − E^n)`. Невязка Пуассона ~1e-13, полный заряд
  (объём + обе поверхности + клип положительности) сохраняется до ~7e-16.
* **Потоки** — Шарфеттер–Гуммель для всех заряженных сортов; больцмановский
  стационар даёт машинно-нулевой поток. Электроны — **неявно** (M-матрица),
  иначе диффузионный шаг `≈3e-12 с` убивает счёт; ионы — явно с CFL.
* **Источники** — формулировка через **reaction extent** (ERRATA A5), две стадии:
  (1) экспоненциальный предиктор даёт средние по шагу плотности `n̄_s = (1/Δt)∫n_s dt`
  (для линейного канала `L·n̄·Δt` тождественно равно точному числу актов реакции);
  (2) для каждой реакции считается один неотрицательный `ΔR_j`, ограниченный запасом
  реагентов, и применяется ОДНОЙ величиной ко всем участникам по стехиометрии.
  Заряд сохраняется машинно точно (дрейф ~3e-16 за период), положительность строгая.
  Медленная нейтральная химия расщеплена с шагом `1e-7 с`.
* **Пристеночные потоки** ионов — не явные, а через точное среднее по шагу решение
  задачи опустошения ячейки `w_eff = (dx/dt)(1 − e^{−w·dt/dx})`: при малом Куранте
  совпадает с явной схемой, при большом уносит ровно содержимое ячейки, не больше.
* **Ток** — формула Сато–Морроу с *численным* весовым полем плюс `C_cell·dU/dt`;
  заряд интегрируется по трапециям с компенсацией Кэхэна.
* **Шаг по времени** адаптивный: min из ионного CFL, точностного CFL электронов,
  `0.5/ν_growth` (чистая скорость роста лавины, без гейта по плотности), скачка поля
  и фазы источника; рост ограничен +25 % за шаг.
* **Отбраковка шага** (NUMERICS §5.2): теневые копии всех полей, после шага —
  три критерия (`min n < −1e-6·max n`, `max|ΔE|/max|E| > 3·dE_tol`, невязка Пуассона
  `> 1e-8`), при срабатывании откат и повтор с `Δt·0.4`. На дефолтных параметрах
  отбраковывается 0.18 % шагов; доля выведена в статус-строку UI.

## Результаты прогона (валидация)

### ⚠ Коэффициенты заменены по результатам решения уравнения Больцмана

Все электронные константы и транспортная таблица в `src/physics.js` заменены на
данные `docs/RATES_REVIEW.md` (собственное решение двухчленного уравнения
Больцмана по схеме Hagelaar–Pitchford на сечениях LXCat/Phelps для **чистого O₂**,
валидация против опубликованной таблицы самого Phelps, JILA Report 28 — согласие
1–4 %). Данные **побитово совпадают** с `sim2d/physics2d.mjs`.

Что именно было не так со старыми коэффициентами:

| что | было | стало | почему |
|---|---|---|---|
| `ELECTRON_TABLE` | w_e = 1.15e5 м/с, ⟨ε⟩ = 3.10 эВ, D·N = 2.38e24 @100 Td | **1.830e5 / 4.362 эВ / 6.240e24** | таблица была для **воздуха**: колебательное возбуждение N₂ охлаждает ФРЭЭ. w_e занижена на 37 %, ⟨ε⟩ на 28–45 %, D_e в 2.6 раза. Через `η = (k₂N + k₃N²)/w_e` это двигало точку α = η |
| E4 `kDiss` @100 Td | ~1.8e-18 (исх. фит), 2.87e-16 (Te-фит) | **1.937e-15** | в модели **полностью отсутствовал канал 8.4 эВ** — 64 % суммы при 100 Td, 78 % при 200 Td |
| E5 `kExc` @100 Td | ~1.5e-17 | **6.982e-16** | заниженная ⟨ε⟩ из воздушной таблицы + заниженный предэкспонент |
| E3 `kAtt3`, тепловой предел | 3.0e-43 м⁶/с, форма `exp(−E/N / 60)` | **2.80e-42 м⁶/с**, форма **степенная** ~(E/N)^−0.9 | прямое измерение Chanin–Phelps–Biondi 1962; экспонента слишком резкая, при 150–500 Td занижала в 3–5 раз |
| E2 `kAtt2` @100 Td | ~1.6e-18 | **4.201e-17** | ×27; ломало η, `alphaEff` и весь баланс O⁻ |
| E1 `alphaN` | фит Morrow 1985 | **таблица k_ion/w_e** | фит занижен ровно вдвое при 200–500 Td и втрое при 100 Td |

Все таблицы интерполируются **лог-лог** (ошибка < 1 % выше 25 Td). Аналитические
фиты сознательно не используются: они дают ±30–50 %.

**Состав суммы «диссоциация» обязателен к прочтению** (неопределённость
ОПРЕДЕЛЕНИЯ — фактор 3.3 — в ~30 раз больше неопределённости данных ±6 %):
принято `k_diss = k(6.0 эВ) + k(8.4 эВ)`, полосы Герцберга 4.5 эВ **не включены**.
Строка `SUM DISSOC.` в таблице самого Phelps — это другая сумма (она исключает
канал 6.0 эВ), сравнивать «в лоб» нельзя.

`node test/solver.test.mjs`, секции 6 и 10 — воспроизводят **все** эталоны

| величина | модель | эталон | было (ОТМЕНЕНО) |
|---|---|---|---|
| α = η | **127.84 Td** = 31.27 кВ/см | 127.8 Td ± 5 | 101.3 Td |
| U_br(γ = 0.005) | **3.634 кВ** (148.56 Td) | 3.634 кВ | — |
| U_br(γ = 0.01) | **3.557 кВ** (145.41 Td) | 3.557 кВ | — |
| U_br(γ = 0.02) | **3.473 кВ** (141.97 Td) | 3.473 кВ | 3.76 кВ (153.4 Td) |
| U_br(γ = 0.05) | **3.349 кВ** (136.88 Td) | 3.349 кВ | — |
| (α−η)·d в корне | **2.960** | 2.960 | 3.93 |
| U_i = U_br(1 + C_g/C_d) | **3.859 кВ** | — | 4.20 кВ |
| время пролёта электрона @141.97 Td | **4.33 нс** | 4.33 нс | ~8 нс |
| время пролёта O₂⁺ | **1.21 мкс** | 1.19 мкс | — |
| k_diss / k(a¹Δ) / k_att2 / k₃ @100 Td | 1.937e-15 / 6.982e-16 / 4.201e-17 / 8.347e-44 | те же | — |

Критерий самоподдержания взят в форме для **электроотрицательного** газа
(ERRATA §C V2): `γ·α/(α−η)·[exp((α−η)d) − 1] = 1`. Упрощённая форма
`(α−η)d = ln(1+1/γ)` не используется — она даёт 146.0 Td вместо 141.97.

**U_br ≠ U_burn ≠ U_i — три разные величины**, путать их нельзя:

* `U_br = 3.473 кВ` — статическое поле самоподдержания в **голом газе**
  (критерий Таунсенда); барьеров и внешней цепи в нём нет вообще;
* `U_i = U_br·(1 + C_g/C_d) = 3.859 кВ` — то, что надо приложить **к ячейке**,
  чтобы на газе появилось `U_br`; порог **первого** зажигания при σ = 0;
* `U_burn` — измеренный солвером потолок `|U_gap|` на импульсе: величина
  **динамическая**, в переходном перенапряжённом режиме заходит выше `U_br`
  (формативное запаздывание), а в установившемся остаточный σ позволяет
  зажигание ниже.

### ⛔ Что НЕ проходит: 1D-солвер расходится на импульсе

**С корректными коэффициентами `node test/run-period.mjs` не досчитывает даже
первый период.** Прогон обрывается защитой на `E/N > 5000 Td` при t = 8.14 мкс
(первое зажигание).

Что происходит: за ~1 нс после зажигания приповерхностная ячейка набирает
`n_e ~ 1e24 м⁻³` (при `N = 2.45e25`) и `E/N ~ 4·10⁴ Td`; на **обоих** барьерах
оседает заряд **одного знака** (σ_L = −1.8e-4, σ_R = −1.8e-2 Кл/м²), поэтому
экранирование зазора пропадает и самогашение — определяющая черта ДБР —
не наступает. Система садится в нефизичное квазистационарное состояние:
проводящая плазма 1e20 м⁻³ по всему зазору плюс ~2 кВ на приповерхностном слое
толщиной 2 мкм; шаг падает до 1e-14 с, 25 % шагов отбраковывается.

Проверено, что это **не** артефакт дискретизации и **не** ошибка переноса
коэффициентов:

| гипотеза | проверка | результат |
|---|---|---|
| грубая сетка | 200 / 400 / 800 ячеек, режим `accurate` | расходится во всех |
| слишком большой шаг | CFL 0.8→0.2, eCFL 8→1, жёсткий потолок dt = 1e-13 с | расходится |
| вторичная эмиссия (катодный слой) | γ = 0.02 / 0.005 / **0** | расходится даже при γ = 0 |
| перенапряжение | U₀ = 5 / 6 / 7 / 8 / 10 кВ | расходится на первом зажигании при любом |
| экстраполяция таблиц выше 1000 Td | клип w_e на 1000 Td | расходится |
| ошибка порта | посортовое сравнение с `sim2d/physics2d.mjs` на 1e-4…5000 Td | расхождение **0.0** (побитово) |
| знак σ (ERRATA A1) | поле памяти при σ_L = −σ_R = 4.6e-4 | −5.195e6 В/м = ровно `0.1·σ/ε₀`, **экранирует** — корректно |
| подавление теплового потока электронов на отталкивающей стенке (больцмановский множитель) | пробная правка BC | **хуже**: n_e доходит до 2.5e26 |

Локализация по коэффициентам: расходимость запускает **либо** новая
`ELECTRON_TABLE`, **либо** новая `alphaN` — по отдельности каждой достаточно.
Замена только `kAtt2`, только `kAtt3` или только `kDiss/kExc` расходимости не даёт.
То есть спусковой крючок — **втрое более быстрая ионизация**
(α/N ×2 при 200–500 Td, w_e ×1.6), из-за которой микроразряд успевает уйти
в стримерно-дуговой режим раньше, чем поверхностный заряд его погасит.

Физически это согласуется с известным ограничением п.8 ниже: 1D-модель зажигает
**всю площадь 1 см² синхронно**, то есть выдаёт в зазор на 2 порядка больше
заряда, чем может принять диэлектрик (`C_d·(U₀−U_i)/A = 9e-4 Кл/м²`). Со старыми
(вдвое-втрое заниженными) коэффициентами модель случайно оставалась в
таунсендовском режиме и гасилась; с корректными — не остаётся.

**Ни один коэффициент под это не подгонялся** (ERRATA: подгонка множителем
вместо замены коэффициентов = дефект severity blocker). Починка требует работы
в `src/solver.js` (разрешение приповерхностного слоя / модель неразрешённого слоя / ограничение по запасу O₂), что выходит за рамки этой правки.

* **B. Вид зазора** — карта поля по x: 5 полей (`n_e`, `ρ`, `S_ion`, `|E|`, `E/N`),
  режимы snapshot и **x–t streak с равномерной осью времени** (1 строка = Δt =
  lens/высота полосы, метка T/2), колорбар (Inferno / расходящаяся), пунктирная
  изолиния ρ=0, послесвечение (буфер `G ← max(S_ion, G·e^(−Δt/250мс))`, красится
  и шкалируется ОДИН И ТОТ ЖЕ массив в абсолютных единицах), подсветка филамента,
  шины поверхностного заряда σ_L/σ_R с glyph'ами `+/−` и цифрами в нКл/см².
* **C. Метрики** — 9 плиток со спарклайнами: мощность, удельная энергия, озон,
  max E/N, пиковый ток, пробоев за период, C_diel, C_cell, энергия за период.
* **D. Осциллограммы** — U(t) и I(t) с раздельными осями, лог по току,
  min/max-децимация (никогда не усреднение) с бейджем `decimated ×N`,
  маркеры пробоев, синхронный курсор. Линза по умолчанию = **один период**
  (быстрые зумы `1 T` / `8 T` / `fil`), при счёте окно прижато к текущему времени;
  если в окне нет данных — явное сообщение с длиной доступной истории.
* **E. Q–V Лиссажу** — фигура с «призраками» до 7 прошлых периодов (из
  `solver.qvHistory`, а не из короткого кольца истории), линии наклонов
  Мэнли, бейдж качества фита (`R²` сторон, число дуг) — предупреждение
  показывается, когда фигура не параллелограмм, а не «никогда».
* **F. Профили** — 9 сортов в log-масштабе по x или по t, штриховые узоры,
  прямые подписи у концов кривых, solo/hide, CVD-safe режим, тултип с Σq/e.
* **G. Контролы** — 12 слайдеров с числовыми полями и **единицами измерения**
  (лог там, где нужно) + селектор точности (`demo`/`default`/`accurate`) +
  индикатор λ_D/Δx по худшему значению за прогон.
* **H. Транспорт и таймлайны** — MACRO и MICRO шкалы с треугольниками пробоев,
  лупа, drag-seek, привязка к событиям; `1 period`, `run to steady`, `step dt`.

Экспорт: CSV (временные ряды), PNG (2×, с параметрами и меткой времени),
JSON + отчёт по Мэнли. Табличный вид любой панели. Клавиатурные сокращения.

## Известные ограничения и честные компромиссы

0. **⛔ ГЛАВНОЕ, ЧЕСТНО: с корректными коэффициентами 1D-солвер не досчитывает
   период.** Разряд уходит в стримерно-дуговую расходимость на первом же
   зажигании (детали, диагноз и полный список проверенных гипотез — в разделе
   «Результаты прогона» выше). Работоспособны и валидированы: сами коэффициенты,
   таунсендовские критерии (α = η, U_br(γ)), Пуассон, ёмкости, сохранение заряда
   на неразрядных прогонах и весь тёмный режим. **Не работает**: количественный
   прогон импульса — мощность, озон, ток, поверхностный заряд, фигура Лиссажу
   горящей ветви. Числа старого прогона в README помечены как исторические
   и валидацией не являются. Коэффициенты под работоспособность НЕ подгонялись.
1. **Скорость.** ~11 с на период в `demo`, ~35 с в `default` (на этой машине).
   Ограничители по времени (ионный CFL, точностной CFL электронов, ограничитель
   роста лавины `0.5/ν_growth`, ограничитель скачка поля) сбалансированы, ни один
   не доминирует, так что дешёвого ускорения нет — нужен WASM или огрубление сетки.
2. **Солвер крутится в главном потоке** внутри бюджета rAF (12 мс/кадр).
   Контрактный `advance(budgetMs)` синхронный, поэтому Web Worker потребовал бы
   изменения контракта (worker + snapshot через `postMessage`). При 60 fps это
   даёт ~5 мкс модельного времени на секунду реального.
3. **Q–V фигура — НЕ параллелограмм, и это не скрывается.** В 1D на полупериод
   приходится 2 микроразряда, зазор зажат неидеально (U_gap плывёт вдоль горящей
   ветви), поэтому:
   * `periodStats.Cdiel` = **измеренный** наклон горящей ветви `dQ/dU_app`
     (8–13 пФ при геометрических 7.97 пФ, R² ≈ 0.8–0.94 — сторона не прямая);
   * `periodStats.CdielIdentity` = наклон `dQ/d(U_app − U_gap)`. Это **тождество**
     последовательной цепи `Q = C_d (U_app − U_gap)`, оно равно `C_d` на ЛЮБОЙ дуге,
     включая полностью тёмную, и годится ТОЛЬКО как самопроверка схемы (раньше
     именно оно выдавалось за «C_diel по Мэнли», и тест на него не мог провалиться);
   * `periodStats.qvOk`, `qvR2on/off`, `qvArcsOn/off`, `qvFallback` — метрики
     качества фита; при `qvOk === false` UI показывает бейдж `⚠ not a parallelogram`.
   `C_cell` снимается с тёмных ветвей (порог «темноты» — абсолютный, по масштабу
   тока смещения `C_cell·U₀·ω`) и совпадает с аналитикой на 0.3–1.5 % вплоть до 50 кГц.
4. **Пик тока выше и импульс короче спеки** (наблюдалось на старых
   коэффициентах: 8.85 А / 4 нс против ориентира 1 А/см² / 100 нс). Причина —
   1D зажигает всю площадь синхронно. С корректными коэффициентами эта же
   причина становится фатальной: за импульс в зазор идёт на 2 порядка больше
   заряда, чем может принять диэлектрик, и разряд не гасится (п.0).
5. **Диффузия нейтралов (O, O₃, O₂(a)) не считается** — только пристеночная гибель
   и объёмная химия. При 1 атм диффузионное время через зазор ~50 мкс против
   2.8 мкс на образование озона, вклад пренебрежим.
6. **Нет протока газа**, поэтому озон накапливается монотонно и в модели нет
   стационарной концентрации, задаваемой расходом, — только химическое насыщение.
7. **Сетка не разрешает дебаевский радиус на пике импульса.** Индикатор в панели
   Controls показывает λ_D/Δx по ХУДШЕМУ значению за прогон и честно краснеет
   (`✕`, λ_D/Δx ≈ 0.25 при 200 ячейках). Это ограничение fluid-модели с LFA;
   уменьшение Δx (режим `accurate`) улучшает ситуацию, но не убирает её.
8. **1D**: филаменты не разрешаются пространственно, вся площадь зажигается
   синхронно. Все токи — площадно-усреднённые. Это не косметическое ограничение:
   именно оно, вместе с корректной (втрое более быстрой) ионизацией, ломает
   самогашение — см. п.0.
9. **Только синусоида.** `params.mode` — это пресет точности, а не форма
   напряжения; square/pulsed ядром не поддерживаются.
10. **Односторонний ДБР (один барьер) не поддерживается**: при `dielMM1 = 0` или
    `dielMM2 = 0` граница газ/диэлектрик совпала бы с металлом, схема стала бы
    рассогласованной и решение молча расходилось. Конструктор бросает `Error`.
11. **Ring-буфер истории вмещает ~2 периода** (4096 отсчётов при записи раз в
    T/2000). Поэтому: перемотка MACRO ограничена доступной историей (недоступная
    область заштрихована), «призраки» Q–V за 8 периодов рисуются из отдельного
    буфера огибающих `solver.qvHistory`, а в шапку CSV пишется реальная длина
    выгружаемого окна.
12. **Три сорта не входили в исходный контракт** `state.n` (O₃⁻) и в палитру UI
    (O₄⁺, O₂(a¹Δ), O₃⁻ получили цвета-расширения, не прошедшие валидацию
    палитры на 6 слотов).

### Что было починено в этой ревизии (ERRATA)

* **A5 — источники реакций не сохраняли заряд.** Электрон получал ионизацию как
  точный экспоненциальный интеграл, а партнёрский O₂⁺ — как трапецию; фон `sBg`
  рождал электрон вообще без иона; ион-ионная рекомбинация считалась независимо
  для положительных и отрицательных. Итог: +1.7e-9 Кл фиктивного заряда за период,
  оседавшего на диэлектриках (σ_L/σ_R = 2:1 в симметричной ячейке).
  Теперь — формулировка через **reaction extent**: один неотрицательный ΔR_j на
  реакцию, ограниченный запасом реагентов, применяется ко всем участникам по
  стехиометрии. Дрейф заряда упал до 3e-16 (машинная точность).
* **A2 — `n_floor = 1e10 м⁻³`** для e/O₂⁺/O₄⁺ был скрытым источником ~5e17 м⁻³с⁻¹.
  Теперь пол = 1 м⁻³ для всех сортов, чисто как защита от round-off. Тёмный ток
  упал с 7.6e-8 до 7.4e-13 А, U_burn вырос на ~6 %.
* **Пристеночный отток ионов** был явным и неограниченным (число Куранта до 2.2 в
  `demo` и ~9 в `accurate`). Теперь используется точное среднее по шагу решение
  задачи опустошения ячейки `w_eff = (dx/dt)(1 − e^{−w·dt/dx})` — безусловно
  положительное и консервативное, без штрафа по шагу.
* **Отбраковка шага (NUMERICS §5.2)** реализована: теневые копии, три критерия
  (отрицательные плотности, скачок поля > 3·dE_tol, невязка Пуассона > 1e-8),
  откат с `dt *= 0.4`; `state.rejects/steps/clipCharge/residual` выведены в UI.
* **`setParams({epsR})`** не пересобирал `epsCell` и весовое поле — слайдер ε_r
  физически ничего не менял (ошибка U_gap до 35 %).
* **Выборка Q–V пропускала слоты** — до 14.5 % ячеек содержали данные прошлого
  периода и входили в ∮U dQ (ошибка мощности до 25 % на 50–100 кГц).
* **UI**: послесвечение красилось не тем массивом, по которому строилась шкала
  (полоса вырождалась в однородный жёлтый); x–t streak теперь имеет равномерную
  ось времени (1 строка = фиксированный Δt) и метку T/2; линза по умолчанию равна
  периоду; смена геометрии сбрасывает UI-состояние; sticky-футер больше не
  накрывает легенду; у всех контролов есть единицы измерения; `sig3` не печатает
  `4.09e+3`.

### API солвера (контракт)

```js
const solver = new DBDSolver({ gapMM, dielMM1, dielMM2, epsR, areaCM2,
                               U0kV, freqKHz, pressureTorr, tempK, gamma,
                               seedDensity, nCells, ballastOhm, mode });
solver.setParams(partial);        // геометрия → пересборка сетки, иначе горячее обновление
solver.reset();
solver.step();                    // один адаптивный шаг, возвращает dt
solver.advance(budgetMs);         // → { steps, simTime }
solver.state;                     // t, dt, x, xFaces, gasMask, n{...}, E, phi, rho,
                                  // ionizRate, EN, sigmaL/R, Uapp, Ugap, current,
                                  // condCurrent, dispCurrent, charge, power,
                                  // o3ppm, maxEN, peakCurrent, breakdownsPerPeriod
                                  // + расширение: steps, rejects, clipCharge,
                                  //   residual, wallCfl (численное здоровье)
solver.history;                   // кольцевые буферы t/Uapp/Ugap/current/condCurrent/charge
solver.qvHistory;                 // огибающие Q–V последних 8 ЗАВЕРШЁННЫХ периодов
solver.periodStats;               // energyPerPeriodJ, powerW, UburnkV,
                                  // Cdiel (= измеренный наклон горящей ветви, = CdielRaw),
                                  // CdielIdentity (тождество Q=C_d(U−U_gap), самопроверка),
                                  // CdielGeom / CcellGeom (аналитика), Ccell,
                                  // qvArcsOn/Off, qvR2on/off, qvOk, qvFallback

// Геометрия: dielMM1 и dielMM2 обязаны быть > 0 — односторонний ДБР схемой
// не поддерживается, конструктор бросает Error вместо тихого расхождения.
```

Расширения сверх исходного контракта: сорт `O3m` в `state.n`, `condCurrent` в
`history`, `CdielRaw` в `periodStats`, `solver.targetSimTime` (стоп-время для
`advance`). Всё это опционально — UI работает и без них (см. `?mock=1`).

**Важно:** `state.x` покрывает **весь стек**, а не только зазор. Газовые ячейки
надо выбирать по `state.gasMask` (в UI это делает адаптер `GAS`).

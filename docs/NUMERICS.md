# NUMERICS.md — численная схема 1D fluid-модели ДБР в O2

Документ фиксирует численную постановку для `/p/dbd-o2`: сетка, дискретизация потоков,
решатель Пуассона, способ снятия жёсткости, управление шагом, бюджет производительности,
диагностика и тесты. Целевая платформа — JavaScript (Web Worker, Float64Array, single thread).

Обозначения: `x` — координата поперёк зазора, газ занимает `[0, d_gap]`, слева барьер 1
(толщина `d1`), справа барьер 2 (`d2`), `eps_r` — их проницаемость. `N` — плотность газа
(2.447e25 м^-3 при 1 атм, 300 K). `E/N` в таунсендах, 1 Td = 1e-21 В·м².

Список частиц (минимальный рабочий набор):

| Индекс | Частица | q | Подвижность (1 атм) | Роль |
|---|---|---|---|---|
| 0 | e | -e | mu_e ~ 0.03–0.07 м²/(В·с), из LFA | ионизация, прилипание |
| 1 | O2+ | +e | ~5e-5 м²/(В·с) | основной положительный ион |
| 2 | O- | -e | ~7e-5 | диссоц. прилипание e + O2 -> O- + O |
| 3 | O2- | -e | ~5e-5 | трёхтельное e + 2O2 -> O2- + O2 |
| 4 | O | 0 | D ~ 2e-5 м²/с | предшественник озона |
| 5 | O3 | 0 | D ~ 1.5e-5 м²/с | продукт |

Заряженные: 0..3 (`NS_ch = 4`), нейтральные: 4..5 — они не входят в Пуассон и считаются
на медленной сетке времени (см. §4.4).

## 1. Сетка

### 1.1 Что дискретизируем

**Решение: транспорт и Пуассон решаются ТОЛЬКО в газовом зазоре. Диэлектрики в сетку не
включаются — они исключаются аналитически в граничное условие Робина.**

Обоснование: внутри барьера нет объёмного заряда и нет проводимости, значит `d/dx(eps dphi/dx)=0`,
то есть потенциал там строго линеен. Любая конечно-объёмная дискретизация барьера воспроизведёт
этот линейный профиль лишь с точностью до ошибки округления и добавит 2×(8..20) лишних ячеек
в трёхдиагональную систему без единого бита новой физики. Аналитическое исключение (§3.3) даёт
**точный** результат при нулевой стоимости. Явные ячейки в барьере понадобятся только если
позже добавлять объёмную проводимость диэлектрика или заряд-ловушки в объёме — тогда включаем
их в ту же сетку с per-cell `eps` (код это поддерживает, см. §3.2, формула с гармоническим
средним универсальна).

### 1.2 Число ячеек и сгущение

Конечно-объёмная (cell-centered) сетка, `Nx` ячеек, границы `x_{i+1/2}`, центры `x_i`,
ширины `dx_i`, расстояния между центрами `h_{i+1/2} = x_{i+1} - x_i`.

Что надо разрешить:
- катодный слой / фронт лавины в атмосферном ДБР в O2: 20–80 мкм;
- зона максимума ионизации у поверхности: масштаб ~10 мкм;
- слой поверхностного заряда и ионный «хвост»: ~10 мкм.

**Решение по умолчанию: `Nx = 300` для зазора 1 мм, симметричное сгущение по tanh к обеим
поверхностям, `dx_min ≈ 1.5 мкм` у стенок, `dx_max ≈ 6 мкм` в центре.**

Генератор (симметричное tanh-растяжение, параметр `beta` = сила сгущения, 2.0–3.0):

```js
// узлы граней xf[0..Nx], xf[0]=0, xf[Nx]=Lg
function makeGrid(Nx, Lg, beta = 2.4) {
  const xf = new Float64Array(Nx + 1);
  const th = Math.tanh(beta / 2);
  for (let k = 0; k <= Nx; k++) {
    const s = 2 * k / Nx - 1;                  // s in [-1, 1]
    xf[k] = 0.5 * Lg * (1 + Math.tanh(beta * s / 2) / th);
  }
  return xf;
}
```

Обязательная проверка гладкости: `max_i |dx_{i+1}/dx_i - 1| < 0.08`. При большем скачке
конечно-объёмная аппроксимация потока падает со 2-го порядка почти до 1-го, и погрешность
поля у стенки становится заметной. При `beta = 2.4, Nx = 300` максимальное отношение ~1.02 —
запас большой.

Профили сеток по режимам:

| Режим | Nx | dx_min | dx_max | Комментарий |
|---|---|---|---|---|
| demo (интерактив) | 200 | 2.5 мкм | 9 мкм | 60 fps, физика качественно верна |
| default | 300 | 1.5 мкм | 6 мкм | рабочий |
| accurate | 800 | 0.5 мкм | 2.5 мкм | для сеточной сходимости и валидации |

Сетка статическая. Адаптивное перестроение (AMR) в 1D не окупается: выигрыш по числу
ячеек ~2–3×, а стоимость интерполяции + потеря консервативности + усложнение кода велики.
Экономию берём из адаптивного шага по времени (§5), а не из сетки.

## 2. Дискретизация потоков: Шарфеттер–Гуммель

### 2.1 Уравнение

Для заряженной частицы `s` со знаком заряда `z_s = ±1`:

```
dn_s/dt + d(Gamma_s)/dx = S_s
Gamma_s = z_s * mu_s * E * n_s  -  D_s * dn_s/dx
```

Консервативное обновление ячейки:

```
n_s,i^{n+1} = n_s,i^n - (dt / dx_i) * (Gamma_{i+1/2} - Gamma_{i-1/2}) + dt * S_i
```

### 2.2 Формула потока на грани

Точное решение стационарного 1D уравнения `d/dx(v n - D dn/dx) = 0` на отрезке между
центрами ячеек при постоянных `v` и `D` даёт схему Шарфеттера–Гуммеля. Пусть на грани
`i+1/2`:

```
v = z_s * mu_{i+1/2} * E_{i+1/2}          (дрейфовая скорость со знаком)
h = h_{i+1/2} = x_{i+1} - x_i
X = v * h / D_{i+1/2}                     (сеточное число Пекле)
```

Тогда

```
Gamma_{i+1/2} = (D_{i+1/2} / h) * [ n_i * B(-X)  -  n_{i+1} * B(X) ]
```

где `B(x) = x / (exp(x) - 1)` — функция Бернулли, `B(0) = 1`.

Проверки предельных случаев:
- `X -> 0`: `B(∓X) -> 1 ∓ X/2`, поток `-> (D/h)(n_i - n_{i+1}) + v(n_i + n_{i+1})/2` —
  центральная разность плюс чистая диффузия. Второй порядок.
- `X -> +inf` (дрейф вправо): `B(X) -> 0`, `B(-X) -> X`, поток `-> v * n_i` — апвинд.
- `X -> -inf`: поток `-> v * n_{i+1}` — апвинд с другой стороны.

Эквивалентная форма через разность потенциалов (удобна, когда `D/mu = V_T` — соотношение
Эйнштейна): `X = z_s * (phi_i - phi_{i+1}) / V_T`, где `V_T = D_s/mu_s` — характеристическая
энергия в вольтах. Для электронов в LFA `V_T = D_e/mu_e` берётся из той же таблицы, что и
остальные коэффициенты, и НЕ равно `kT/e`.

### 2.3 Почему не апвинд

Апвинд первого порядка эквивалентен точному уравнению с добавленной численной диффузией

```
D_num = |v| * h / 2
```

Оценка для наших параметров: `h = 3e-6 м`, `E = 3e6 В/м`, `mu_e = 0.05` -> `v_e = 1.5e5 м/с`,
значит `D_num = 0.22 м²/с`. Физическая `D_e = mu_e * (D_e/mu_e) ≈ 0.05 * 3 = 0.15 м²/с`.
**Численная диффузия больше физической.** Последствия конкретны и фатальны для задачи:

1. Фронт лавины размазывается, максимум `n_e` занижается в разы -> занижается пиковый ток
   филамента и заряд, перенесённый за импульс.
2. Ширина катодного слоя (где `alpha` меняется на порядки на 10 мкм) искажается -> смещается
   напряжение зажигания, а именно оно определяет форму параллелограмма Лиссажу.
3. Ошибка не уходит при измельчении «на глаз»: чтобы `D_num < 0.1 D_e`, нужно
   `h < 2*0.1*D_e/v = 2e-7 м` — то есть `Nx = 5000`. Это в 16 раз дороже нашей сетки
   по числу ячеек и в 16 раз по шагу CFL, итого ~250× по стоимости.

SG же **точна** для кусочно-постоянного поля и стационарного профиля при любом `h`: она
воспроизводит больцмановский экспоненциальный профиль в слое без разрешения дебаевской длины.
Именно поэтому она стандарт в дрейф-диффузионных плазменных и полупроводниковых кодах.

Центральная разность (2-й порядок) в этой задаче непригодна: при `|X| > 2` она даёт
осциллирующее решение с отрицательными плотностями, а у нас `|X_e| ~ 10..100`.

### 2.4 Численно устойчивая реализация `B(x)`

Опасности: переполнение `exp(x)` при `x > 709`, потеря значимости `x/(exp(x)-1)` при `x -> 0`
(деление 0/0), и медленный `Math.exp`.

```js
// B(x) = x / (exp(x) - 1), устойчиво на всей оси
function bern(x) {
  if (x > 40)   return x * Math.exp(-x);     // ~0, но без переполнения
  if (x < -40)  return -x;                   // exp(x)->0  =>  x/(-1)
  if (Math.abs(x) < 1e-10) return 1 - 0.5 * x;
  return x / Math.expm1(x);                  // expm1 точен при малых x
}
```

`Math.expm1` обязателен: наивное `Math.exp(x)-1` при `x ~ 1e-8` теряет 8 значащих цифр.
Порог 40 выбран так, что `exp(-40) ~ 4e-18` — ниже относительной точности double, то есть
переход к апвинду там точен.

Ещё лучше — не звать `bern` дважды на грань. Используем тождество `B(-x) = B(x) + x`:

```js
const bp = bern(X);          // B(X)
const bm = bp + X;           // B(-X)
Gamma = (D / h) * (n_i * bm - n_ip1 * bp);
```

Один `expm1` на грань на сорт вместо двух.

### 2.5 Предел D -> 0 (ионы, нейтралы в сильном поле)

При `D -> 0` имеем `X -> ±inf`, и формула `(D/h)*[...]` формально даёт `0 * inf`. Ветвь
`|x|>40` в `bern` это уже разрешает численно (`D/h * X = v`), но чтобы не полагаться на
сокращение больших чисел, ставим явный переключатель:

```js
if (D < 1e-30 || Math.abs(X) > 40) {
  // чистый апвинд — математически точный предел SG
  Gamma = (v > 0) ? v * n_i : v * n_ip1;
} else {
  const bp = bern(X), bm = bp + X;
  Gamma = (D / h) * (n_i * bm - n_ip1 * bp);
}
```

Этот `if` вдобавок экономит `expm1` для электронов почти на каждой грани в активной фазе
(там `|X| ~ 10..100`) — существенный выигрыш по времени, см. §6.

### 2.6 Коэффициенты и LFA-таблицы

Все коэффициенты — функции `E/N` на грани:
`mu_e*N`, `D_e*N`, `alpha/N` (ионизация), `eta_2/N` (диссоц. прилипание), `eta_3/N²`
(трёхтельное прилипание). Табулируются в лог-равномерной сетке по `E/N` в диапазоне
0.1–1000 Td, 256 точек, линейная интерполяция по `log10(E/N)`:

```js
// idx = (log10(EN) - L0) * invDL   -> целая часть + дробная, 2 умножения
```

Никаких `Math.pow`/`Math.exp` в горячем цикле для коэффициентов. `Math.log10` на грань —
один вызов; можно заменить на извлечение экспоненты из битового представления double
(быстрый log2) при необходимости.

Поле на грани для коэффициентов берём как `E_{i+1/2} = -(phi_{i+1} - phi_i)/h_{i+1/2}`.
Для источников в ячейке — `E_i = 0.5*(E_{i-1/2} + E_{i+1/2})` (или модуль по среднему
квадрату, но простое среднее достаточно).

## 3. Уравнение Пуассона

### 3.1 Постановка

```
d/dx ( eps(x) * dphi/dx ) = -rho(x),      rho = e * (n_+ - n_- - n_e)
```
плюс поверхностный заряд `sigma_1`, `sigma_2` на границах газ/диэлектрик,
плюс ГУ `phi = U_el(t)` на левом металле, `phi = 0` на правом.

### 3.2 Конечно-объёмная дискретизация с переменным eps

Интегрируем по ячейке `i` (`D = -eps dphi/dx` — электрическая индукция):

```
D_{i+1/2} - D_{i-1/2} = rho_i * dx_i
D_{i+1/2} = -eps_{i+1/2} * (phi_{i+1} - phi_i) / h_{i+1/2}
```

**Проницаемость на грани — ГАРМОНИЧЕСКОЕ среднее по толщинам полуячеек:**

```
eps_{i+1/2} = (dx_i + dx_{i+1}) / ( dx_i/eps_i + dx_{i+1}/eps_{i+1} )
```

Это не косметика. Гармоническое среднее эквивалентно последовательному соединению двух
конденсаторов и воспроизводит скачок `E` на границе двух сред **точно** (нормальная компонента
`D` непрерывна). Арифметическое среднее даёт ошибку ~`(eps_r-1)/(eps_r+1)` = 80% при `eps_r=9`
в поле у границы — неприемлемо, так как именно это поле определяет момент зажигания.

Матрица трёхдиагональная:

```
a_i = -eps_{i-1/2}/h_{i-1/2}
c_i = -eps_{i+1/2}/h_{i+1/2}
b_i = -(a_i + c_i)
b_i*phi_i + a_i*phi_{i-1} + c_i*phi_{i+1} = rho_i*dx_i     (знаки: см. код ниже)
```

Решается прогонкой (алгоритм Томаса), O(Nx), ~8 flop/ячейку. Матрица симметрична и
диагонально доминантна -> прогонка безусловно устойчива, пивотинг не нужен.

### 3.3 Граница газ/диэлектрик и поверхностный заряд

Пусть слева от газа барьер толщиной `d1`, проницаемость `eps_d = eps0*eps_r`, потенциал
металла `U_el`. Потенциал в барьере линеен, поэтому вводим только неизвестную `phi_s1` —
потенциал поверхности — и исключаем её.

Проводимости («ёмкости на единицу площади»):

```
g_d = eps0*eps_r / d1          (весь барьер целиком — точно, без дискретизации!)
g_g = eps0 / (dx_1 / 2)        (полуячейка газа)
```

Условие Гаусса на поверхности с нормалью `n = +x` (из барьера в газ):
`D_gas - D_diel = sigma_1`. Подставляя `D_diel = -g_d*(phi_s1 - U_el)`,
`D_gas = -g_g*(phi_1 - phi_s1)`:

```
phi_s1 = ( -sigma_1 + g_d*U_el + g_g*phi_1 ) / (g_d + g_g)
```

Отсюда индукция на первой грани (со стороны газа), которая и входит в баланс ячейки 1:

```
D_{1/2} = -G1*(phi_1 - U_el)  -  (g_g/(g_g+g_d)) * sigma_1 * (-1)
```
раскрывая аккуратно:

```
G1 = g_g*g_d/(g_g + g_d)                       (эффективная проводимость грани)
D_{1/2} = -G1*(phi_1 - U_el) + [g_g/(g_g+g_d)] * sigma_1     ... (знак зависит от
                                                                 ориентации нормали)
```

**Практическая форма для сборки матрицы** (проверенная на тесте §8.1c): вклад левой границы
в строку 1:

```
b_1 += G1
rhs_1 += G1*U_el  -  w1*sigma_1,     w1 = g_g/(g_g + g_d)
```

Симметрично справа (`d2`, `phi = 0` на правом металле, `sigma_2`), с весом
`w2 = g_g_right/(g_g_right + g_d2)`.

Заметим: `G1` — та же гармоническая формула, что и в §3.2, только с `a_d = d1` (полная
толщина барьера, а не полуячейка), потому что в барьере профиль точный. То есть код сборки
единый; барьер — просто «ячейка» с полушириной `d1` и `eps_r`, у которой второй сосед — металл.

Проверка непротиворечивости: разность индукций по разные стороны поверхности равна
`sigma_1 * (g_d + g_g)/(g_d + g_g) = sigma_1` — условие Гаусса выполняется тождественно,
а не приближённо. Это гарантирует точное сохранение заряда на поверхности.

### 3.4 Обновление поверхностного заряда

```
sigma_1^{n+1} = sigma_1^n + dt * sum_s ( z_s * e * Gamma_s,wall1 )
```
где `Gamma_s,wall1` — поток НА стенку (положительный, если частица уходит в стенку слева,
знак по нормали наружу). Ионы нейтрализуются, электроны прилипают; в этой модели считаем
коэффициент прилипания 1 и не даём заряду растекаться (проводимость поверхности = 0;
опция `sigma_surf_leak` для затухания с постоянной времени 1–100 мс — полезна, чтобы
фигура Лиссажу замыкалась в реальных приборах).

Граничные потоки — по Хагелаару (учёт теплового и дрейфового вклада):

```
Gamma_s,wall = (1/4)*v_th,s*n_s,wall  +  a * z_s*mu_s*E_wall*n_s,wall  -  gamma_se*Gamma_ion
a = 1, если дрейф направлен к стенке, иначе 0
v_th,s = sqrt(8*k*T_s/(pi*m_s))
```
Вторичная эмиссия `gamma_se = 0.01..0.05` для Al2O3 — она критична: без неё таунсендовский
режим не поджигается при разумных напряжениях. Эмитированные электроны добавляются как
входящий поток в первую ячейку.

### 3.5 Внешний последовательный резистор

`U_el = U_src(t) - R * I(t)`, а `I` зависит от `phi`. Задача линейна по `(U_el, rho, sigma)`,
поэтому используем суперпозицию: решаем две прогонки с одной и той же матрицей,

```
phi = phi_A + U_el * phi_B
phi_A : rhs с реальными rho, sigma, но U_el = 0
phi_B : rhs = 0, U_el = 1  (единичный отклик, «лапласовское» решение)
```

Ток по Сато–Морроу (§7) тоже линеен: `I = I_A + U_el * k_B`. Подставляем в
`U_el = U_src - R*I`:

```
U_el = (U_src - R*I_A) / (1 + R*k_B)
```

Одно скалярное уравнение, две прогонки на шаг. Стоимость ничтожна (~2×8×Nx flop).
Побочная выгода: `phi_B` даёт весовое поле `E_L` для формулы Сато–Морроу бесплатно.

## 4. Снятие жёсткости

### 4.1 Диагноз

Три источника жёсткости:

| Механизм | Характерное время | Комментарий |
|---|---|---|
| Диэлектрическая релаксация `tau_d = eps0/(e*n_e*mu_e)` | 1e-13 … 1e-11 с | при `n_e = 1e20..1e22 м^-3` |
| Дрейфовый CFL электронов | ~1e-11 с | `dx=3мкм, v=1.5e5 м/с` |
| Ионизация `1/(alpha*v_e)` | ~2e-10 с | при 200 Td |
| Период поля | 1e-4 с | 10 кГц |
| Химия озона `O+O2+M` | 1e-5 … 1e-4 с | «обратная» жёсткость |

Явная схема ограничена `tau_d` -> `1e-4/1e-13 = 1e9` шагов на период. Недопустимо.
Убрав только `tau_d`, получаем ограничение CFL `1e-11` -> `1e7` шагов, если бы шаг был
постоянным; адаптивность (§5) сбивает это до `3e4..1e5`, потому что реально жёсткая фаза
занимает доли процента периода.

### 4.2 Полунеявная (заряд-сохраняющая) схема — снятие tau_d

Схема Вентцека/Хагелаара (semi-implicit, implicit displacement current). Идея: подставить
в уравнение Пуассона на новом слое закон сохранения заряда, а зависимость тока от поля
линеаризовать.

```
div(eps * grad phi^{n+1}) = -rho^{n+1}
rho^{n+1} = rho^n - dt * div( J^{n+1} )
J^{n+1} ≈ J^* + sigma_cond * ( E^{n+1} - E^n )
```
где `J^*` — ток, вычисленный явно по старому полю (включая диффузионную часть), а
`sigma_cond = sum_s |q_s| * mu_s * n_s` — локальная проводимость. Подставляя `E = -grad phi`:

```
div[ (eps + dt*sigma_cond) * grad phi^{n+1} ]  =  -rho^n  +  dt * div( J^* + sigma_cond*grad phi^n )
```

**Это и есть рабочее модифицированное уравнение Пуассона.** Всё, что меняется в коде:

1. на гранях вместо `eps_{i+1/2}` подставляем `eps_eff_{i+1/2} = eps_{i+1/2} + dt*sigma_{i+1/2}`;
2. в правую часть добавляется дивергенция известного вектора
   `F_{i+1/2} = dt*( J^*_{i+1/2} - sigma_{i+1/2} * E^n_{i+1/2} )`, то есть
   `rhs_i += (F_{i+1/2} - F_{i-1/2})`.

Структура матрицы не меняется — та же прогонка. Стоимость: пересборка коэффициентов
каждый шаг (`dt` и `sigma` меняются), ~10 flop/грань.

Проводимость на грани берём **согласованно с SG-потоком**, а не «просто» `|q|mu n`.
Линеаризуем поток по полю: `dGamma/dE ≈ z_s*mu_s*n_upwind`, поэтому

```
sigma_{i+1/2} = sum_s  e * mu_{s,i+1/2} * n_{s,upwind(s)}
```
с апвиндом, определяемым знаком `z_s * E_{i+1/2}` для каждого сорта отдельно. Это даёт
точную линеаризацию в дрейфовом пределе и заметно лучшее поведение схемы, чем среднее
по грани (нет ложных отрицательных проводимостей при больших градиентах).

Почему это снимает `tau_d`: в чисто релаксационном пределе (однородная плазма, нет
источников) схема сводится к `E^{n+1} = E^n * eps/(eps + dt*sigma) = E^n /(1 + dt/tau_d)`.
Это A-устойчивая (L-устойчивая) аппроксимация точного `exp(-dt/tau_d)`: при `dt >> tau_d`
поле корректно уходит в ноль, а не осциллирует и не взрывается, как при явной схеме
(`E^{n+1} = E^n(1 - dt/tau_d)`, неустойчива при `dt > 2*tau_d`). Ограничение по `tau_d`
исчезает полностью; остаётся ограничение по точности, а не по устойчивости.

Поверхностный заряд тоже включаем полунеявно: линеаризация пристеночного потока по полю
добавляет `dt*e*mu_s*n_s,wall` к проводимости граничной грани, то есть просто входит в
`g_g` при сборке §3.3 как `g_g_eff = eps0/(dx1/2) + dt*sigma_wall`. Без этого при сильном
токе на стенку схема снова становится жёсткой в момент зарядки поверхности.

### 4.3 Экспоненциальный интегратор для источников

После транспорта источники в каждой ячейке решаем локально. Для каждого сорта приводим
правую часть к виду «производство минус линейная гибель»:

```
dn/dt = P - L*n
```
и интегрируем **точно** для замороженных `P, L`:

```
n^{n+1} = n^n * exp(-L*dt) + (P/L) * (1 - exp(-L*dt))
```
с устойчивым пределом `L -> 0`:
```
n^{n+1} = n^n + dt*P  -  dt*L*n^n + O(dt^2)     // использовать -expm1(-L*dt)/L
```

Практично: `phi1 = -Math.expm1(-L*dt)/L` при `L*dt > 1e-8`, иначе `phi1 = dt*(1 - 0.5*L*dt)`.
Тогда `n^{n+1} = n^n + phi1*(P - L*n^n)`.

Свойства: безусловная устойчивость по реакциям, **строгая положительность** (`n >= 0` при
`n^n >= 0, P >= 0, L >= 0`) — это главное, при явном Эйлере прилипание с `L*dt > 1` даёт
отрицательные плотности и мгновенный разлёт схемы.

Для электронов чистая экспонента (нетто-рост лавины):

```
nu_net = alpha*|v_e| - eta_2*|v_e| - eta_3*|v_e|         [1/с]
n_e^{n+1} = n_e * exp(nu_net*dt)   плюс источники от фотоионизации/фона
```
Это точное решение линейного роста и **снимает ограничение шага по ионизации**. Оставляем
только ограничение по точности `nu_net*dt < 0.2` (§5), потому что лавина обратно влияет
на поле.

Для системы связанных сортов (e -> O-, O2-; O2+ рекомбинация) используем последовательный
Гаусс-Зейделевский проход в порядке e, O2+, O-, O2- с уже обновлёнными значениями —
первый порядок по расщеплению, но положительность сохраняется, а `dt` у нас всё равно
ограничен полем.

Ключевые реакции (константы из таблиц LFA / литературы):

```
e + O2      -> O2+ + 2e        alpha(E/N)          [ионизация]
e + O2      -> O-  + O         eta_2(E/N)          [диссоц. прилипание]
e + 2 O2    -> O2- + O2        eta_3(E/N) * N      [трёхтельное]
O-  + O2+   -> O + O2          ~2e-13 м³/с         [ион-ионная рекомбинация]
O2- + O2+   -> 2 O2            ~2e-13 м³/с
O-  + O2    -> O3 + e          ~5e-21 м³/с         [отлипание, важно!]
O + O2 + M  -> O3 + M          6.4e-46 м⁶/с        [озон]
```

### 4.4 Двухмасштабное расщепление: медленная химия отдельно

`O` и `O3` не заряжены и не влияют на поле. Их характерные времена — 1e-5..1e-2 с, то есть
на шаге `dt = 1e-11` они не меняются вовсе, и считать их на каждом шаге — чистая потеря
~20% времени.

**Решение:** аккумулируем производство `O` за интервал `dt_slow` (источник от диссоциации
и прилипания), а систему `{O, O3, O2(a)}` интегрируем один раз на `dt_slow ~ 1e-7..1e-6 с`
тем же экспоненциальным интегратором + диффузия (неявная трёхдиагональная, шаг большой).
Экономия ~15–25% общего времени и отсутствие лишней жёсткости.

### 4.5 Порядок операций на шаге (расщепление Ли–Троттера)

```
step(dt):
  1.  E^n на гранях из phi^n;  E/N;  LFA-таблицы -> mu, D, alpha, eta
  2.  явные SG-потоки Gamma_s^*  для всех заряженных сортов
  3.  sigma_cond на гранях (апвинд по каждому сорту)
  4.  сборка полунеявного Пуассона: eps_eff = eps + dt*sigma_cond;
      rhs = -rho^n + div(dt*(J^* - sigma*E^n)) + граничные вклады (U_el, sigma_surf)
  5.  две прогонки (phi_A, phi_B) -> U_el из уравнения цепи -> phi^{n+1}, E^{n+1}
  6.  коррекция потоков: Gamma_s = Gamma_s^* + z_s*mu_s*n_upwind*(E^{n+1} - E^n)
      (это ровно та линеаризация, что заложена в п.4 -> схема согласована и сохраняет заряд
       машинно точно: сумма q*div(Gamma) в точности равна изменению rho, «зашитому» в Пуассон)
  7.  консервативное обновление n_s по div(Gamma)
  8.  пристеночные потоки -> sigma_surf^{n+1}
  9.  источники: экспоненциальный интегратор при E^{n+1}
  10. клип положительности (floor 1e0 м^-3) с учётом инжектированного заряда в диагностику
  11. накопление медленной химии; каждые dt_slow — шаг §4.4
  12. диагностика: I(t) по Сато–Морроу, Q(t), энергия
```

Пункт 6 принципиален: если обновлять плотности потоками, посчитанными по СТАРОМУ полю,
схема перестаёт быть заряд-сохраняющей и появляется дрейф `div(eps E) != rho`, который
за 1e5 шагов накапливается в проценты. С коррекцией невязка Пуассона остаётся на уровне
1e-12 относительных.

## 5. Шаг по времени

### 5.1 Ограничители

```
dt_drift  = CFL * min_i,s ( dx_i / |v_s,i| )                 CFL = 0.4 (demo 0.8, accurate 0.2)
dt_diff   = 0.4 * min_i,s ( dx_i^2 / (2*D_s,i) )             только если диффузия явная
dt_reac   = 0.2 / max_i |nu_net,i|                           точность лавины
dt_field  = dE_tol * max|E| / max|dE/dt|,  dE_tol = 0.02..0.05
dt_relax  = K_relax * min tau_d,  K_relax = 50                МЯГКИЙ страховочный, не обязателен
dt_surf   = 0.05 * min( |sigma_surf| + sigma_ref ) / |dsigma/dt|
```

`dt_relax` при полунеявной схеме НЕ нужен для устойчивости — оставляем с большим `K_relax`
только как детектор аномалий (если он срабатывает, значит `sigma_cond` посчитана неверно).

Диффузия: при `dx_min = 1.5 мкм`, `D_e = 0.15` -> `dt_diff = 0.4*2.25e-12/0.3 = 3e-12 с`,
это ЖЁСТЧЕ дрейфового CFL (1e-11..4e-12). Поэтому:
**решение — диффузию электронов делать неявно.** В 1D это ещё одна трёхдиагональная прогонка
на сорт (или на один только электронный сорт, ионы диффундируют пренебрежимо). Разделяем
SG-поток на дрейфовую (явно) и диффузионную (неявно) части нельзя без потери точности SG,
поэтому проще: если `dt_diff < 0.5*dt_drift`, включаем полностью неявный SG-транспорт для
электронов (матрица `I + dt*A_SG` трёхдиагональна, M-матрица, положительность гарантирована).
Иначе — явно. Это одна ветка и +8 flop/ячейку, зато `dt` определяется дрейфом.

### 5.2 Контроллер

```js
let dtNew = Math.min(dtDrift, dtDiff, dtReac, dtField, dtSurf);
dtNew = Math.min(dtNew, 1.25 * dt);            // мягкий рост, не более +25% за шаг
dtNew = clamp(dtNew, DT_MIN, DT_MAX);          // DT_MIN=1e-14, DT_MAX=2e-8
```

**Отбраковка шага (step rejection).** После шага проверяем:
- `min n_s < -1e-6 * max n_s`  -> отрицательные плотности сверх шума;
- `max |E^{n+1} - E^n| / max|E| > 3*dE_tol`;
- невязка Пуассона `> 1e-8` относительно.

Если сработало — откат состояния (держим теневые копии массивов), `dt *= 0.4`, повтор.
Частота отбраковки в норме < 0.5%; если больше — падают лимиты. Счётчик отбраковок
выводится в диагностику: рост — верный признак того, что физические параметры увели
модель в нефизичный режим.

### 5.3 Стратегия «тёмная фаза / филамент»

Ключ к производительности. Фаза без плазмы (`max n_e < 1e13 м^-3`) занимает 90–97% периода,
и там нет ни лавины, ни релаксации: ячейка — просто три последовательных конденсатора.

Два уровня ускорения:

1. **Мягкий (по умолчанию):** в тёмной фазе активны только `dt_field` и `dt_drift` по ионам
   (медленные) -> `dt` вырастает до `DT_MAX = 2e-8 с` (~5000 шагов на период на тёмную фазу
   при `dE_tol=0.02`, что даёт разрешение синусоиды в 5000 точек — с большим запасом).
2. **Агрессивный (режим demo):** при `max n_e < n_dark` полностью пропускаем транспорт
   электронов и решаем аналитическую капацитивную задачу — `phi` линеен в каждой среде,
   поле считается делителем ёмкостей за O(1). Транспорт ионов подшагиваем раз в 20 шагов.
   Тёмная фаза схлопывается до ~1000 шагов.

Выход из тёмной фазы детектируем по критерию **до** взрыва: как только
`max_i (alpha_eff(E_i) * v_e,i) * dt > 0.05` или `max n_e > n_dark`, принудительно
`dt = 1e-12` и включаем полный солвер. Запас по фазе — примерно 1 мкс до пробоя,
чего с избытком.

## 6. Производительность и «реальное время» — честная оценка

### 6.1 Честно: физического реального времени не будет

Период 10 кГц = 100 мкс. Нижняя граница числа шагов при `dt` не выше дрейфового CFL в
активной фазе — примерно `3e4..1e5` шагов на период (см. таблицу). Даже при фантастических
1 мкс на шаг это 0.03–0.1 с на период против 1e-4 с реального времени, то есть
**замедление минимум в 300–1000 раз**, а реалистично — в 2e4–5e4 раз. Ускорение до
настоящего real-time потребовало бы отказа от 1D fluid-модели в пользу подгонянной
0D/цепевой модели, что убивает всю запрошенную физику (профили, слои, фронт лавины).

**Что делаем вместо этого — и почему это лучше для UI:** настоящий период 10 кГц при 60 fps
занял бы 0.006 кадра — зритель не увидел бы ничего. Нам НУЖНО замедление ~1e4. Целевой
показатель: **один период сети проигрывается за 2–10 секунд стенных часов**, филамент
(~200 нс физического времени) растянут на ~1–2 секунды. Это и продаём как «реальное время»
в UI: непрерывная, не заикающаяся анимация при интерактивном изменении U0, f, d_gap.

### 6.2 Бюджет шага

`Nx = 300`, 4 заряженных сорта, 301 грань.

| Операция | Оценка | Время (V8, Float64Array) |
|---|---|---|
| LFA lookup на грань (log10 + интерп × 5 таблиц) | 301 × ~25 flop + 1 log | 4–6 мкс |
| SG-потоки, 4 сорта (в основном апвинд-ветвь) | 1204 граней × ~15 flop, ~150 expm1 | 8–14 мкс |
| sigma_cond | 1204 × 4 flop | 2 мкс |
| Сборка + 2 прогонки Пуассона | ~2 × 10 × 300 flop | 3–4 мкс |
| Обновление плотностей + коррекция потока | 1200 × 8 flop | 3 мкс |
| Источники, экспоненциальный интегратор | 300 × 4 × (1 exp + 15 flop) | 8–12 мкс |
| Диагностика (Сато–Морроу интеграл) | 300 × 6 flop | 1 мкс |
| **Итого** | | **30–45 мкс/шаг** |

Проверено допущение: `Math.exp/expm1` в V8 ~15–25 нс. Именно поэтому §2.5 (апвинд-ветвь при
`|X|>40`) даёт экономию порядка 10 мкс/шаг — электроны в активной фазе почти всегда там.

### 6.3 Шаги на период

| Фаза | Доля периода | Типичный dt | Шагов |
|---|---|---|---|
| Тёмная (мягкий режим) | ~97% (9.7e-5 с) | 2e-8 | ~5 000 |
| Предпробой (рост лавины) | 2 × 1 мкс | 1e-11..1e-12 | ~2 × 6 000 |
| Филамент (пик тока) | 2 × 200 нс | 3e-13..2e-12 | 2 × ~5 000 |
| Спад / зарядка поверхности | 2 × 2 мкс | 1e-11 | 2 × 2 000 |
| **Итого** | | | **~31 000 шагов/период** |

- `default` (Nx=300, CFL=0.4): ~3.1e4 шагов × 38 мкс = **1.2 с на период**.
- `accurate` (Nx=800, CFL=0.2): ~2.5e5 шагов × 110 мкс = **28 с на период**.
- `demo` (Nx=200, CFL=0.8, агрессивная тёмная фаза): ~1.2e4 шагов × 22 мкс = **0.27 с/период**.

### 6.4 Архитектура «солвер — рендер»

Солвер в Web Worker, UI в главном потоке. **Не** синхронизировать «шаг = кадр».

```
Worker:
  loop:
    tBudget = 8 ms                       // 8 из 16.7 мс — запас на GC и рендер
    t0 = performance.now()
    while (performance.now() - t0 < tBudget) { step(dt); }
    if (simTime - lastSnap >= snapInterval) pushSnapshot();  // ring buffer
    postMessage(snapshot, [transferable])  // не чаще ~60 Гц
```

`snapInterval` — по **симуляционному** времени, адаптивный: логарифмический по фазе
(в филаменте кадры каждые 5 нс симуляции, в тёмной фазе — каждые 2 мкс), чтобы анимация
шла с равномерной «интересностью», а не залипала на 97% периода в статике.

Снапшот: `n_e, n_i, n_neg, rho, E, phi` по 200 точкам (даунсэмпл с 300/800) + скаляры
(`t, U, I, Q, sigma1, sigma2, P`). Это ~6×200×4 байта (Float32 достаточно для отрисовки)
= 4.8 КБ на кадр -> 290 КБ/с. Передавать через `transferable` ArrayBuffer из пула
двойной буферизации, чтобы не аллоцировать в цикле (GC-паузы = дёрганая анимация).

Ring buffer на ~600 снапшотов (3 МБ) позволяет UI играть с постоянной скоростью и
поддерживать «scrub»/паузу/замедление, даже если worker временно отстал.

Режимы в UI:
- **«Быстрая модель»**: demo-профиль + повышенная затравка `n_seed = 1e13 м^-3` (вместо
  1e6–1e9) и/или `f = 1 кГц` -> пробой воспроизводимо на каждом полупериоде, никакой
  статистики зажигания, ~0.3 с/период. Честно помечать в UI: «ускоренная модель, затравка
  завышена, амплитуда тока и число филаментов не количественны».
- **«Физически точный»**: accurate-профиль, реальная затравка, фоновая ионизация
  1e9–1e12 м^-3 с^-1, 28 с/период. Запускается по кнопке, результат проигрывается из буфера.

## 7. Диагностика, ток и консервативность

### 7.1 Ток: формула Сато–Морроу

```
I(t) = A * integral_gap [ e*(Gamma_i - Gamma_e - Gamma_neg) * E_L(x) ] dx  +  C_cell * dU_el/dt
```

где `E_L(x)` — **весовое (лапласовское) поле**: решение `div(eps grad phi_L) = 0` при
`phi_L = 1` на питаемом электроде и `0` на земле, `E_L = -dphi_L/dx`. В нашей геометрии оно
известно аналитически:

```
d_eff = d_gap + (d1 + d2)/eps_r
E_L,gas  = 1 / d_eff        [1/м]
E_L,diel = 1 / (eps_r*d_eff)
C_cell   = eps0 * A / d_eff
```

**Важно: наивное `e*A/d_gap` неверно** — оно завышает ток в `d_eff/d_gap` раз
(при `d_gap=1мм, d1=d2=0.5мм, eps_r=9`: `d_eff = 1.111 мм`, ошибка 11%). Барьеры входят
в весовое поле, и игнорировать их нельзя. В коде `E_L` берём как готовое `phi_B` из §3.5 —
это ровно то же самое решение, посчитанное численно (полезно как встроенный тест: численный
`E_L` должен совпасть с аналитическим до 1e-12).

### 7.2 Почему не dQ/dt

1. **Отношение сигнал/шум.** Заряд на электроде `Q = C_cell*U + Q_plasma`. При 10 кВ
   `C_cell*U ≈ 7.9e-11 Ф/м²·... ~ 8e-8 Кл`, а заряд одного филамента — 1e-9..1e-8 Кл.
   Численное дифференцирование разности двух больших близких чисел с адаптивным `dt`
   усиливает шум как `1/dt`: при `dt=3e-13` относительная ошибка `Q` в 1e-12 превращается
   в ошибку тока порядка мА при полезном сигнале в мА. Метод разваливается ровно там, где
   он нужен.
2. **Локальность.** `Q` определяется полем в ОДНОЙ точке (на электроде) — это самая
   неточная величина в сетке (крайняя полуячейка, максимальный градиент). Сато–Морроу —
   интеграл по объёму: погрешности усредняются, сходимость по сетке на порядок быстрее.
3. **Мгновенность и физичность.** Формула Шокли–Рамо/Сато даёт индуцированный ток в момент
   движения заряда, а не в момент его прихода на электрод. Именно она воспроизводит
   наносекундный импульс тока филамента правильной формы и длительности.
4. **Разделение вкладов.** Формула явно разделяет кондукционный (первый член) и смещения
   (второй) вклады — это нужно UI: показать, что в тёмной фазе ток чисто ёмкостный.
5. **Совместимость со схемой.** В полунеявной схеме `E^{n+1}` уже содержит неявную поправку
   по току; `dQ/dt` из такого поля даёт ток, «размазанный» линеаризацией, а интеграл
   Сато–Морроу считается по согласованным потокам п.6 из §4.5.

`dQ/dt` при этом **вычисляем тоже** — но как независимую перекрёстную проверку (§8.6),
а не как основной канал.

### 7.3 Проверки консервативности (в рантайме, дёшево)

```
C1. Невязка Пуассона:   max_i | div(eps grad phi)_i + rho_i | / (e*max n)   < 1e-8
C2. Баланс заряда:      d/dt [ integral rho dx + sigma_1 + sigma_2 ]  ==  0
                        (в закрытой ячейке полный заряд системы + электродный сохраняется)
C3. Баланс электронов:  dN_e/dt = integral (alpha - eta)*|v_e|*n_e dx - Gamma_wall,1 - Gamma_wall,2
                        относительная невязка < 1e-6
C4. Энергия:            U_el * I(t)  ==  integral J*E dx * A  +  d/dt(энергия поля)
                        расхождение < 0.5%
C5. Инжектированный заряд от клипа положительности: суммарно < 1e-6 от перенесённого заряда.
C6. Замкнутость фигуры Лиссажу: |Q(t+T) - Q(t)| / Q_max < 1e-3 после переходного процесса.
```

C5 особенно важен: клип `n = max(n, floor)` — это скрытый источник заряда. Логируем
`sum(dn_clip * dx * q)` и показываем в диагностической панели. Если он растёт — схема
теряет положительность и нужен неявный транспорт (§5.1).

### 7.4 Метод Мэнли (Q–V фигура)

`Q(t) = integral I(t) dt` (интегрируем ток Сато–Морроу трапециями с накоплением по Кэхэну —
за 3e4 шагов простое суммирование теряет ~4 цифры). Строим `Q` против `U_el`.

Из параллелограмма:
- наклон «горящих» сторон (разряд активен) = `C_diel = eps0*eps_r*A/(d1+d2)`;
- наклон «тёмных» сторон = `C_cell = eps0*A/d_eff`;
- площадь = энергия за период, `P = f * Area`;
- пересечение с осью U даёт `U_min` (напряжение горения) и `U_burn` на зазоре.

Извлечение наклонов — робастная линейная регрессия по 4 сегментам, разделённым по знаку
`dU/dt` и по признаку `I_cond > порог`. Восстановленные `C_diel, C_cell` **обязаны** совпасть
с аналитическими в пределах 2% — это интегральный тест всей модели (§8.7).

## 8. Программа численных тестов

Все тесты — автоматические (`npm test`), с числовыми допусками, в CI.

**8.1 Пуассон.**
 a) Вакуум, `rho=0, sigma=0` -> `phi` линеен, ошибка < 1e-14 (машинная).
 b) Однородный `rho` -> парабола, точное решение известно, ошибка < 1e-12 на любой сетке
    (FV с гармоническим eps точна для квадратичных при постоянном eps).
 c) Трёхслойный конденсатор без заряда -> делитель ёмкостей:
    `E_gas = U/d_eff` с ошибкой < 1e-13; проверка ГУ §3.3.
 d) Лист поверхностного заряда `sigma_1` при `U=0` -> проверка скачка `D_gas - D_diel = sigma`
    до 1e-13 и полей по обе стороны против аналитики.
 e) Manufactured solution с плавно переменным `eps(x)` на НЕравномерной сетке ->
    порядок сходимости по `L2` должен быть 2.0 ± 0.1 (Nx = 50..800).

**8.2 Чистый дрейф.** Гауссиан, `D=0`, `E=const`, периодические/протяжённые ГУ.
 - положение максимума после времени `t`: `x0 + v*t`, ошибка < 0.5% от ширины;
 - масса сохраняется до 1e-14;
 - **измеряем численную диффузию:** рост дисперсии `d(sigma^2)/dt` -> сравнить с
   теоретической `|v|*h` (апвинд) и убедиться, что SG в этом пределе ей эквивалентна
   (SG при D=0 = апвинд, это ожидаемо). Тест фиксирует величину, чтобы отслеживать регрессии.

**8.3 Чистая диффузия.** Гауссиан, `v=0` -> `sigma^2(t) = sigma_0^2 + 2Dt`, ошибка < 1%;
 сохранение массы 1e-14.

**8.4 Дрейф-диффузия, стационар (главный тест SG).** Постоянное `E`, поглощающие стенки,
 источник в центре -> аналитический экспоненциальный профиль `n ~ exp(v x/D)`.
 SG должна давать **машинную точность на грубой сетке** (Nx = 20), апвинд — ошибку в разы.
 Это прямая проверка, что SG реализована верно, а не «почти».

**8.5 Полунеявная схема / релаксация.** Однородная проводящая плазма без источников,
 начальное поле `E0`. Точное решение `E(t) = E0*exp(-t/tau_d)`.
 - при `dt = 0.1*tau_d`: ошибка < 2%;
 - при `dt = 100*tau_d`: **схема устойчива**, поле монотонно -> 0 (явная схема здесь
   обязана взорваться — тест проверяет и это, как negative control).

**8.6 Ток и сохранение заряда.**
 - `I_SatoMorrow(t)` vs `dQ_electrode/dt` на длинном прогоне: расхождение < 1% RMS
   (после сглаживания второго);
 - `integral I dt` за целый период после установления `< 1e-3 * Q_max`;
 - баланс C2, C3 из §7.3 на 10 периодах.

**8.7 Таунсенд/пробой (физическая валидация).**
 - Без объёмного заряда, засветка с катода: `n_e(x) ~ exp(alpha_eff*x)` — восстановленная
   из решения `alpha_eff` совпадает с табличной в пределах 1%;
 - Напряжение пробоя 1 мм O2 при 1 атм: ожидаем `E_bd ≈ 30–35 кВ/см`, то есть `U_bd ≈ 3–3.5 кВ`
   на зазоре (порог `alpha = eta` при `E/N ≈ 100–130 Td`). Допуск ±15%: это проверка таблиц
   LFA, а не схемы.
 - Восстановленные из Q–V фигуры `C_diel` и `C_cell` совпадают с аналитическими в пределах 2%.

**8.8 Сеточная и временная сходимость.**
 - Перенесённый за импульс заряд `Q_pulse` при Nx = 200/400/800: изменение < 5% на последнем
   удвоении;
 - при CFL = 0.8/0.4/0.2: изменение `Q_pulse` < 3%;
 - пиковый ток и его FWHM — те же критерии (они чувствительнее, допуск 10%).

**8.9 Положительность и робастность.** Стресс-прогон: `U0 = 15 кВ, f = 50 кГц, d_gap = 0.5 мм`,
 20 периодов. Требования: ни одной отрицательной плотности сверх шума, отбраковок < 1%,
 `dt` не залипает на `DT_MIN`, C1–C6 держатся.

## 9. Сводка решений (TL;DR)

| Вопрос | Решение |
|---|---|
| Сетка | 300 ячеек в газе, tanh-сгущение к стенкам, `dx_min` 1.5 мкм; барьеры **не** дискретизируются |
| Барьеры | аналитическое исключение в ГУ Робина, `g_d = eps0*eps_r/d` — точно |
| Потоки | Шарфеттер–Гуммель, `Gamma = (D/h)[n_i B(-X) - n_{i+1} B(X)]`, `X = v h/D` |
| B(x) | `x/expm1(x)`, ветви `|x|>40` -> апвинд, `|x|<1e-10` -> `1-x/2` |
| Пуассон | FV, **гармоническое** среднее eps на грани, прогонка Томаса, sigma в rhs с весом `g_g/(g_g+g_d)` |
| Резистор | суперпозиция `phi = phi_A + U_el*phi_B`, скалярное уравнение цепи |
| Жёсткость поля | полунеявно: `div[(eps + dt*sigma_cond) grad phi^{n+1}] = -rho^n + dt div(J^* + sigma grad phi^n)` |
| sigma_cond | `sum_s e*mu_s*n_{s,upwind}` на грани (согласованно с SG) |
| Источники | экспоненциальный интегратор `n += phi1(L dt)*(P - L n)`, положительность гарантирована |
| Нейтралы | отдельное медленное расщепление, `dt_slow ~ 1e-6 с` |
| Шаг | адаптивный, min(дрейф, диффузия, реакция, dE/E, поверхность), 1e-14…2e-8, отбраковка ×0.4 |
| Тёмная фаза | dt до 2e-8 (мягкий) / аналитический капацитивный пропуск (demo) |
| Ток | Сато–Морроу с весовым полем `E_L = 1/d_eff` в газе, **не** `dQ/dt` |
| Real-time | физического нет и быть не может; цель — 1 период за 1–3 с, солвер в Worker, ring buffer снапшотов |
| Оценка | ~3.1e4 шагов/период, 30–45 мкс/шаг, ~1.2 с/период (default) |

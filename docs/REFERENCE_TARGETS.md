## 2. Самоподдержание разряда, U_br(γ)

Численный корень критерия для электроотрицательного газа

```
γ · α/(α − η) · [ exp((α − η)·d) − 1 ] = 1 ,   d = 1 мм
```

Упрощённая форма `(α − η)d = ln(1 + 1/γ)` НЕ используется (она даёт 146.0 Тд
при γ = 0.02, то есть завышает).

| γ | E/N, Тд | E, кВ/см | **U_br, кВ** | (α−η)·d |
|---|---|---|---|---|
| 0.005 | 148.56 | 36.34 | **3.634** | 4.567 |
| 0.010 | 145.41 | 35.57 | **3.557** | 3.777 |
| 0.020 | 141.97 | 34.73 | **3.473** | 2.960 |
| 0.050 | 136.88 | 33.49 | **3.349** | 1.820 |

Допуск для тестов: **5 %**.

Независимая проверка тем же критерием, но на числах ТОЛЬКО из опубликованной
таблицы Phelps (без нашего решателя): γ = 0.02 → 140.4 Тд, **3.434 кВ**
(на 1.1 % ниже). γ = 0.005 → 3.586 кВ, γ = 0.05 → 3.314 кВ.

γ **не является** калибруемым параметром (ERRATA §C1): U_br предъявляется как
функция γ, а не как независимое подтверждение физики.

### ⚠ U_br УМЕНЬШИЛСЯ, а не вырос — и это не ошибка

`ERRATA §C0` предполагала, что раз критическое поле выросло на ~26 %, то и U_br
должен вырасти (ожидалось 4.3–4.9 кВ). **Численный расчёт этого не подтверждает:**
U_br(γ=0.02) упал с 3.75 кВ (старые коэффициенты) до 3.47 кВ, то есть на 7 %.

Причина — ровно та, о которой ERRATA сама предупреждала («форма кривой α−η
изменилась нелинейно»). Точка α = η сдвинулась вверх (101→128 Тд), но ВЫШЕ неё
α растёт заметно круче, чем в фите Morrow (α/N вдвое-втрое больше). Поэтому
запас над критическим полем, нужный для самоподдержания, сжался с +51 % до +11 %,
и произведение «критическое поле × запас» стало меньше. Ни один коэффициент
под этот результат не подгонялся; результат воспроизводится на независимом
наборе чисел (таблица Phelps) с точностью 1 %.

Отдельно: 4.27 кВ, которые даёт 1D-солвер, — это напряжение горения ДБР
**с диэлектриками и внешней цепью**, а не поле самоподдержания в голом газе.
Прямое сравнение этих двух чисел некорректно; связь идёт через
`U_i = U_b·(1 + C_g/C_d)` (ERRATA §C V3).

## 6. Неопределённость — честный раздел

**Не ужимать допуски в тестах ради «зелёного» прогона.** Перечисленное ниже —
реальная неопределённость, а не запас на численный шум.

1. **k3, трёхтельное прилипание: ±40 %.** Расчёт по сечению Phelps даёт в
   тепловом пределе 1.76e-42, прямое измерение CPB-1962 — 2.8e-42 (+59 %),
   формула Kossyi 1992 — 1.9e-42. Принято значение CPB. Значение по набору
   Biagi (1.5e-41) **отвергнуто** как на порядок выше прямого измерения.
   Причина расхождения — грубая трёхточечная оцифровка узкого резонанса
   0.073–0.109 эВ в файле LXCat.
   *Влияние на эталоны:* при варьировании k3 на ±40 % точка α = η ходит в
   пределах 127.4…128.3 Тд, то есть меньше 1 %. Для U_br влияние того же
   порядка. **Критическое поле к k3 нечувствительно** — при 128 Тд трёхтельный
   канал даёт лишь ~4 % от η, доминирует диссоциативное прилипание.

2. **Определение «диссоциации»: фактор 3.3.** Это в ~30 раз больше
   неопределённости самих данных. При 100 Тд, набор Phelps:
   только 6.0 эВ → 6.99e-16; 6.0 + 8.4 (принято) → 1.937e-15;
   + полосы Герцберга 4.5 эВ → 2.344e-15 (+21 %);
   строка `SUM DISSOC.` самого Phelps (прилипание + 8.4 + 9.97 + 14.7) → 1.27e-15.
   **Перед сравнением с любой чужой работой первым делом выяснять состав суммы.**

3. **Разброс между базами сечений:** ±5–7 % для k_diss, ±1–5 % для k(a¹Δ),
   ±2–4 % для критического поля (Phelps/IST 128 Тд, Biagi 132 Тд).

4. **α/N.** Наш k_ion на 5–12 % ниже опубликованной таблицы Phelps при
   100–250 Тд (при 40 Тд совпадает до 0.5 %). Использование таблицы Phelps
   «как есть» сдвигает критическое поле со 127.8 на 126.6 Тд и U_br(γ=0.02)
   с 3.473 на 3.434 кВ. Разница 1 % — внутри допуска 5 %.

5. **Двухчленное приближение** надёжно для O2 до ~100–200 Тд; при 500–1000 Тд
   ошибка может достигать 10–20 %.

6. **Локальное приближение поля.** На фронте стримера ФРЭЭ не успевает за полем.
   Для высокопороговых каналов (8.4 эВ, ионизация) это отдельная,
   здесь не устранённая систематика.

7. **Основное состояние.** Расчёт для O2(X, v=0). В работающем ДБР заметна доля
   колебательно возбуждённых и O2(a) молекул с более низкими порогами —
   реальный k_diss будет выше. Не учтено.

## 7. Что это меняет для солвера — предупреждение

* **D_e вырос в 2.6 раза** при 100 Тд (6.24e24 против 2.38e24 в старой колонке
  D·N, которая строилась по приближению D/µ = (2/3)⟨ε⟩ на заниженной ⟨ε⟩).
  Это может ужесточить явное ограничение шага по диффузии электронов.
* **w_e вырос в 1.6 раза** — соответственно растёт ток и падает время пролёта.
* **Источник атомарного O вырос примерно в 8 раз** при 100–200 Тд; ожидается
  соответствующий рост выхода озона (RATES_REVIEW §7.3).
* **Прилипание тоже выросло** (kAtt2 ×8…×27, k3 ×3…×9), поэтому чистый эффект
  на ток надо смотреть численно, а не предсказывать.

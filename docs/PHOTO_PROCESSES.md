Спецификация, готовая к кодированию. Заменяет раздел **F** файла `ERRATA.md`
(там оставлен только конспект). Иерархия документов:
**`ERRATA.md` > `PHOTO_PROCESSES.md` (этот файл, для фотопроцессов) >
`PHYSICS.md`, `NUMERICS.md`, `NUMERICS_2D.md`.**

Опорное состояние: `p = 101325 Па`, `T = 300 K`, `N = 2.45e25 м⁻³`,
`d_gap = 1.0e-3 м`, барьеры Al₂O₃ `0.5 мм`, `eps_r = 9`, `A = 1e-4 м²`.
Рабочая точка филамента: `E_b = 3.78e6 В/м`, `U_b = 3.78 кВ` (V2 в `ERRATA.md`:

перенесённый заряд `~1e-3 Кл/м²` за импульс длительностью `~100 нс`,
`J ≈ 1e4 А/м²`, объёмная мощность в филаменте `P_vol ≈ 3.8e10 Вт/м³`.

## Маркировка достоверности

| Метка | Смысл |
|---|---|
| **[A]** | Прямое измерение для нужного вещества/диапазона, погрешность ≲ 30 % |
| **[B]** | Литературное значение, перенесённое (другой газ, диапазон, поверхность) — фактор 2–3 |
| **[C]** | Порядковая оценка — фактор 10 и хуже; **обязана быть параметром модели** |

**Все три ключевых множителя (`eta_gamma`, `f_VUV`, `f_det`) имеют метку [C].**
Причина одна и та же: **абсолютно калиброванного спектра излучения разряда в
чистом O₂ не существует ни в одном из нужных диапазонов.** Это главный
ограничитель точности всего модуля, и никакая аккуратность численной схемы его
не компенсирует. Поэтому все три вынесены в параметры с логарифмическими
слайдерами, а модуль спроектирован так, чтобы прогон «вкл/выкл» и развёртка по
этим параметрам были дешёвыми.

**Что изменилось по сравнению с решением `PHYSICS.md` строки 249–252**
(«свернуть фотоэмиссию и метастабильную эмиссию в эффективный γ, переноса

* по **метастабилям** решение верно и остаётся;
* по **фотоэмиссии** решение неверно **не по величине, а по структуре**:

* **`γ_i` после введения отдельного члена фотоэмиссии нельзя оставлять

## 2. Объёмная фотоионизация O₂

### 2.1 Постановка: почему это НЕ запрещено (исправление исходного ТЗ)

Ранее в ТЗ фигурировал тезис: «в чистом O₂ фотоионизация не работает, потому
что фотон, способный ионизовать O₂, излучается самим O₂ и им же поглощается».
**Этот тезис неверен и в тексте документа не используется.**

Собственная фотоионизация
```
O2*  ->  O2 + h*nu        (излучение)
O2 + h*nu  ->  O2+ + e    (поглощение с ионизацией)
```
ничем не запрещена. Совпадение излучателя и поглотителя означает лишь, что
длина пробега определяется тем же сечением, что и в воздухе, но при полном
парциальном давлении O₂ — то есть **в 5 раз короче, чем в воздухе, а не
«исчезающе мала»**: `ℓ = 6.6 … 376 мкм` против `33 мкм … 1.79 мм`.

Процесс мал по **четырём** независимым причинам, каждая из которых —
множитель в цепочке:

1. **Слабое возбуждение нужных состояний.** Ионизующий фотон требует верхнего
   уровня выше 12.06 эВ, комбинирующего с `X³Σ_g⁻`. В O₂ такие уровни лежат
   на пороге ионизации или выше и возбуждаются редко.
2. **Предиссоциация и автоионизация.** Сверхвозбуждённые состояния O₂
   распадаются безызлучательно со скоростями `1e12…1e14 с⁻¹` против
   радиационных `1e8…1e9 с⁻¹` → радиационное ветвление `1e-6…1e-3`.
3. **Столкновительное тушение при 1 атм.** `k_q·N ≈ 3e-16·2.45e25 = 7.4e9 с⁻¹`
   — для медленных каналов это решающий фактор.
4. **Не всякое поглощение даёт ион.** Квантовый выход ионизации
   `Phi_ion = sigma_ion/sigma_abs` вблизи порога заметно меньше единицы;
   конкурирует диссоциация.

Отдельная оговорка (не входит в основную цепочку, но её надо знать):
для **резонансной** линии `O₂** → X` работает пленение излучения — при 1 атм
резонансное сечение `~1e-16 м²` даёт пробег `~0.4 нм`, и такой фотон
переносит энергию, но не переносит ионизацию. Нелокальный перенос обеспечивают
фотоны в крыльях линий и в нерезонансном континууме, где сечение падает до
`1e-22…6e-21 м²` — именно они и описываются вилкой Железняка. Соотношение этих
двух вкладов неизвестно и является частью неопределённости `eta_gamma`.

### 2.2 Точная формула источника

```
S_pi(x) = N * INT dlambda  sigma_ion(lambda)
              * INT_V  [ q_gamma(x', lambda) / (4*pi*R^2) ] * exp( -N*sigma_abs(lambda)*R ) dV'
R = |x - x'|
```
Единицы: `[q_gamma] = фот м^-3 с^-1 нм^-1`, `[sigma] = м²`, `[S_pi] = м^-3 с^-1`.

**Критично: `sigma_ion` стоит в амплитуде, `sigma_abs` — в экспоненте.**
Подставлять одно и то же в оба места — ошибка, систематическая при
`Phi_ion = sigma_ion/sigma_abs < 1` (см. §2.4). Это самая частая ошибка при
переносе воздушных моделей.

В уравнения частиц:
```
dn_e/dt    += S_pi
dn_O2p/dt  += S_pi
```
(заряд сохраняется тождественно — обязательная проверка A5 из `ERRATA.md`).

### 2.3 Спектральный источник q_gamma

```
q_gamma(lambda, x) = sum_m  n_e * N * k_exc,m(E/N) * B_m,lambda
                            * A_m / ( A_m + sum_q k_mq * n_q )
```
где `m` — излучающие состояния, `k_exc,m` — константы возбуждения электронным
ударом, `B_m,λ` — ветвление по спектру, последний множитель — фактор выживания
против столкновительного тушения.

> **Блокирующая проблема, которую надо назвать прямо.**
> Текущий набор реакций `PHYSICS.md` (E1–E8) **не содержит ни одного состояния,
> излучающего в 98–103 нм**. Вычислить `q_gamma` из существующей химии
> **нельзя**. Добавлять такие состояния в набор — отдельная работа с сечениями,
> которых для O₂ в нужном диапазоне нет в надёжном виде.
> **Поэтому `q_gamma` параметризуется через отношение к скорости ионизации,
> а не считается из первых принципов.**

### 2.4 Рабочая параметризация

```
q_gamma_total(x) = eta_gamma * S_ion(x)          [фот м^-3 с^-1]
S_ion(x)         = k_E1(E/N) * n_e * N            (реакция E1)
```

| Параметр | Смысл | Диапазон | По умолчанию | Метка |
|---|---|---|---|---|
| `eta_gamma` | фотонов окна A на одну ударную ионизацию | `1e-4 … 1e-2` | **1e-3** | [C] |
| `Phi_ion` | квантовый выход ионизации на поглощённый фотон | `0.1 … 0.7` | **0.3** | [B] |

Отсюда **отношение фотоионизации к ударной**:
```
S_ph / S_ion = eta_gamma * Phi_ion  =  1e-5 ... 5e-3,   номинал 3e-4
```

Спектральная зависимость `Phi_ion(λ)` (для будущего уточнения, **[B]**,
Chan–Cooper–Brion 1993 + Fennelly–Torr 1992):

| λ | hν | `Phi_ion` |
|---|---|---|
| 102.72 нм (порог) | 12.06 эВ | **0** |
| 100–102 нм | 12.2–12.4 эВ | 0.1–0.5 |
| 98–100 нм | 12.4–12.7 эВ | 0.3–0.8 |
| < 90 нм | > 13.8 эВ | → 1 (нерелевантно: излучателя нет) |

Среднее по окну **0.3**, варьировать 0.1–0.7. Для сравнения: в воздухе
эквивалентная величина при 1 атм
`xi*(nu_u/nu_i)*p_q/(p+p_q) = 0.1*30/790 = 3.8e-3` **[A для воздуха]** —
то есть номинал в чистом O₂ (`3e-4`) в **13 раз ниже** воздушного, а не
«на порядки», как утверждалось в исходном ТЗ. Верхняя граница диапазона
(`5e-3`) даже превышает воздушную.

### 2.5 Величина источника впереди фронта

Головка филамента, `E/N = 200 Тд`:
```
alpha/N = 2.0e-20*exp(-724.8/200) = 5.335e-22 м^2  ->  alpha = 1.307e4 м^-1
w_e = 9.00e23 * 200 * 1e-21 = 1.80e5 м/с ,   n_e = 1e20 м^-3
S_ion = alpha*n_e*w_e = 2.35e29 м^-3 с^-1
V_head = pi*(75 мкм)^2 * 100 мкм = 1.77e-12 м^3
полная скорость ионизации = 4.16e17 с^-1
фотоны окна A при eta_gamma = 1e-3:  4.16e14 фот/с
```

Источник впереди головки, `S_ph = Phi_ion · Ṅ_γ · exp(-R/ℓ) / (4πR²ℓ)`,
`Phi_ion = 0.3` (в м⁻³с⁻¹). Столбцы 2–4 — вклад **каждой группы в отдельности**,
если бы в ней были все фотоны; последний — реальная сумма с весами
0.67 / 0.26 / 0.07:

| R впереди | `ℓ = 14.8 мкм` (w = 0.67) | `ℓ = 90 мкм` (w = 0.26) | `ℓ = 238 мкм` (w = 0.07) | **Σ с весами** |
|---|---|---|---|---|
| 50 мкм | 9.2e24 | 2.5e25 | 1.4e25 | **1.4e25** |
| 100 мкм | 7.8e22 | 3.6e24 | 2.7e24 | **1.2e24** |
| 200 мкм | 2.3e19 | 3.0e23 | 4.5e23 | **1.1e23** |
| 400 мкм | 7.7e12 | 8.1e21 | 4.9e22 | **5.5e21** |

**Именно поэтому нельзя ограничиться короткой группой.** На 400 мкм впереди
компонента `ℓ = 238 мкм` (вес всего 7 %) даёт источник в **6·10⁹ раз** больше,
чем компонента `ℓ = 14.8 мкм` (вес 67 %), и даёт **62 % полной суммы**.
Далёкий хвост слабого по весу слагаемого определяет всё поведение впереди
фронта — это стандартное свойство фотоионизационных моделей и главная причина,
по которой трёхгрупповое разложение обязательно. Модель с одной короткой
группой физически эквивалентна отсутствию фотоионизации.

**Сравнение с уже имеющимися источниками затравки.**
```
S_bg  = 1.0e13 м^-3 с^-1                              (фон, PHYSICS.md §5)
S_D6  = nu_D6 * n(O2-) = (1.1e7 ... 2.1e8) * n(O2-)   (см. §5.3 о расхождении ×18)
S_D5  = 1.23e5 * n(O-)
```

| Область | `n(O₂⁻)` | `S_D6` | `S_ph` на 100 мкм впереди | Отношение |
|---|---|---|---|---|
| Канал предыдущего филамента | 1e19 | 1.1e26 … 2.1e27 | 1.2e24 | **0.06 … 1.1 %** |
| Периферия (ион разлетелся/рекомбинировал) | 1e17 | 1.1e24 … 2.1e25 | 1.2e24 | **6 … 110 %** |
| Свежий газ / первое зажигание | 0 | 0 (`S_bg = 1e13`) | 1.2e24 | **10¹¹** |

**Вывод §2.5.** Фотоионизация не влияет на интегральный баланс заряда
(`3e-4` от ударной ионизации) и на оси филамента проигрывает отлипанию
в 100–1000 раз. Но:
* на **радиальной периферии**, где остаточных отрицательных ионов на 2 порядка
  меньше, она **сравнима** с отлипанием или превосходит его — а это ровно та
  область, которая решает, куда расплывётся филамент и где зажжётся следующий;
* в **свежем газе** она превышает фоновый источник на 11 порядков и является
  единственным физическим (а не подставленным константой) механизмом затравки.

Для 2D-модели, где предмет интереса — морфология, а не интегралы, её надо
включать. Утверждение исходного ТЗ «источник локален, им можно пренебречь»
не подтверждается: 33 % источника имеет масштаб ≥ 90 мкм, то есть больше
радиуса головки.

### 2.6 Коэффициенты трёхгруппового разложения

Аппроксимация ядра: `F(R)/R = sum_j A_j * exp(-lambda_j * R)`, откуда
```
lap S_j - lambda_j^2 * S_j = -A_j * q_gamma_total(x)
S_pi = Phi_ion * sum_j S_j
```
Функция Грина оператора `(lap - lambda^2)` равна `exp(-lambda R)/(4 pi R)`;
закон сохранения источника: `sum_j A_j/lambda_j^2 = 1`.

**Набор «O2-Zheleznyak» (по умолчанию), [B] по λ / [C] по весам:**

| j | `lambda_j` [м⁻¹] | `1/lambda_j` | вес `A_j/lambda_j²` | `A_j` [м⁻²] |
|---|---|---|---|---|
| 1 | **4.202e+03** | **238 мкм** | 0.07 | **1.236e+06** |
| 2 | **1.111e+04** | **90 мкм** | 0.26 | **3.210e+07** |
| 3 | **6.757e+04** | **14.8 мкм** | 0.67 | **3.059e+09** |
| | | | Σ = 1.000 | |

**Откуда они и в чём степень достоверности.** Это коэффициенты Бурдона
(*PSST* **16** (2007) 656) для воздуха, пересчитанные на `p_O2 = 760 Торр`:
```
A_j^SI = A_j^Bourdon * p_O2^2 ,  lambda_j^SI = lambda_j^Bourdon * p_O2
A_j^Bourdon = 1.986e-4, 5.100e-3, 0.4886   см^-2 Торр^-2
lambda_j^Bourdon = 0.0553, 0.1460, 0.8900  см^-1 Торр^-1
```
Проверка: в записи через `N` (`ERRATA.md` F3) `A_j = 1.91e-45, 4.91e-44,
4.70e-42 м⁴`, `lambda_j = 1.72e-22, 4.53e-22, 2.76e-21 м²`; при `N = 2.45e25`
это даёт `1/λ_j·N = 237.3, 90.1, 14.79 мкм` и `Σ A_j/λ_j² = 0.921`
(нормируем к 1 → веса 7 %, 26 %, 67 %). Сходится.

* **`lambda_j` переносятся законно [B]**: они описывают функцию поглощения
  **кислорода** и масштабируются с парциальным давлением O₂. При переходе
  воздух → чистый O₂ все длины сокращаются в 5.0 раз — это единственное,
  что происходит с ними.
* **`A_j` (веса) переносятся НЕ законно [C]**: они кодируют форму
  **азотного** эмиссионного спектра в окне 98–102.5 нм, свёрнутую с
  `sigma_abs(O₂)`. Спектр собственного излучения O₂ в этом окне другой и
  неизвестен (§2.3).

Поэтому веса **вынесены в параметр**:
```
photoIonWeights : [0.07, 0.26, 0.67]    // сумма нормируется к 1 автоматически
```
Предустановки для развёртки чувствительности:
```
'air'       : [0.07, 0.26, 0.67]   // Бурдон при p_O2=760 Торр (по умолчанию)
'short'     : [0.02, 0.13, 0.85]   // гипотеза «спектр смещён к 98 нм» (сильное поглощение)
'long'      : [0.20, 0.40, 0.40]   // гипотеза «спектр у порога 102.7 нм» (слабое поглощение)
```
Развёртка по этим трём наборам при фиксированном `eta_gamma·Phi_ion` — это и
есть честная оценка неопределённости формы ядра. **Ожидаемая
чувствительность радиуса филамента к выбору набора — десятки процентов;
это надо померить и показать, а не прятать.**

**Коэффициенты Бурдона в исходной, воздушной форме (`p_O2 = 152 Торр`)
использовать только как численный тест транспорта (VF3), не как физику.**

### 2.7 Процедура настоящего перефита (когда появятся данные)

1. Построить спектральный источник:
   `q_gamma(lambda,x) = sum_m n_e N k_exc,m(E/N) B_m,lambda A_m/(A_m + sum_q k_mq n_q)`.
2. Взять `sigma_abs(lambda)` и `sigma_ion(lambda)` O₂ с разрешением ≤ 0.05 нм
   (полосы Хопфилда сильно структурированы): Heays–Bosman–van Dishoeck 2017 /
   база PHIDRATES; Fennelly & Torr 1992; Chan–Cooper–Brion 1993.
3. Ядро:
   `K_pi(R) = (1/(4 pi R^2)) * INT y_gamma(lambda) * N * sigma_ion(lambda)
              * exp( -N*sigma_abs(lambda)*R ) dlambda`,
   где `y_gamma(λ)` — нормированный спектр (`INT y_gamma dλ = 1`).
4. **Неотрицательный** МНК в логарифмическом масштабе:
   `(1/R) * INT y_gamma N sigma_ion exp(-N sigma_abs R) dlambda  ~=  sum_j B_j exp(-kappa_j R)`
   на диапазоне `R ∈ [dx_min, L_domain]`.
5. Пересчёт в масштабируемую по плотности форму: `A_j = B_j/N^2`, `lambda_j = kappa_j/N`.
6. Перенормировка `A_j` так, чтобы `sum_j A_j/lambda_j^2 = INT y_gamma Phi_ion dlambda`.

**Обязательно: `sigma_ion` в амплитуде, `sigma_abs` в экспоненте.**

## 3. Фотоэмиссия с диэлектрика Al₂O₃

### 3.1 Порог: `E_th ≠ E_g`

Ошибка, которую легко сделать: приравнять порог фотоэмиссии ширине
запрещённой зоны. Нужен переход **валентная зона → вакуум**:
```
E_th ~= E_g + chi_e
```

| Величина | Значение | Метка | Источник |
|---|---|---|---|
| `E_g` (сапфир, α-Al₂O₃) | 8.7–8.9 эВ | [A] | Robertson, *JVST B* **18** (2000) 1785 |
| `chi_e` (электронное сродство) | ≈ 0.5–1.5 эВ | [B] | там же; Gutierrez et al. 1969 |
| **`E_th` практический, стехиометрическая поверхность** | **9.0 … 10.5 эВ** | **[B]** | |
| **`E_th` дефектный / аморфный / плазменно обработанный оксид** (эмиссия из ловушек) | **5 … 8 эВ** | **[C]** | |
| Длина затухания фотоэлектрона в оксиде | ≈ 13 нм | [B] | Gutierrez et al., *JAP* **40** (1969) 1733 |

**`E_th` ОБЯЗАН быть параметром модели**, причём с диапазоном 5…10.5 эВ:
разница между 9.0 и 10.5 эВ **включает и выключает** линию O I 130.4 нм —
главного кандидата (см. §3.3). Это качественная бифуркация, а не поправка.

```
E_th : 9.0,      // эВ, слайдер 5.0 ... 10.5
```

### 3.2 Параметризация выхода (Фаулер)

```
Y_ph(h*nu) = Y_ref * max(0, (h*nu - E_th) / (E_ref - E_th))^2
Y_ref = 5e-3   при   E_ref = 12.5 эВ                    [C]
```
Значения при разных `E_th`:

| Линия | hν [эВ] | `E_th = 9.0` | `E_th = 10.5` | `E_th = 6.0` (дефектная) |
|---|---|---|---|---|
| Герцберг, край 200 нм | 6.20 | 0 | 0 | 4.7e-6 |
| SR-континуум 146 нм | 8.55 | 0 | 0 | 7.4e-4 |
| **O I 135.6 нм** | 9.14 | **8.0e-6** | **0** | 1.2e-3 |
| **O I 130.4 нм** | 9.51 | **1.06e-4** | **0** | 1.5e-3 |
| **O I 102.7 нм** | 12.07 | **3.8e-3** | **3.1e-3** | 4.4e-3 |
| **O I 98.9 нм** | 12.54 | **5.1e-3** | **5.2e-3** | 5.1e-3 |

Независимые ориентиры по литературе **[B/C]**:
```
чистая стехиометрическая поверхность, 9.1-9.5 эВ : Y = 1e-5 ... 1e-3
дефектный оксид,                       9.1-9.5 эВ : Y = 1e-4 ... 1e-2
любая поверхность,                     12-13 эВ   : Y = 1e-3 ... 5e-2
```
Фаулеровская параметризация с `E_th = 9.0`, `Y_ref = 5e-3` попадает во все три
диапазона. Это её единственное обоснование — она **согласована**, а не выведена.

### 3.3 Что реально доходит до стенки

| Излучатель | λ | hν | Выше `E_th`? | Судьба фотона |
|---|---|---|---|---|
| **O I 98.9 нм** | 98.9 нм | 12.54 эВ | **да, при любом `E_th`** | `ℓ = 16 мкм` — сильно поглощается O₂ |
| **O I 102.6/102.7 нм** | 102.7 нм | 12.07 эВ | **да, при любом `E_th`** | `ℓ = 20 мкм` |
| Окно A в целом | < 102.8 нм | 12.1–12.5 эВ | **да** | `ℓ = 7…376 мкм` — **часть доходит** |
| **O I 130.2–130.6 нм** | 130.4 нм | 9.49–9.52 эВ | только при `E_th ≤ 9.5` | `ℓ = 41 мкм`; **плюс резонансное пленение атомарным O** |
| **O I 135.6 нм** | 135.6 нм | 9.14 эВ | только при `E_th ≤ 9.1` | запрещённый переход, `τ = 180 мкс`; при 1 атм радиационное ветвление ничтожно → **вклад ≈ 0** |
| Континуум Шумана–Рунге (эмиссия) | 130–175 нм | 7.1–9.5 эВ | только коротковолновая часть, и то при малом `E_th` | `ℓ = 27–410 мкм` |
| Герцберг I | 200–400 нм | 3.1–6.2 эВ | **только из поверхностных ловушек** | газ прозрачен, доходит весь |
| O I 777.4 / 844.6 нм | 777/845 нм | 1.60/1.47 эВ | **нет** | **фотоэмиссии не дают**; важны для отлипания (§5) |

**Ключевой момент, который меняет картину по сравнению с наивной оценкой:**
самый надёжный кандидат на фотоэмиссию — **не** линия 130.4 нм (она может
оказаться ниже порога и вдобавок пленяется атомарным кислородом), а **окно A**
(98–103 нм, 12.1–12.5 эВ). Оно **уверенно** выше любого `E_th`, у него
`Y_ph ≈ 4e-3…5e-3` — на **полтора порядка** выше, чем у 130.4 нм при `E_th = 9`.
Расплата: сильное поглощение O₂ (`ℓ = 7…376 мкм`).

Следствие для кода: **источник окна A обслуживает и §2, и §3.** Отдельная
группа окна B нужна только для сценария `E_th ≤ 9.5`.

### 3.4 Радиус засветки — исправление обеих исходных оценок

Для точечного источника мощностью `Ṅ` на высоте `h` над плоскостью
**поверхностная плотность потока** (уже с косинусом):
```
F(rho) = Ndot * h / ( 4*pi*(rho^2 + h^2)^{3/2} )        [фот м^-2 с^-1]
```
Проверка нормировки: `INT_0^inf F(rho) 2 pi rho drho = Ndot/2` ✔ (половина
телесного угла). Медианный радиус (внутрь которого попадает половина потока):
```
rho_50 = sqrt(3) * h
```

| `h` | `rho_50` | `F(0) = Ndot/(4 pi h^2)` |
|---|---|---|
| 0.1 мм | 0.173 мм | `7.96e6·Ṅ` |
| 0.3 мм | 0.520 мм | `8.84e5·Ṅ` |
| 0.5 мм | **0.866 мм** | `3.18e5·Ṅ` |

**Но** это чистая геометрия, без поглощения. Реальное пятно ограничено ещё и
`ℓ_abs`. Множитель ослабления `exp(-h/ℓ)` по нормали:

| `ℓ_abs` | `h = 0.1 мм` | `h = 0.2 мм` | `h = 0.5 мм` |
|---|---|---|---|
| 14.8 мкм | 1.2e-3 | 1.4e-6 | 2.1e-15 |
| 41 мкм (130.4 нм) | 8.7e-2 | 7.6e-3 | 5.1e-6 |
| 90 мкм | 3.3e-1 | 1.1e-1 | 3.9e-3 |
| 238 мкм | 6.6e-1 | 4.3e-1 | 1.2e-1 |
| 376 мкм | 7.7e-1 | 5.9e-1 | 2.7e-1 |

**Итог по радиусу засветки — обе исходные формулировки были неточны:**

* тезис ТЗ «радиус засветки порядка зазора (0.5–1 мм)» **верен только для
  прозрачного видимого/ИК излучения, которое порог фотоэмиссии не проходит**;
* моя предыдущая оценка «пятно ≈ 85 мкм, ненамного шире филамента» **тоже
  неверна** — она использовала только короткую компоненту `ℓ = 41 мкм` и
  игнорировала длинные компоненты окна A;
* **правильно:** пятно засветки — это `rho_50 = sqrt(3)·h`, **обрезанное**
  поглощением. Для длинной компоненты (`ℓ = 238–376 мкм`, вес ~7 %) при
  `h = 0.5 мм` до стенки доходит 12–27 % — то есть **пятно радиусом ~0.9 мм
  существует, но несёт ~10 % потока**. Для короткой компоненты
  (`ℓ = 14.8 мкм`, вес 67 %) стенка освещается, только когда фронт подошёл
  ближе 50 мкм, и тогда пятно ≈ размеру филамента.
* **Практический вывод: засветка двухмасштабная** — узкое яркое ядро
  (~радиус филамента) плюс широкий слабый ореол (~0.9 мм, ~10 % потока).
  Именно ореол определяет, где зажжётся следующий филамент. Схема должна
  разрешать оба масштаба — поэтому §7.4 рекомендует прямой view factor,
  а не диффузионное замыкание.

### 3.5 Отношение к ион-индуцированной эмиссии

```
F_ph / F_i = 1.05e4 * Y_ph * f_VUV * T_w / beta_i
```
где
```
Y_ph   — квантовый выход, эл/фотон                       (§3.2)
f_VUV  — доля мощности разряда, излучаемая выше E_th     [C], 1e-6 ... 5e-3, номинал 1e-4
T_w    — доля испущенных фотонов, доходящих до стенки    0.05 ... 0.3, номинал 0.1
beta_i = gamma_i/0.02  — нормированный ионный коэффициент
```
Проверка структурной формулой (независимый вывод):
```
F_ph/F_i = Y_ph * f_VUV * T_w * (e*U_b) / (gamma_i * E_ph)
e*U_b/(gamma_i*E_ph) = 3780/(0.02*9.51) = 1.99e4    (окно B)
                     = 3780/(0.02*12.3) = 1.54e4    (окно A)
```
Формула ревью даёт `1.05e4`; структурный вывод — `1.5…2.0e4`. **Согласие в
пределах фактора 2**, что для оценки с меткой [C] достаточно.
В коде использовать структурную форму (она самосогласована с `U_b`, `E_ph`,
`gamma_i` модели), константу `1.05e4` — как контрольное значение.

| Сценарий | `Y_ph` | `f_VUV` | `T_w` | `F_ph/F_i` |
|---|---|---|---|---|
| Низ (стехиометрия, `E_th = 10.5`) | 1e-5 | 1e-5 | 0.05 | **5.3e-8** |
| **Номинал** | 1e-3 | 1e-4 | 0.1 | **1.05e-4** |
| Верх (дефектный оксид, окно A) | 1e-2 | 5e-3 | 0.3 | **1.6e-1** |

**Реалистичный интегральный диапазон `1e-6 … 1e-2`.**

### 3.6 Почему процесс всё равно важен: временнóе разделение

Это главный физический вывод §3, и он не связан с интегральной величиной.

Время пролёта иона (`mu(O₂⁺) = 2.41e-4`, `mu(O₄⁺) = 2.37e-4 м²/В/с`):

| E | `v_d(O₂⁺)` | пролёт 1 мм | пролёт слоя 50 мкм |
|---|---|---|---|
| 30 кВ/см | 723 м/с | **1.383 мкс** | **69 нс** |
| 37.8 кВ/см (`E_b`) | 911 м/с | **1.098 мкс** | **55 нс** |

Для `O₄⁺`: 711 и 896 м/с → 1.406 и 1.116 мкс. Пролёт фотона через 1 мм:
**3.3 пс**. Радиационное время O I 130.4 нм: 2.9 нс.

**Следствие.** В первые 10–50 нс после начала лавины поток ионов на стенку
`Γ_i ≈ 0` — ионы физически ещё не долетели. Фотонный поток при этом уже
установился. Значит **в окне 0–50 нс отношение `F_ph/F_i` не `1e-4`, а
формально бесконечно**: фотоэмиссия — **единственный** источник вторичных
электронов на старте.

Это переводит фотоэмиссию из категории «поправка к дозе» в категорию
«триггер». Она влияет на:
* **момент** зажигания (фаза относительно приложенного напряжения — критерий V8);
* **радиальное место** зажигания (через широкий ореол §3.4 — определяет, где
  возникнет следующий филамент);
* **скорость нарастания** переднего фронта тока.

и почти не влияет на:
* интегральный перенесённый заряд (V6);
* мощность по Мэнли (V5);
* выход озона (V10).

**Именно поэтому её надо включать в 2D-модель, несмотря на `F_ph/F_i ~ 1e-4`.**

### 3.7 Граничное условие и запрет двойного счёта

**Правильное ГУ:**
```
Gamma_e,emit(r) = gamma_i * sum_k Gamma_i,k(r)
                + INT dlambda INT dOmega  Y_ph(lambda) * F_gamma,inc(r, lambda, theta)
```
где `F_gamma,inc` — падающий на поверхность спектрально-угловой поток
(§7.4 даёт его дискретную форму). В коде — сумма по фотогруппам:
```
Gamma_pe(r) = sum_g  Y_ph(hnu_g) * F_gamma,g(r)
```
Встраивание в поток электронов на стенку (`NUMERICS.md` §3.4, `ERRATA.md` A1):
```
Gamma_e,wall = 0.25*v_th_e*n_e + a*|mu_e*E|*n_e - gamma_i*Gamma_pos - Gamma_pe
dSigma/dt    = e*( Gamma_pos - Gamma_e,wall - Gamma_neg )
```
`Gamma_pe` вычитается **ровно один раз** — внутри `Gamma_e,wall`.
Отдельно в `dSigma/dt` его добавлять нельзя (критерий VF6).

> ### ⚠ ЗАПРЕТ ДВОЙНОГО СЧЁТА
> `gamma = 0.02` в `PHYSICS.md` §4.1 объявлен «эффективным»: в него **уже
> свёрнуты** фотоэмиссия и метастабильная эмиссия. После введения явного
> члена `Gamma_pe` оставлять `gamma_i = 0.02` **нельзя**.
>
> **Правило разделения:**
> ```
> gamma_i = gamma_eff / (1 + (F_ph/F_i)|_рабочая точка)
> ```
> При номинале (`F_ph/F_i = 1.05e-4`): `gamma_i = 0.02/(1.000105) = 0.019998`
> — поправка 0.01 %, неотличима от нуля.
> При верхнем сценарии (`F_ph/F_i = 0.16`): `gamma_i = 0.02/1.16 = 0.01724`
> — поправка **14 %**, уже значима и обязана быть внесена.
>
> В коде: `gamma_i` — **отдельный** параметр, инициализируемый по формуле выше
> при старте прогона; `gamma_eff = 0.02` остаётся только для режима
> `photoEmission = false`. Метастабильный вклад из `gamma_eff` вычитать не надо
> — его там нет (§4).
>
> Дополнительно: `ERRATA.md` C1 напоминает, что `gamma = 0.02` — **круговая
> калибровка**, а не измерение. Правильная подача — кривая `U_br(gamma_i)`
> в диапазоне 0.005…0.05; фотоэмиссия сдвигает эту кривую, а не «подтверждает» её.

Оже-девозбуждение на диэлектрике требует `E_exc > E_g + chi_e`. Максимум в O₂ —
4.34 эВ, вдвое-втрое ниже порога. Даже при дефектном пороге 5–6 эВ ни один не
проходит. Для сравнения: N₂(A³Σ_u⁺) = 6.17 эВ (граничный случай),
He(2³S) = 19.8 эВ (доминирующий канал). **Вклад в O₂ ≈ 0.**

Следствия: (1) `gamma_eff = 0.02` метастабилями не завышен — их там не было;
(2) при разделении `gamma_eff` на компоненты (§3.7) метастабильную долю
вычитать не надо; (3) отдельный член не реализовывать.

### 5.2 Частота фотоотлипания

### 5.4 Почему процесс всё равно важен: эксклюзивность канала для O₃⁻

Это главный вывод §5, и он не связан с темпом.

Посмотрим на таблицу отлипания `PHYSICS.md` §2.3 по ионам:

| Ион | Каналы отлипания | Работают между импульсами? |
|---|---|---|
| O⁻ | D1 (`+O₂(a)`), D2 (`+O`), D5 (`+O₂`) | **да**, D5 всегда |
| O₂⁻ | D3 (`+O₂(a)`), D4 (`+O`), D6 (полевое) | **да**, D3 всегда |
| **O₃⁻** | **только D7 (`+O`)** | **НЕТ** |

При этом (`PHYSICS.md` §1) **O₃⁻ несёт основную часть отрицательного заряда
между импульсами**: `O⁻ → O₃⁻` за `1/(1.1e-42·N²) = 1.5 нс`. А единственный его
канал D7 требует атомарного кислорода, который за `1/(6.0e-46·N²) = 2.8 мкс`
уходит в озон. **Через ~10 мкс после импульса у O₃⁻ не остаётся ни одного
столкновительного канала отлипания.** Фотоотлипание — единственный.

Оценка вклада:
```
P_pd(O3-) = nu_pd(O3-) * tau_pulse ,   tau_pulse = 100 нс
```

| `f_det` | `nu_pd(O₃⁻)` | `P_pd` за импульс | `Δn_e` при `n(O₃⁻) = 1e20` |
|---|---|---|---|
| 1e-5 | 0.22 с⁻¹ | 2.2e-8 | **2.2e12 м⁻³** |
| **1e-4** | 2.2 с⁻¹ | 2.2e-7 | **2.2e13 м⁻³** |
| 1e-3 | 22 с⁻¹ | 2.2e-6 | **2.2e14 м⁻³** |

Диапазон **`Δn_e = 1e12 … 1e15 м⁻³`** — сравним или **выше** искусственной
затравки `n_e(0) = 1e13 м⁻³` из `PHYSICS.md` §5 (которую `ERRATA.md` C2
прямо называет численным костылём, а не физикой). **Фотоотлипание от O₃⁻ —
кандидат на замену этого костыля физическим механизмом.**

> ### ⚠ ИСПРАВЛЕНИЕ: фотоотлипание НЕ готовит затравку заранее
> Формулировка «фотоотлипание создаёт затравку за десятки микросекунд до
> следующего импульса» **неверна**. Прозрачный фотон покидает зазор 1 мм за
> **3.3 пс**. Излучение существует только пока горит разряд. Значит
> отлипание идёт **одновременно** с новым светящимся импульсом, а не до него.
>
> Межполупериодная затравка была бы возможна только от долгоживущего
> излучателя. Единственный кандидат — ИК-излучение O₂(a¹Δ_g) на 1270 нм,
> но `A ≈ 2e-4 с⁻¹`, и при `n_a = 1e22 м⁻³` получается `nu_pd ~ 2e-6 с⁻¹` —
> **в ~10¹² раз меньше D3**. **ИК от O₂(a) значимой затравкой не является.**
>
> Правильная физическая роль фотоотлипания: **радиальное и продольное
> расплывание зажигания внутри импульса.** Первый же свет филамента
> мгновенно освобождает электроны из O₃⁻ по всему зазору (газ прозрачен) —
> в том числе там, куда фронт ещё не дошёл. Это работает **в паре с
> фотоионизацией (§2)**, но на бо́льших расстояниях (нет поглощения) и на
> ионах, оставшихся от предыдущего полупериода.

### 5.5 Члены источника

```
nu_pd,s(x) = INT sigma_pd,s(lambda) * Psi_gamma(x, lambda) dlambda
S_e        = sum_s  n_s * nu_pd,s
S_s        = -n_s * nu_pd,s
```
для `s ∈ {O⁻, O₂⁻, O₃⁻}`, `sigma_pd = [6.0e-22, 2.4e-22, 1.5e-22] м²`.
Нейтральные продукты (сохранение вещества обязательно):
```
O-  + hv -> O  + e     ->  dn(O)/dt  += n(O-)*nu_pd,O-
O2- + hv -> O2 + e     ->  (фон, не отслеживается)
O3- + hv -> O3 + e     ->  dn(O3)/dt += n(O3-)*nu_pd,O3-
```
Заряд сохраняется тождественно (проверка A5 `ERRATA.md`).

## 6. Фотодиссоциация O₂ и O₃ — не реализовывать, с доказательством

### 6.1 O₃, полоса Хартли

```
sigma_max(O3, 254 нм) = 1.15e-21 м^2   [A]  (JPL Publication 19-5)
полоса 200-310 нм, квантовый выход диссоциации ~1

Излучателей в 200–310 нм в чистом O₂ практически нет (Герцберг потушен,

q_UV   = 1e-4 * 3.80e10 / 7.85e-19 = 4.84e24 фот/(м^3 с)
Phi_UV = q_UV * G_slab = 5.86e21 фот/(м^2 с)
J      = sigma*Phi = 1.15e-21 * 5.86e21 = 6.7e-3 с^-1   (во время импульса)
```

<J> = 2.7e-5 с^-1  ->  постоянная времени 1.0 час

даёт `O + O₂`, а атом O возвращается в озон за 2.8 мкс (N1) — **чистый эффект
ещё ближе к нулю**.

**Не включать. Влияния на баланс озона за 2–10 периодов нет (`~1e-8`).**

### 6.2 O₂, континуум Шумана–Рунге — единственный ненулевой фотоэффект

Каждый ВУФ-фотон окна B поглощается O₂ в континууме SR, а континуум SR на

При f_VUV = 5e-4:  q_VUV = f_VUV*P_vol/E_ph = 5e-4*3.80e10/1.523e-18 = 1.25e25

отношение = 0.88 %
```
Поправка ~1 % — полностью внутри погрешности самой E4, которую `ERRATA.md` D
называет **заниженной на 1–2 порядка** (`1e-16…1e-15` вместо `1.8e-18`).

Кроме того, излучающие состояния (диссоциативное возбуждение O₂, порог

**Не реализовывать. Считать учтённым в E4.** Вернуться к вопросу, если

### 7.1 ⚠ Гельмгольц НЕЛЬЗЯ собирать как «Пуассон со сдвигом диагонали»

Это самая опасная ловушка раздела, и она должна быть прочитана до написания
первой строки кода.

Матрица Пуассона собрана с **переменной проницаемостью** `eps(z)`
(`eps_r = 9` в барьерах, 1 в газе) и с гармоническими трансмиссивностями на
материальной границе (`NUMERICS.md` §3.2, `ERRATA.md` B5). Фотонное уравнение
```
lap(S_j) - kappa_j^2 * S_j = -q_j
```
имеет коэффициент **1**, а не `eps(z)`, и живёт **только в газовом зазоре**
(диэлектрик для ВУФ непрозрачен).

**Переиспользуются:**
* радиальная диагонализация (`ERRATA.md` B1: обобщённая задача
  `K_r v_k = lambda_k M_r v_k`, `M_r = diag[(r²_{i+1/2} - r²_{i-1/2})/2]`,
  нормировка `v^T M_r v = I`) — те же `v_k`, те же `lambda_k`;
* код прогонки Томаса;
* инфраструктура ГУ и прямого/обратного преобразования в метрике `M_r`.

**Собирается заново, отдельно:**
* z-матрицы — с `eps = 1`, на **газовой** части сетки, с диагональным членом
  `+(lambda_k + kappa_j^2)`.

Разделять эти две сборки в коде явно (два разных конструктора), иначе рано или
поздно в фотонное уравнение просочится `eps_r = 9`.

### 7.2 Дискретизация

**Радиальный оператор** (`ERRATA.md` B1, B2). На оси грань `r_{-1/2} = 0`,
её площадь нулевая, поток через неё автоматически нуль — `1/r` не вычислять:
```
(L_r S)_0 = 2*(S_1 - S_0)/dr^2                      (равномерная сетка)
(L_r S)_i = [ r_{i+1/2}*(S_{i+1}-S_i)/h_{i+1/2}
            - r_{i-1/2}*(S_i-S_{i-1})/h_{i-1/2} ] / (r_i * dr_i)
```
Диагонализация — обобщённая, симметризованная через `M_r^{-1/2} K_r M_r^{-1/2}`.
Соглашение о знаке (`ERRATA.md` B3): `lambda_k` — собственные значения `-L_r`,
то есть `lambda_k >= 0`, и в модальном уравнении стоит **минус**.

**Модальное уравнение** (после `L_r Q_m = -k_m^2 Q_m`):
```
d^2 S_hat/dz^2  -  ( k_m^2 + kappa_j^2 ) * S_hat  =  -q_hat
```

**Трёхдиагональная форма на неравномерной сетке по z:**
```
a_l^-  = 1 / ( dz_l * delta_z_{l-1/2} )
a_l^+  = 1 / ( dz_l * delta_z_{l+1/2} )
диагональ: a_l^- + a_l^+ + k_m^2 + kappa_j^2
-a_l^- * S_{l-1} + [a_l^- + a_l^+ + k_m^2 + kappa_j^2] * S_l - a_l^+ * S_{l+1} = q_l
```
где `dz_l` — ширина ячейки, `delta_z_{l±1/2}` — расстояния между центрами.
Матрица симметрична и **строго** диагонально доминантна
(`k_m^2 + kappa_j^2 > 0` всегда, в отличие от Пуассона, где `lambda_0 = 0` при
чистом Неймане). Прогонка безусловно устойчива, пивотинг не нужен.

**Факторизации кэшируются:** `kappa_j` и `k_m` постоянны, `eps` в газе не
меняется → все `n_groups × nr` прогонок факторизуются один раз при
инициализации; на шаге остаются прямой/обратный ход.

### 7.3 ⚠ Граничные условия: `S_j = 0` на границе зазора физически неверно

Однородный Дирихле на границе газового зазора означает «фотоны исчезают на
стенке И поле обнуляется» — это искусственно занижает `S_j` вблизи стенки
именно там, где идёт фотоэмиссия.

**Правильно — модальное открытое (радиационное) условие**, которое для плоской
границы **точно** для каждой радиальной моды:
```
dS_hat_m / dn  +  sqrt( k_m^2 + kappa_j^2 ) * S_hat_m  =  0
```
Вывод: вне области решение моды `m` — затухающая экспонента
`exp(-sqrt(k_m² + kappa_j²)·n)`, сшивка даёт ровно это условие. Отражения нет,
поле продолжается «как будто среда бесконечна» — что и есть физика поглощающей
стенки в P1-смысле.

Дискретно — модификация **только** первого/последнего диагонального элемента:
```
b_1  += sqrt(k_m^2 + kappa_j^2)          (граница z = 0)
b_nz += sqrt(k_m^2 + kappa_j^2)          (граница z = d_gap)
```
Трёхдиагональность и разделимость сохраняются полностью.

**Альтернатива (проще, дороже):** расширить расчётную область по z и r на
`3…5 * ell_max = 3·376 мкм ... 5·376 мкм ≈ 1.1…1.9 мм` за пределы зазора и
поставить `S = 0` снаружи. Стоимость: `nz` растёт примерно вдвое.
**Рекомендуется первое** — оно точнее и бесплатно.

По радиусу: на оси — Нейман (заложен в `L_r` через `r_{-1/2} = 0`);
на `r = R_dom` — то же модальное открытое условие.

### 7.4 Фотоэмиссия: прямой view factor (рекомендуется), а не диффузионное замыкание

Причина выбора — §3.4: пятно засветки **двухмасштабное** (узкое яркое ядро +
широкий слабый ореол `rho_50 = sqrt(3)h ≈ 0.87 мм`), и именно ореол определяет
место следующего зажигания. Диффузионное (P1) замыкание врёт в 1.5–2 раза на
расстояниях меньше длины пробега — то есть ровно в ядре — и не воспроизводит
угловую структуру `cos θ`, от которой ореол и зависит.

**Ядро потока на стенку** (с косинусом):
```
Gamma_gamma,g(r_w) = INT_V  q_g(r',z') * exp(-mu_g*R) * cos(theta) / (4*pi*R^2) dV'
cos(theta) = |z' - z_wall| / R
```
В осесимметрии азимутальный интеграл сводится к эллиптическому — **элементарной
замкнутой формы нет** (в отличие от объёмного ядра §7.5). Считать **один раз**
при инициализации гауссовой квадратурой по `phi` (64 узла достаточно:
подынтегральная функция гладкая при `R > dr`).

**Размер матрицы.** `nr = 96`, `nz = 256`:
```
полная:  nr x (nr*nz) = 96 x 24576 = 2.359e6 элементов
         float32: 9.4 МБ ; float64: 18.9 МБ
         matvec:  4.72e6 flop
```
**Обрезание работает только для короткой группы.** Вклад ячейки на расстоянии
`> 4*ell` подавлен в `e^4 = 55` раз:

| Группа | `ell` | Радиус обрезания `4ell` | Матрица (float32) | matvec |
|---|---|---|---|---|
| B (130.4 нм) | 41 мкм | 164 мкм | `96 x (33 x 40)` = 0.51 МБ | 2.5e5 flop |
| A-короткая | 14.8 мкм | 59 мкм | ещё меньше | ~5e4 |
| A-средняя | 90 мкм | 360 мкм | `96 x (70 x 90)` = 2.4 МБ | 1.2e6 |
| **A-длинная** | **238 мкм** | **952 мкм** | **обрезание невозможно, полная 9.4 МБ** | **4.7e6** |

Итого при 2 группах фотоэмиссии (окно A-длинная + окно B) —
**≈ 10 МБ и ≈ 5e6 flop на обновление**. При `nPhotoSubstep = 3` это
`1.7e6 flop/шаг` — сопоставимо с одним решением Пуассона. Приемлемо.

**Практическая рекомендация по группировке:** для фотоэмиссии использовать
**две** группы, а не пять:
```
группа PE-A: h*nu = 12.3 эВ, ell = 90 мкм (средневзвешенная по весам 0.07/0.26/0.67
             с обрезанием: ell_eff = sum w_j ell_j = 0.07*238+0.26*90+0.67*14.8 = 50 мкм)
             -> Y_ph(12.3, E_th) ~ 4e-3 ... 5e-3
группа PE-B: h*nu = 9.51 эВ, ell = 41 мкм
             -> Y_ph(9.51, E_th) = 0 при E_th > 9.51; 1.1e-4 при E_th = 9.0
```
**Важно:** усреднённая `ell_eff = 50 мкм` **теряет длинный хвост**, который и
даёт ореол. Поэтому для группы PE-A **сохранить полное трёхэкспоненциальное
разложение** (3 подматрицы: 0.05 + 2.4 + 9.4 = 11.9 МБ) — или, если память
критична, оставить две подгруппы (`ell = 238` полная + `ell = 20 мкм`
обрезанная), пожертвовав средней. **Дефолт: три подматрицы, 11.9 МБ.**

**Что реализовать как дешёвую альтернативу** (`photoEmissionMode = 'p1'`):
одна дополнительная гельмгольцева группа с P1-замыканием
`kappa = sqrt(3)*mu`, амплитуда `3*mu`, поток на стенку `Gamma = h_w * S|_wall`,
`h_w = (1-R_w)/(2(1+R_w))`. Точность ~фактор 2 в ядре, хуже в ореоле.
Использовать только для быстрых прогонов.

### 7.5 Фотоотлипание: прямое ядро `1/(4πR²)` — Гельмгольц не годится

**Почему Гельмгольц не подходит.** При `kappa -> 0` функция Грина
`exp(-kappa R)/(4 pi R)` стремится к `1/(4 pi R)`, а прозрачный поток имеет
ядро `1/(4 pi R^2)`. Это разные функции, и никакой малой `kappa` их не
примирить.

**Правильный осесимметричный интеграл с аналитически взятым азимутом:**
```
Psi(r,z) = INT q(r',z') * r' dr' dz'
           / ( 2 * sqrt( [ (r+r')^2 + (z-z')^2 ] * [ (r-r')^2 + (z-z')^2 ] ) )
```
Вывод: `INT_0^{2pi} dphi/(a - b cos phi) = 2 pi/sqrt(a^2-b^2)` с
`a = r^2+r'^2+(z-z')^2`, `b = 2 r r'`, и
`a^2-b^2 = [(r-r')^2+Δz^2]·[(r+r')^2+Δz^2]`.
**Формула проверена численной квадратурой по 4e5 узлам на четырёх случайных
наборах аргументов: совпадение до 1e-6.**

**Самоячейка.** Точечное выражение сингулярно, 3D-интеграл конечен —
интегрировать по конечному объёму. Для тороидальной ячейки с `dr, dz << r`
(предел стержня): вклад бесконечного стержня на единицу площади сечения равен
`1/(4 rho)`, откуда
```
Psi_self = q * (1/4) * < INT_cell da/rho >
```
Численно, усреднением по точкам наблюдения внутри ячейки:

| Отношение сторон `dz/dr` | `Psi_self / (q * sqrt(dr*dz))` |
|---|---|
| 0.5 | 0.723 |
| 1.0 | **0.744** |
| 2.0 | 0.723 |
| 4.0 | 0.666 |

```
Psi_self = C_self * q * sqrt(dr*dz),    C_self = 0.72 +- 0.05
```
Для **приосевой** ячейки (`r -> 0`) предел стержня неприменим: ячейка
компактна, использовать шаровой эквивалент `Psi_self = q * R_eq`,
`R_eq = (3V/(4 pi))^{1/3}`, `V = pi*(dr/2)^2*dz`.

`C_self` окончательно калибруется тестом VF8 (см. §8).

**Огрубление.** `Psi` по построению гладкая (оператор с ядром `1/R²`
сглаживающий). Полная матрица `(nr·nz)² = 24576² = 6.04e8` элементов =
**4.83 ГБ** — исключено. Считать на огрублённой сетке:

| Огрубление | Точек | Матрица (float32) | matvec | Ячейка при `R_dom=1 мм`, `d=1 мм` |
|---|---|---|---|---|
| 24 × 32 | 768 | 2.36 МБ | 1.18e6 | 42 × 31 мкм |
| **32 × 48** | **1536** | **9.4 МБ** | **4.7e6** | **31 × 21 мкм** |
| 48 × 64 | 3072 | 37.8 МБ | 1.9e7 | 21 × 16 мкм |

**Рекомендация: 32 × 48.** Филамент радиусом 75 мкм разрешается 2–3 ячейками
радиально — достаточно, потому что `1/R²`-профиль от него всё равно
восстанавливается интегралом, а не формой одной ячейки. При
`nPhotoSubstep = 3` стоимость `1.6e6 flop/шаг`.

**Ближняя поправка.** Огрубление занижает поток внутри самого филамента.
Добавить прямой расчёт на **мелкой** сетке в окне `R < R_near = 2` огрублённых
ячейки (полоса ~5×7 мелких ячеек), с вычитанием соответствующего огрублённого
вклада:
```
Psi = interp(Psi_coarse) - Psi_coarse_near + Psi_fine_near
стоимость: nr*nz*35 = 8.6e5 flop
```

**Альтернатива через спектральное представление** (для сведения):
```
1/R^2 = (1/R) * INT_0^inf exp(-kappa R) dkappa
```
то есть прозрачное ядро точно представимо континуумом юкавских ядер.
Дискретизация 8–16 логарифмически разнесёнными `kappa_j` с квадратурными
весами даёт **отдельный** фит (не имеющий никакого отношения к трём воздушным
коэффициентам §2.6). Стоимость: 8–16 гельмгольцевых решений =
`8…16 × 4.9e6 = 4…8e7 flop` на обновление — **в 10–17 раз дороже прямого
ядра**. Плюс проблема: `1/kappa_1` в такой квадратуре заведомо больше области,
и решение начинает определяться граничным условием.

**Вердикт: прямое огрублённое ядро.** Спектральное разложение реализовать
только как эталон в тесте VF9.

**Приближение равномерного засвета (`photoDetachMode = 'uniform'`)**
```
Psi = G_slab * q_bar ,   G_slab = (d_gap/2)*ln(R_el/(d_gap/2)) = 1.21e-3 м
```
**для одиночного филамента 50–100 мкм — плохое приближение**: оно теряет и
сильный `1/R²`-профиль вблизи филамента (занижение в 10–30 раз), и широкие
хвосты. **Допустимо только для усреднённой модели большого числа случайных
микроразрядов** (режим «много филаментов», где `q` действительно почти
однороден по площади). Оставить как отладочный режим с предупреждением в UI.

### 7.6 Порядок операций на шаге

```
1. Транспорт заряженных (Шарфеттер-Гуммель)             — как было
2. Пуассон (полунеявный, 2 прогонки)                    — как было
3. --- ФОТОБЛОК: если any(photo*) и (step % nPhotoSubstep == 0) ---
   3a. Источники:
         S_ion(r,z)  = k_E1(|E|/N) * n_e * N                 (модуль! ERRATA E1)
         P_dep(r,z)  = e * |Gamma_e . E|                     [Вт/м^3]
         q_A = eta_gamma * S_ion                             (окно A)
         q_B = f_VUV * P_dep / E_ph_B                        (окно B)
         q_C = f_det  * P_dep / E_ph_C                       (окно C)
   3b. Окно A: одно прямое r-преобразование q_A (в метрике M_r),
                3 набора z-прогонок, 3 обратных преобразования -> S_1,S_2,S_3
                S_pi = Phi_ion * (S_1+S_2+S_3)
   3c. Фотоэмиссия: view-factor matvec по группам PE-A (3 подматрицы) и PE-B
                -> Gamma_gamma,g(r) на обеих стенках
                Gamma_pe(r) = sum_g Y_ph(hnu_g, E_th) * Gamma_gamma,g(r)
   3d. Фотоотлипание: огрублённый matvec + ближняя поправка -> Psi(r,z)
                nu_pd,s = sigma_pd,s * Psi
4. Объёмные источники (экспоненциальный интегратор):
      + S_pi   в n_e, n_O2p                (photoIonization)
      + nu_pd  в отлипание, с нейтральными продуктами (photoDetachment)
5. Граничные потоки: Gamma_e,wall -= Gamma_pe            (photoEmission)
6. Обновление sigma_surf                                 — как было (знак: ERRATA A1)
7. Медленная химия (подцикл)                             — как было
```
Фотоблок — **после** Пуассона (нужно `E` для `P_dep`) и **до** источников.
При `nPhotoSubstep > 1` поля замораживаются: уравнения эллиптические,
собственной памяти не имеют, ошибка — только от изменения источника за
`nPhotoSubstep` шагов (проверка VF10).

### 8.2 Критерии валидации фотомодуля

Нумерация **VF1…VF12**, чтобы не пересекаться с V1–V13 (`ERRATA.md` C).

**VF1. Точное выключение.** При всех трёх флагах `false` результат совпадает с
прогоном сборки без фотомодуля в пределах 1e-12 относительных по `U_gap(t)`,
`I(t)`, `Sigma(t)`, `∮U dQ` на 2 периодах.
*Ловит: непреднамеренную инициализацию, забытые слагаемые.*

**VF2. Экспоненциальный спад от точечного источника.** Однородный газ,
`q = δ`-источник в центре, область `> 10/kappa_1`, **одна** группа Гельмгольца.
`S(R)·4πR/A_1 = exp(-kappa_1 R)` с ошибкой < 2 % на `R ∈ [3·dr, 5/kappa_1]`.
*Ловит: знак диагонального сдвига (`ERRATA.md` B3), неверное `kappa`,
ошибку в весе `M_r`, деление на `r` на оси (`ERRATA.md` B2).*

**VF3. Тест транспорта на воздушных коэффициентах Бурдона.**
С `A_j = 1.91e-45, 4.91e-44, 4.70e-42 м⁴`, `lambda_j = 1.72e-22, 4.53e-22,
2.76e-21 м²` и `p_O2` воздуха модуль обязан воспроизвести опубликованный
профиль `S_ph(R)` Бурдона для точечного источника в пределах 5 %.
**Это тест ТРАНСПОРТА, не физики** — с этими коэффициентами прогон O₂
физически недопустим.

**VF4. Сохранение интеграла источника.** При отражающих границах
(`R_w = 1` / чистый Нейман) и достаточно большой области
```
INT S_pi dV = Phi_ion * eta_gamma * INT S_ion dV   с точностью 1 %
```
Плюс алгебраическая проверка при старте:
`assert(|sum_j A_j/lambda_j^2 - 1| < 1e-3)`.

**VF5. Открытое ГУ не создаёт и не отражает.** Тот же точечный источник у
границы: решение с модальным условием
`dS_hat/dn + sqrt(k_m² + kappa_j²)·S_hat = 0` должно совпасть с решением на
области, расширенной на `5/kappa_j`, в пределах 3 %. Решение с `S = 0`
на границе даст ошибку 30–60 % — **этот прогон включить в тест как
«так делать нельзя»**.

**VF6. Сохранение заряда при включённой фотоэмиссии.**
`INT rho dV + (Sigma_1 + Sigma_2)·A + Q_внеш` сохраняется лучше 1e-10
относительных.
*Ловит: двойной учёт `Gamma_pe` (в потоке электронов И в `dSigma/dt`).*

**VF7. Порог фотоэмиссии переключает канал.** Прогон с `E_th = 9.0` и
`E_th = 10.5` должен давать **качественно разный** состав `Gamma_pe`:
при 10.5 эВ вклад группы PE-B (130.4 нм) обязан быть строго нулевым, весь
поток — из окна A. Если при `E_th = 10.5` группа PE-B даёт ненулевой вклад —
ошибка в фаулеровской отсечке `max(0, ...)`.

**VF8. Калибровка самоячейки прозрачного ядра.** При `q = const` по всей
области дискретный оператор §7.5 даёт `Psi = q·G_slab`,
`G_slab = 1.21e-3 м`, ошибка < 5 %. Константа `C_self` подбирается по этому
тесту (ожидается 0.72 ± 0.05; приосевая ячейка — по шаровому эквиваленту).

**VF9. Согласие трёх схем прозрачного переноса.** Модельная задача:
однородно излучающий цилиндр `a = 75 мкм`, `L = 1 мм`, `q = 1e26`.
Точное ядро на мелкой сетке, огрублённое 32×48 ядро и спектральное
разложение `1/R² = (1/R)∫exp(-κR)dκ` (16 узлов) должны согласоваться в
пределах 15 % на `rho ∈ [0.15, 2] мм`. Аналитический эталон вдали:
`Psi = q·pi·a²/(4 rho) · (2/pi)·arctan(h/rho)`.
Режим `'uniform'` в этом тесте обязан **провалиться** (занижение в 10–30 раз
при `rho < 0.3 мм`) — это подтверждает, что предупреждение §7.5 записано верно.

**VF10. Независимость от `nPhotoSubstep`.** Прогоны с `nPhotoSubstep = 1` и
`= 3` дают одинаковые V1–V12 в пределах 0.5 %, и одинаковую фазу зажигания
в пределах 1° (при 10 кГц это 0.28 мкс).

**VF11. Ожидаемое влияние на физику — не «ноль», а конкретный профиль.**
Это не тест «должно совпасть», а **предсказание, которое надо проверить**.
При номинальных параметрах, сравнение вкл/выкл:

| Метрика | Ожидаемое изменение | Если больше — разбираться |
|---|---|---|
| Перенесённый заряд `ΔQ` (V6) | < 2 % | |
| Мощность по Мэнли (V5) | < 2 % | |
| `U_b` (V2) | < 1 % | |
| Выход озона (V10) | < 3 % | |
| **Фаза зажигания (V8)** | **1–10°** (0.3–3 мкс при 10 кГц) | > 20° |
| **Радиус филамента** | **10–40 %** | > 100 % |
| **Скорость фронта** | **10–30 %** | > 100 % |
| **Пиковый ток `I_max`** | 5–20 % | > 50 % |

Логика: интегральные величины держатся балансом заряда на барьере (V6 = `2 C_d
(U₀ − U_i)` — чистая электротехника, фотопроцессы её не трогают), а
пространственно-временные характеристики зажигания — держатся затравкой,
которую фотопроцессы и меняют. **Обратная картина (интегралы поехали, а
морфология нет) означает ошибку в знаке или в двойном счёте.**

**VF12. Развёртка неопределённости.** Прогнать 3 набора `photoIonWeights`
(`'air'`, `'short'`, `'long'`) и 3 значения `E_th` (9.0 / 10.0 / 10.5) при
фиксированных остальных параметрах. Разброс радиуса филамента и фазы зажигания
по этой сетке — **и есть честная оценка неопределённости модели**, её надо
показывать в UI/анимации, а не прятать. Ожидаемый разброс: радиус ×1.5–2,
фаза ±5°.

## 9. Что нужно измерить, чтобы поднять достоверность

По убыванию важности:

1. **Абсолютно калиброванный спектр излучения разряда в чистом O₂ при 1 атм,
   90–180 нм.** Даёт сразу `eta_gamma`, `f_VUV` и веса `A_j` — то есть три из
   четырёх [C]-параметров модуля. Без этого точность модуля принципиально
   ограничена фактором ~30. Экспериментально: вакуумный тракт, Al/MgF₂-оптика
   (MgF₂ отсекает на 115 нм — для 98–103 нм нужен бесоконный ввод).
2. **`E_th` и `Y_ph(hν)` для Al₂O₃, работавшей в разряде** (не для свежей).
   Разница между `E_th = 9.0` и `10.5` эВ включает/выключает главный канал —
   это качественная, а не количественная неопределённость (VF7, VF12).
3. **Полная доля энергии в излучение** (`f_rad`) из калориметрии/абсолютной
   актинометрии → `f_det`.
4. `sigma_pd(O₃⁻)` в детачмент-канале **отдельно** от фотодиссоциации
   `O₃⁻ + hν → O⁻ + O₂` — сейчас [B], а это единственный ион, для которого
   фотоотлипание принципиально.
5. Разрешить расхождение по D6 (приведённая vs полная масса, §5.3) — оно
   больше, чем весь эффект фотоотлипания, и относится не к этому документу,
   а к `ERRATA.md` D.
